# 法器、供具与陈设（src/world/props）

寺里能近看、能上手的器物都在这里，全部由程序搭出来，没有外部模型。佛像另在 `buddha*`，不在本文范围。

- 入口：`src/world/props/index.ts`（统一导出）。
- 看单件：`/lab.html?m=<名字>&h=10&az=25&el=18&d=1.6&ty=0.3`（名字同函数名；另有 `propsAll` 全部排开、`propsStats` 逐件量建时 / 三角 / 绘制，结果打在控制台 warn 里）。
- 约定：函数签名 `(mats: Mats, q: Quality, ...额外参数) => THREE.Group`；原点在**底面中心**、面朝 **+z**、单位米；会动的部分是有名字的子节点，并写在 `group.userData` 里。例外见各条。
- `q.tier === 'low'` 时车削段数减半、花瓣 / 细枝减少。

## 各件的做法与依据

- **大香炉**：三足圆鼎式，一足朝前（寺里三足炉的摆法）。立耳立在口沿上、顺着口沿走（耳孔朝左右，穿杠抬鼎的那个方向），自下而上向外撇——正面看是两道外扬的弧。腹上两道弦纹夹一圈乳钉；足根是只取个意思的兽面。炉里的残香是实例化的细杆（顶上一截灰、交界一圈焦）。
- **木鱼**：诵经用的团鱼形圆木鱼。鱼身是一张经纬网（在鱼口与两端圆孔处加密）：鱼口处把面往里压 4 厘米，口沿略鼓；鱼口里的黑、口沿的金线、两肋的鳞纹、额头敲旧的一块，都画在同一张贴图上（颜色 / 粗糙与金属 / 高度三张，高档 1024×512）。提梁是两条鱼首衔一颗金珠。朱褐漆带一层清漆。
- **大磬**：钵形，口沿略收、沿下两道细弦纹，壁有厚度（看得见里面）。用自烘的「暗金的铜」，不带金箔接缝、不生绿锈。
- **梵钟**：钟身略上收的筒形、平口厚唇、圆肩。袈裟纹：五道横带（各两条弦纹）、四道纵带（各两条棱）；上区四面各三排四列乳钉（共 48，实例化）；中带前后各一枚八瓣莲的撞座，位置在钟高约 1/4 处。蒲牢钮简化成一道背上带脊的拱形龙身，铁环穿过钮下往上挂。有内壁。
- **石灯**：取唐代燃灯塔的形制——八角地栿、覆莲座、八角短柱（腰上一道箍）、仰莲托、八角灯室（正四面开窗衬纸，斜四面是带直棂意思的石板）、八角攒尖顶（八条垂脊、檐略厚）、相轮与宝珠。
- **莲灯**：三层纸瓣（8 + 8 + 5），连底托、小烛一共一块网格、一个材质；发光强弱靠一张 4×64 的渐变贴图顺着瓣走（根上最亮、瓣尖暗、底托不亮）。
- **蒲团**：轮廓线上真的鼓出一圈圈草辫（每圈 2.35 厘米），再叠一张人字纹的草编贴图，一圈贴图正好对一圈草辫。
- **匾与联**：字用 "Ma Shan Zheng" 画成黑底白字，抹宽当高度，现算出颜色、粗糙 / 金属、法线三张贴图：金字是金属、鼓起来的。调用前要保证这些字的字体已到（`fontsReady(text)`）。
- **幡、祈愿带**：各是一块网格，带 `sway` 顶点属性（上端 0、下端 1）；材质已自己 `enhance({ wind })` 过，并留了 `userData.enhance`，主场景再 `adopt()` 也无妨。幡的风量 0.25，祈愿带 0.7；整体强弱跟 `shared.uWind.z` 走。影子不随风动。

## 材质（kit.ts 的 `pmats(mats, q)`）

core/mats 里没有的质感在这里补：白瓷 / 青瓷 / 黑釉（高档带一层釉光，低档是普通材质）、竹、生铁、草编、牛皮、红泥、麻绳、暗金的铜、织金（小菱纹）、蜡、墨、水、果与花叶（全靠顶点色）、毛毡、旧木、深色素木、`tool`（素的、全靠顶点色，槌和笔这类小件用它，一件只一块网格）。

- 用到哪种才建哪种（小贴图也是那时才烘），同一套 `mats` 只建一次。
- 都已 `enhance()`（接了寺里的雾）。
- 白瓷、蜡、纸在日光下容易过曝起泛光，颜色特意压到七八成白。

## 工具（kit.ts / furniture.ts）

`spl`（把控制点连成顺滑轮廓）、`prof`（几段轮廓相接，接缝处重复的点就是硬棱）、`rib`（弦纹）、`turn`（车削：uv 的 v 按真实弧长；接缝在背后；`tile` 让一圈凑成整数张贴图）、`disc`（朝上的圆面，uv 平铺）、`ring`、`tube`（圆管，法线圆滑）、`curve3`、`pillow`（超椭球软垫）、`blob`（捏过的球）、`withSway`、`dyed`（几块几何各染一色并成一块）、`lowTable` / `slab` / `apronBoard`（几案：案面倒棱、束腰、壸门牙板、蹄足）。

## 性能

- 全部器物各建一遍：第二遍起约 100–150 毫秒（其中匾和联的字图各占 15–30 毫秒）；头一遍连材质与小贴图约 250 毫秒。
- 最重的几件：供桌 27k、梵钟 26k、木鱼 17k、大香炉 15k、大鼓 15k 三角（高档）。供桌上的小件多，远看时可以整套不画或换低档。
- 石灯每座 2 次绘制、5.9k 三角，摆多座时建议合并或实例化。
- 签筒 `live=true` 是 33 次绘制，只在抽签的特写里用；平时摆着用 `lotTube(mats, q, false)`。

## 已知的不足

- 铜器用的是 core 的 `mats.bronze`，绿锈的斑块偏大偏硬（近看像迷彩）；这是 core 贴图的事，器物这边没有改。
- 供桌的桌围是一片素布加织金边，没有绣花。
- 兽面、蒲牢、莲瓣都只取了意思，经不起贴脸看。
- 扫帚的细枝是实体的细管，没有用带透明通道的卡片；枝梢没有更细的分叉。
- 幡和祈愿带的摆动只是顶点上的位移，不是布料解算。
