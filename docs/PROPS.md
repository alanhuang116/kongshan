# 屋舍与器物（src/world/build）

安乐窝里人手造的一切，全是程序搭的，用画法（`docs/INK.md`）的材质：土、茅、木、竹、石、纸。位置、尺寸都从总图 `site.ts` 取，这里的坐标是按当时的总图量出来的——总图一改，重跑一遍台子就是新的数。

```ts
import { createBuildings } from './world/build';
const B = await createBuildings({ q, season });   // 约 0.4–0.7 秒（含等字体）
scene.add(B.group);
B.hallRoof.visible = B.hallFront.visible = !inHall;   // 人进了草堂：屋顶、南墙（连门窗、两扇门）隐去
B.setLamp(atmos.lamp); B.update(dt, t);                 // 每帧：窗纸、屋里、灯笼的暖光；水碓转、灯火跳；晒的东西下雨、天黑就收
B.setSeason('winter');                                  // 换季：屋里的火盆竹席、瓶里的花、匾里晒的东西、门上的桃符（一下子换过去）
```

**随季节换的**（`seasons.ts`；都是住在这里的人随季节过日子，不是雪进了屋）：

| | 春 | 夏 | 秋 | 冬 |
| --- | --- | --- | --- | --- |
| 草堂条几上的胆瓶 | 一枝桃 | 荷一朵、一苞、一叶 | 几茎菊（黄白） | 一枝红梅 |
| 西间榻前的矮架 | 一盆石菖蒲 | 同 | 同 | 一只火盆，炭是红的（夜里透一点红光） |
| 榻上 | 叠着一床被 | 一领竹席、竹夫人、蒲扇 | 叠着一床被 | 被摊开，再叠一床 |
| 院里晒架（下雨、天黑就收） | 笋干（洛阳不产茶，北宋的茶是南方来的团饼，不在院里晒） | 摊开的书（晒书） | 柿饼、菊花 | 萝卜干、晾蔫的白菜；架脚一口压着石头的腌菜缸 |
| 陶家 | 窑门里有火；屋前坯架上摊着阴坯（怕雨，下雨收） | 同 | 同 | 歇窑：窑门里没火、窑顶苫草帘，坯架空着 |
| 各家门口 | | | | 年下挂一对桃符 |

实现：`Ctx.season[季]`、`Ctx.dry[季]` 各是一个 Builder（世界坐标），`Ctx.dabs[季]` 是瓶花的笔（`VASE` 里的格）；`make.ts` 各并成一组，只显当季的那一组。

- `B.group.userData.solids`：挡路的脚印（`rect`：中心 x,z、宽 w（沿自己的 x）、深 d、`yaw` 按 three 的 `rotation.y`；`disc`：中心与半径 r；`top` 是顶面高，`walk: true` 的是能踩上去的面；`roof` 是有顶小棚的檐口高，给画法「屋顶底下不积雪」用，这样的脚印 id 带「檐」字、不挡路）。`userData.stats`：三角与绘制数（连没显出来的各季都算上）。
- 台子：`/ink.html?m=hall|hallInside|gate|fence|bridge|pavilion|house&id=a|school|well|props|more|buildAll&ground=0`，另有 `&lamp=0…1`、`&hide=roof,front`、`&land=0`、`&dump=1`；新添的：`bambooHome`（篾匠家）、`potter`（陶家：屋、坯棚、窑）、`herbGarden`（药圃）、`hallSeasons`（草堂里随季节换的，`&season=` 看各季）、`dryRack`（院里晒架）、`traces`（甲家门前屋后）、`scene`（只搭新添的这几件，数三角用）。
