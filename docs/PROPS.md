# 屋舍与器物（src/world/build）

安乐窝里人手造的一切，全是程序搭的，用画法（`docs/INK.md`）的材质：土、茅、木、竹、石、纸。位置、尺寸都从总图 `site.ts` 取，这里的坐标是按当时的总图量出来的——总图一改，重跑一遍台子就是新的数。

```ts
import { createBuildings } from './world/build';
const B = await createBuildings({ q });        // 约 0.4–0.6 秒（含等字体）
scene.add(B.group);
B.hallRoof.visible = B.hallFront.visible = !inHall;   // 人进了草堂：屋顶、南墙（连门窗、两扇门）隐去
B.setLamp(atmos.lamp); B.update(dt, t);                 // 每帧：窗纸、屋里、灯笼的暖光；水碓转、灯火跳
```

- `B.group.userData.solids`：挡路的脚印（`rect`：中心 x,z、宽 w（沿自己的 x）、深 d、`yaw` 按 three 的 `rotation.y`；`disc`：中心与半径 r；`top` 是顶面高，`walk: true` 的是能踩上去的面）。`userData.stats`：三角与绘制数。
- 台子：`/ink.html?m=hall|hallInside|gate|fence|bridge|pavilion|house&id=a|school|well|props|more|buildAll&ground=0`，另有 `&lamp=0…1`、`&hide=roof,front`、`&land=0`、`&dump=1`。

## 挂点（`B.anchors`，世界坐标 x, y, z ∠朝向）

## 分量

全部：三角约 17 万（低档 15 万）、绘制 57 次（院里一处、村里一处、田间渡口一处各按材质并块；草堂的屋顶、南墙各一组；可拿的每件一次）。`createBuildings` 约 0.4–0.6 秒。

## 还差的

- 茅顶的草丝靠材质的干笔，近看是一道道深浅，不是一根根草；檐口的参差是折线。
- 邻家的屋进不去，门里只是一片黑；村塾里的桌席很简。
- 夜里屋里只有墙面、地面泛暖光，家什还是暗的剪影。
- 观物亭檐低，「观物」牌从高处的镜头看会被檐口挡住上半。
