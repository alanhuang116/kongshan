# 草木（src/world/env/flora.ts）

寺里寺外的松、古松、银杏、枫、竹、梅、草丛、荷。全部由程序现场长出来：枝干是沿折线扫出的管，叶是带透明的卡片，叶的贴图在画布上现画。没有任何下载的模型与图片。

## 怎么用

```ts
import { createFlora } from './env/flora';
import { adopt } from './core/mats';

const flora = createFlora(mats, quality, layout, season);
adopt(flora.group);          // 必须：接上寺里的雾、风、雪（材质上已写好 userData.enhance）
scene.add(flora.group);
flora.setSeason('winter');   // 换季：只改颜色、显隐、叶卡画几成，不重建
```

接口与主代理定的一致，多了一个 `flora.stats`（各部分三角数、各段建造毫秒，调试用）。

- `layout` 里每个点的 `y` 是地面高度；`s` 大小倍率、`r` 绕 y 转、`v` 形态编号（不给就按下标轮换）。
- `canopies`：古松、银杏、枫、梅、竹丛的冠心与半径（世界坐标），给落叶 / 落花粒子用。普通的松不列（太多）。
- `leafTex`：银杏叶、枫叶、梅花瓣、松针各一张小图（64px，带透明），给粒子用。
- 远近的松由主代理分：近的进 `pines`（每棵两三千三角），远的进 `farPines`（66 三角）。**近松别放太多**——260 棵就是七十多万三角，手机上建议近松 60–90 棵、其余全用远松。

## 各种植物的长法

| | 形态 | 三角（high / density 0.45） | 说明 |
|---|---|---|---|
| 松 `pines` | 4 种：高松、斜松、平顶松、小松 | 3248 / 2774 / 3026 / 1382（低：2120 / 1844 / 1790 / 896） | 高 12.4 / 9.9 / 10.8 / 6.6 米，冠幅 9–11 米（小松 5–6 米）。实例化，每种形态「干枝一份 + 针叶一份」两次绘制 |
| 远松 `farPines` | 3 种 | 66 | 高 10–12.5 米。干四棱、七片「云片」各三张大卡；不投影 |
| 古松 `heroPines` | 每棵按 `v` 单独生成 | 约 9600–10200 | 高约 9 米，横向探出 10–13 米。干 12 棱、带枯桩，云片下有细枝；`v` 换一个就是另一棵 |
| 银杏 `ginkgo` | 每棵单独生成 | 约 38000（低约 29000） | 高约 15 米、冠幅约 12 米、胸径约 1.1 米；干枝 19000、叶 17400（约 8700 张卡）、冬天才显的细枝卡 1700 |
| 枫 `maples` | 3 种 | 5100–5900 | 高约 4–4.5 米、冠幅 6–7 米（要更高用 `s`） |
| 竹 `bamboo` | 3 种丛 | 5000–5700 | 每丛 9–16 竿，高 8–9 米，丛径 5–6 米 |
| 梅 `plums` | 2 种（一白一红） | 约 1450 | 高约 3 米、冠幅 3.5–4.4 米 |
| 草 `shrubs` | 草丛 / 蕨 / 麦冬 | 8 / 36 / 10 | 不投影 |
| 荷 `lotus` | 四季各一套 | count=46 时：夏 6600（叶 4600、梗 1400、花 600）、秋 5700、冬 1700、春 2100 | 同时只显一季的一套；叶高出水面 0.35–1.05 米，花 1–1.4 米 |

- **松**（flora/pine.ts）：干是一段一段长的，每段换一点方向——往一边斜、左右摆两三道弯、顶上放平；枝先平伸再下探，带折；针叶聚成扁平的「云片」（底平顶微隆），一片 = 十几到三十来小枝，一小枝 = 两张交叉的立卡（侧看：分叉小枝上六七个瓶刷似的新梢）+ 一张平卡（俯看的一团新梢）。所以远看是几层墨绿的云，近看有针，从树下往上看得见枝骨与针的星芒。
- **银杏**（flora/broad.ts）：先定冠形（下宽上收的卵），在冠面上撒 18 个「梢点」；每根大枝从干上陡陡地上扬，再朝自己的梢点弯出去（先上扬后外展），大枝上出小枝、细枝，叶卡沿小枝细枝贴。干有根脚的棱，皮是单独烘的一张（竖的木栓脊与深裂）。
- **枫**：矮干、五根主枝横斜，叶卡近于水平、分层摊开。
- **梅**：干与主枝不抹顺、留着硬折；主枝上另抽几根直上的新条；花卡沿枝贴。
- **竹**（flora/small.ts）：竿六棱，节在贴图上（一格一节：节上一道白粉环）；上段朝外弯、梢头微垂；枝从节上出，叶成「个」「介」字往下披。
- **荷**：叶是真的几何（盾状圆叶，20 边，叶心下凹、叶缘起伏），梗四棱；花是 19 瓣两节的卡片。

## 四季

| | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| 松 | 色略浅 | 墨绿 | 略带黄 | 略灰；积雪 |
| 银杏 | 嫩黄绿，叶只画六成，细枝可见 | 深绿 | 金黄 | 叶隐去，只见枝与细枝 |
| 枫 | 黄绿带橙，叶画七成 | 绿 | 红里带橙 | 只见枝 |
| 梅 | 花画四成（偏粉）、新叶五成 | 叶 | 叶五成半、偏黄 | 花满枝，无叶 |
| 竹 | 浅绿 | 绿 | 绿 | 略黄；积雪 |
| 草 | 浅绿 | 绿 | 枯黄 | 枯褐 |
| 荷 | 小浮叶、尖尖的卷叶 | 立叶、浮叶、花、蕾 | 半枯卷边的叶、折腰的梗、莲蓬 | 枯梗折茎、挂着的枯叶卷、焦黑的莲蓬 |

叶卡在几何里的次序是打乱过的，所以「只画前六成」得到的是一棵均匀疏下来的树，而不是秃掉半边。

## 几处要紧的做法

- **叶的贴图**（`alphaAtlas`，flora/util.ts）：每格单独逐级缩小（格与格不串色），每缩一级把透明度整体放大到「超过阈值的面积」与原图相等。不这样做，松针这类细东西缩几级就全低于阈值，远处的树会秃。透明处的颜色填成叶的平均色，免得叶缘带黑边。松的近景图是 512 一格，其余 256（`q.tex < 1` 时各减半）。
- **叶的材质**（`leafMat`）：内置的 MeshStandardMaterial 上叠了几处小改——
  - 正反两面都用同一条「成团的法线」（从簇心 / 冠心指向外，再和朝上混一点），否则卡片背面黑一片、像纸片；
  - 逆光透亮：朝着日头看过去时叶被照透（`uTrans`、`uTransC`，秋天银杏是金、枫是橙），并且这部分光也受日影遮挡（冠心暗、冠缘亮）；
  - 从树下往上看偏暗（`uUnder`）；
  - 卡片的假法线照出的高光是假的：直射高光去掉，环境反光只留一成；
  - 透明边缘的抗锯齿（alphaToCoverage）：近处抹顺，远处（一个像素里透明度乱跳）退回硬裁，不然层层叠叠的叶各自只盖住同样的采样点，背景永远透得过来。
- **风**：枝、叶的顶点上有 `sway`（0 不动…1 梢头，按高度与离干的远近算），同一棵树的干枝与叶用同一个风幅，所以枝叶一起摆、不脱节。风幅（`userData.enhance.wind`）：松 0.3、银杏 0.5、枫 0.45、梅 0.3、竹 0.9、草 0.22、荷 0.14。把 `shared.uWind.value.z` 加到 2.2（默认的 18 倍）试过，树形不散。
- **雪**：枝叶材质都带 `snow: true`（梅花除外——雪里要看得见梅）。

## 实测（i9-13900KF + RTX 4090，无头 Chrome）

接近实际用量的一整套（松 260、远松 300、古松 3、银杏 1、枫 6、竹 30 丛、梅 4、草 200、荷 60，即 `/lab.html?m=full`）：

- 建造：**184–208 ms**（high），121–154 ms（low）；其中松约 80、银杏约 55、枫约 16、梅 10、竹 10、草 7、荷 12。机器正忙时见过 400 以上。
- 画面：97.5 万三角、61 次绘制，60 帧。

## 在台子上看

`/lab.html?m=<名字>&s=spring|summer|autumn|winter&w=snow&h=<时刻>`，名字：`pine`（四种形态 + 远松）、`heropine`（`&v=1` 换一棵）、`ginkgo`、`maple`、`plum`、`bamboo`、`shrub`、`lotus`（`&gy=-0.5` 把地面降到水面下）、`grove`（混在一起的一片）、`full`（整套，量耗时用）。`&a2c=0` 关掉透明边的抗锯齿对比。控制台里 `__flora.stats` 看三角数与耗时，`__shared.uWind.value.z = 1` 加大风。

## 还不够好的地方

- 枫偏矮（4–4.5 米），树形略像盆景；红色在夕照下偏艳。
- 银杏远看饱满，近看（树下 5 米内）叶片成团的颗粒感略重；冠的轮廓偏规整，缺一两根特别突出的老枝。
- 松的云片底边能看出一张张卡片垂下来的边；普通松的干偏光滑，没有古松那样的枯桩与疙瘩。
- 荷花瓣是平的两节卡片，凑到一两米内看会显薄；秋荷叶缘的折线略硬。
- 竹叶只有一种小枝图，凑近看重复。
- 草只有三种、每种一个形态（靠大小、转向、颜色区分）。

## 给主代理

1. **`World.frame` 的头一两帧 `dt` 可能是负的**（`requestAnimationFrame` 给的时间戳早于 `start()` 里记下的 `performance.now()`；无头模式下 `world.time` 能走到 −0.9）。而 `Atmos.update` 里 `this.w[k] += clamp(g - this.w[k], -dt/5, dt/5)` 在 `dt < 0` 时上下界颠倒，会把雾、雨、雪的权重各加上 `|dt|/5`——于是画面随机带上一成左右的雪与雾（朝上的面发白、日光变弱），每次刷新都不一样。我在台子上是每次建完后重新 `atmos.setWeather(atmos.weather, true)` 压回去的（见 src/lab/models/flora.ts）；正路是 `World.frame` 里 `dt = Math.max(0, …)`。
2. 记得 `adopt(flora.group)`；不 adopt 就没有雾、风、雪。
3. 影子贴图要把树冠罩进去（银杏高 15 米）。远松不投影。
4. 银杏树下的那圈落叶、飘落的叶，用 `canopies` 与 `leafTex` 自己撒。
