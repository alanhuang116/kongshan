# 草木（`src/world/env/flora/`）

安乐窝的草木：桃林、柳、松、梅、竹、桑、槐与杂树，田里的庄稼，菜畦、菊圃、池荷，水边的芦苇，地上疏疏的几笔草，人家门前屋后的果树与零碎。全是画出来的（画法见 `docs/INK.md`）：干枝是沿折线扫出的面，叶、花、草是一笔一笔点上去的；位置全照总图 `site.ts`。

## 怎么用

```ts
import { createFlora } from './env/flora';
const flora = createFlora({ q, season });
scene.add(flora.group);
flora.setSeason('autumn');                             // 换季：约 1.4 秒过渡过去，不重建树
tick.push((dt, t) => flora.update(dt, t, { night, wind, player }));   // 每帧（过渡、夜里把花调淡）
flora.bloomSpots;     // 桃林里花最盛的 12 处（世界坐标，枝头高度）——落花从这里起
flora.extraTrunks;    // TREES 之外草木自己添的树（人家的果树、茶棚边的老柳）：{x, z, r}，走路的要绕开
```

## 有什么

| | 数目 | 长法与笔 |
|---|---|---|
| 桃 `peach.ts` | 64（照 `TREES`） | 矮干斜出，两三根主枝（一根探得低而远），枝是折的；主枝上抽长条，花一簇簇贴着条开——点花 |
| 柳 `willow.ts` | 11 + 茶棚边 1 | 老干朝水斜，大枝先上后拱；垂丝是一串上下相接的笔，越往下摆得越大 |
| 松 `pine.ts` | 2 | 干盘曲，朝石桌欹；枝先平伸再下探、带折，梢头托平展的松盖：一把把攒针，底下压浓墨。低枝避开屋 |
| 梅 `plum.ts` | 1 | 铁干三折，一枝横斜（中段下压、梢头翘），短刺与直上的新条；花疏疏地贴枝 |
| 竹 `bamboo.ts` | 32 丛 | 每丛 13–17 竿，占地约 `r`×2.4，丛丛相接成林；竿按真粗细，节在材质里；叶是「个」「介」字 |
| 槐、杂树、桑 `broad.ts` | 槐 1、村里杂树 26、桑 21 | 先定冠形与梢点，老树干顶分几股粗枝；叶一团团托在枝梢上（先染一笔淡底再点叶）。槐用胡椒点夹羽叶，杂树三种用介字点 / 胡椒点 / 混点，桑是「拳」上抽条 |
| 北坡的远树 `broad.ts: backdrop` | 164 | 只作景：一根干、两三笔枝，几团大点；冬天是寒林的枯枝。一株一百来个三角 |
| 地上的草 `cover.ts` | 约 4500 笔 | 疏疏几笔，一丛一丛：溪岸、路边、田埂、篱脚、树根石根多；路上、田里、水里、院里、屋里、井台晒场没有 |
| 庄稼、菜、菊、荷、芦苇 `field.ts` | 16 畦、菊 16 丛 | 见下「每季一套」 |
| 人家门前屋后 `extras.ts` | 果树 5 | 枣（甲家）、柿（乙家、酒肆）、杏（村塾）、石榴（丁家）；门边蜀葵 / 凤仙、南瓜藤、一小畦葱；瓜架上的藤与葫芦、篱上牵牛、井台与捣衣石边的苔与蕨、水边菖蒲 |

暗合「加一倍法」的几样数目不许动：一梅、两松、十六丛菊（四行四列，略不齐）、三十二丛竹、六十四株桃。

## 四季

四时各有一样花是主：**春桃、夏莲、秋菊、冬梅**，其余的在那一季是安静的。

| | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| 桃 | 花满枝，梢上几片嫩叶 | 披针叶 | 叶黄而疏 | 墨枝 |
| 梅 | 剩寥寥几朵、嫩叶 | 叶 | 叶黄而疏 | 红梅满枝 |
| 柳 | 鹅黄带绿，略疏 | 浓绿 | 黄 | 光的垂条 |
| 杂树、槐、桑 | 汁绿，叶稀，看得见枝 | 老绿 | 一黄、一赭、一苍，叶稀 | 鹿角枝、蟹爪枝 |
| 松、竹 | 常青 | | | 略苍；积雪 |
| 麦 | 青苗成行 | 黄熟 | 茬间新苗 | 稀苗 |
| 油菜 | 菜花（淡黄） | 结荚 | 菜秧 | 稀菜秧 |
| 豆 / 新翻的地 / 荒地 | 矮苗 / 只有垄 / 草 | 满架 / 谷苗 / 蒿 | 枯藤 / 谷穗 / 枯蒿 | 架 / 茬 / 枯 |
| 菊 | 叶 | 叶、苞 | 开（黄、白、浅赭） | 枯茎 |
| 荷 | 无 | 叶与花 | 残荷、莲蓬 | 无 |
| 芦苇 | 新笋夹枯秆 | 青 | 黄、抽花 | 枯，剩几穗 |
| 人家 | 杏花（近白）、路边野花 | 蜀葵、石榴花、牵牛、葫芦 | 柿子、枣、南瓜、田埂野菊 | 枝上几只柿子、干葫芦 |

**怎么换的**（都不重建树）：

- **树上的层**（`layers.ts`）：一层是一种颜料、一次绘制（桃花、梅花、桃梅的叶、柳、杂树三色、枯枝、冬柳的条、松、竹、草）。每层有四季的颜料、点缀色、浓淡、笔的大小与「画次序在几成以内的笔」；每一笔带一个次序 `k`，层里按 `k` 排好——春天的嫩叶、将尽的秋叶就是同一棵树疏一些。换季时这几样量在 1.4 秒里过渡。
- **每季一套的**（`field.ts`）：庄稼、菜、菊、荷、芦苇、人家的花果四季形状不同，每季搭一套（淡彩一层、粉一层、荷叶的面），用到时才搭、搭过留着；换季时旧的一套淡出、新的淡入（`uQ.z`）。颜料写在每一笔上。头一回换到某季要现搭（二三十毫秒）。
- 雪：靠材质的 `snow`（花不积：梅 0、桃 0.15）。风：干枝的 `sway` 属性与每一笔的 `sway`，全在着色器里。夜：粉彩的 `body` 调低三成。

## 笔（`tiles.ts`、`tiles2.ts`）

五张图集，开场现画，一格 192 像素（松竹 224；乘 `q.tex`）：`TREE`（介字点、胡椒点、混点、桑叶、槐叶、桃叶、垂柳、鹿角枝、蟹爪枝、远树）、`BLOOM`（桃、梅）、`EVER`（攒针、松盖、个字竹叶）、`FIELD`（草、苔、芦苇、麦、谷、油菜、菜、豆、蒿、菊叶、瓜叶、蕨、菖蒲、藤）、`PETAL`（菜花、菊、莲、芦花、野花、葫芦、果、石榴花、蜀葵、牵牛）。

叶团的格子底下垫一层**不到一半透明的淡底**：近看镂空（笔与笔之间透着纸），缩小了门槛放低，它才显出来把一团叶连成片——远树不稀，近树不闷。

## 还不够好的地方

- 大槐的粗枝凑到跟前看是几块板似的（七棱、明暗两分），缺疙瘩与老皮的细节。
- 竹叶的「个」字偏阔，丛的上半截远看是一片匀匀的绿，少了竿梢探出去的参差。
- 庄稼的一格是「一小段垄」，凑近能看出同一格重复；垄是直的，没有顺地势。
- 北坡的远树在六十米外褪成淡墨团，夏天略显灰。
- 垂柳的丝是朝着镜头的片，从正下方往上看是平的。
- 瓜架、竹篱是屋舍那边搭的：位置只约定了 `SITE.more.trellis` 与院的南篱，架子的宽深高（3.2×2.4×2.15 米）、篱高（1.05 米）是这边估的，要对一对。
