# 器物游戏（src/world/acts 的十来样、src/world/play）

安乐窝里「拿起来玩一会儿」的那些事：每一样都有手上的节奏（按住、松开、拖、点的时机）、有动画、有声音、有个小小的结果，做完记一笔（起居注 `k.log({ kind: 'play', text })`，成绩记在 `k.mem` 的 `'play'` 那一份里）。
器物与玩法都是北宋有的：投壶、秋千、纸鸢、打水漂、钓鱼、摇橹、堆雪人、扫院、风铃、柴门、灯笼。不照搬哪一款现成的游戏。

| 事（act id） | 在哪、什么时候 | 怎么玩 | 结果 |
| --- | --- | --- | --- |
| 秋千 `swing` | 村塾前的秋千（屋舍那边的 `swingSeat`）；小女孩在、或正往这边来时让给她 | 坐上去，两手攥绳；按「蹬」（空格、点画面）——荡到头、刚往回走的那一刻蹬最得劲（表上「蹬」那一段），越荡越高，袖子兜着风；「下来」时脚尖在地上拖一拖，停稳了再站起来 | 最高荡到几度、板离地多高 |
| 摇橹 `boat` | 渡口栈桥西边泊着的小划子 | 按住「摇」是推橹、松开是拉回，推到头、拉到头的那一刻换（表上标着该换的那一头）。转向：← → 或 A D；手指（鼠标）按在画上左右拖——拖向哪边船头往哪边去，拖得越远舵越满，松手回正；触屏上左边另有「左」「右」两枚键（按住转、松开回正，左手转向、右手按「摇」；`state.steer`，见 `src/app/acts/Widgets.tsx` 的 SteerKeys，检查在 `tests/play/steer.mjs`），也可以一只手按「摇」、另一只手拖；点一下要去的水面（或竹篙、栈桥的签），船头自己转过去、对准了回正。橹也是舵：偏着舵时橹整个往一边偏着摆，摇着转得最快，船快时次之，停着手不摇只能拨着橹慢慢掉头；镜头跟在船后头、方位慢半拍跟上，所以船头在画里摆过去看得见，船尾的水纹拖出一道弯，左永远是画面的左。提示先教摇，再教转，离了方向就说竹篙（栈桥）在哪边、往哪边转。沿北岸摇到插在水里的竹篙，停一停南望伊阙，再摇回来，船自己靠上栈桥；浅处、远处会搁住，说往深水那边转 | 一个来回几秒 |
| 垂钓 `fishing` | 石桥西七米的溪北岸，柳树下 | 按住「抛」蓄劲、松手甩（落在溪心最好）；浮子轻点是试饵，猛一沉才提（点画面 / 「提」）；遛鱼时按住提竿、松手放一放，「劲」要在中间那一段——太紧断丝，太松脱钩；上来了收进鱼篓（行囊里添一尾 `fish`）或放回溪里 | 什么鱼、几寸 |
| 纸鸢 `kite` | 春天，渡口北边的河滩草地（这件事做着也能走） | 先看风从哪边来，迎着风跑（Shift），跑出劲来按住「放」；拽得紧就放线，松了别放、迎着风走几步；太紧线断（纸鸢顺风飘走），太松栽下来；「收线」收回来 | 最高几米（高了只剩天上一点） |
| 投壶 `pitchpot` | 院里，石桌西南的空地（壶平时就立在那里，十二支矢插在壶里） | 提示一句话说全怎么投：左右拖画面（← →）瞄准，按住「投」（空格）蓄力，指针走进「正好」那段就松手。瞄：地上一溜淡墨点是矢要走的方向，对准了壶口转朱，壶上的签写「对准了」「偏左·往右拖」「偏右」「对着壶耳·力道略小些」。力：表叫「力道」，指针从左到右匀匀地走、到头再走回来（一帧一报，不落后），标出的那一段（昼朱夜金）底下写着「正好」，大键头上写着「按住蓄力」；按着时空中一道淡弧是这一下的去处（进壶口转朱）。投出去落定了说落在哪：中了（几筭）、远了＝力大了、近了＝力小了、偏左、偏右、碰着壶口沿、擦着壶耳——落点上一圈淡墨、一枚签，表停在松手的那一刻；下一支的提示照着说怎么改（「上一支力大了：指针过了「正好」那段才松手」）。碰在壶上反跃回来的那一支，大键变成「接」，眼疾手快按一下（或点画面）接住，再投而中是骁箭 | 照司马光《投壶新格》计筭：有初、连中、散箭、贯耳、有终、骁箭、倚竿、全壶、败壶 |
| 打水漂 `skip` | 渡口栈桥头，斜着朝西南的开阔水面 | 弯腰拣一块（扁的漂得远）→ 表上的针走到「贴着水面」那一段时按下定角 → 按住蓄劲、到合适的那一段松手 | 漂了几下、多少步开外沉下去 |
| 堆雪人 `snowman` | 冬天地上积着雪，院里（做着也能走） | 推着雪球走，越滚越大，「立住」当底座；再滚一个推到跟前「叠上去」；捏个头；插树枝、点炭眼、戴斗笠 | 雪人留在院里（存在 mem），天晴、过几天慢慢化 |
| 点灯 `lantern` | 黄昏到夜里，院里三盏纸灯笼（檐下东、西，柴门楣头） | 点灯笼上的签，人走过去举起纸捻点亮；走到灯底下站一站也就点了（做着也能走） | 三盏都亮了记一晚；点亮的一直亮到天明，不点就黑着 |
| 扫院 `broom` | 秋天院里落了一地叶；冬天下过雪 | 拿起门边的竹帚走动就扫，站着按住「扫」也扫；秋天把叶子扫到老梅底下成一堆，冬天从堂前到柴门扫出一条土路 | 第二天叶子又落、雪又积 |
| 风铃 `chime` | 观物亭西南角檐下 | 风起时自己晃、自己响；走到底下点画面抬手拨一拨 | 拨过三下念一联 |
| 柴门（不是一件事） | 院门 | 人（或村里人）走近了两扇柴扉「吱呀」朝院里开，走远了轻轻掩上；读门联时掩着——「闭门即是深山」 | — |

## 怎么写的

- 每一样一个 `acts/*.ts`，导出 `create(k)`；器物与动画在 `play/`：`kit.ts`（state 的写法、每帧的钩子、存档、出声、材质、细线、不动的小器物并块）、`carry.ts`（把行者挂在秋千板、船上的架子）、`pot.ts`、`rod.ts`、`boat.ts`、`kite.ts`、`lantern.ts`、`ripples.ts`（伊水上的水纹）。
- **state** 照界面那一路的约定写（`src/app/acts/state.ts`）：`meter`（表与「合适的那一段」）、`hold`（按住的大键，空格同）、`tags`（钉在画里的签）、`steps`/`step`、`keys`、`count`/`total`、`progress`、`choices`（`main`、`off`、`sub`）。表这一类一秒变十几次的用 `put()`，至多每秒十五次告诉界面。
- **每帧的钩子** `onFrame(k, 名字, fn)` 挂在 `world.tick` 上：各件事是在总装把自己那一帧挂上去之前建的，所以排在总装之前——先把秋千、船、人摆好，总装再走人的步子、摆镜头（手伸到绳上、橹柄上不会差一帧）。不做这件事时它也跑：空秋千慢慢停、风铃自己响、灯笼的火跳、柴门开合。哪一个出错三次就停掉那一个。
- **人挂在会动的东西上**（秋千、船）：`Carrier` 在行者的 root 外面套一层架子，架子的变换是「此刻 × 静止时的逆」。player.ts 照旧把「静止时」的位置写在 root 上，小人按真实的世界位置算脚、袖子的惯性。做完摘掉。
- **镜头跟着动的**（船、纸鸢）：给 `nav.setPose()` 的那个 pose 对象每帧就地改 `pos`/`look`（nav 存的是引用）。纸鸢做着人还能走，就把 `nav.yaw` 设成这个镜头的方位，WASD 的「前」才对。
- **界面上的小补**：投壶、摇橹把 state 的 `kind` 设成 `'pitchpot'`、`'boat'`，界面落在 `.act` 的 `data-kind` 上；`src/app/styles/extra/boatpot.css` 只认这两样：投壶表上的指针不缓动（松手看的就是此刻的力道）、标出的那一段底下「正好」、大键头上一行怎么按的小字、投壶的签不挡手指（按在签上照样是拖着瞄）。摇橹另认 `cmd('steer', 'L' | 'R' | 0)`（按住、松开），界面哪天要在大键旁添左右两枚键就发这个。
- **淡墨点**（`pot.ts` 的 `Dots`）：一张实例化的小方片、永远朝着镜头，画在勾完线之后那一层、自己比深度（被人、壶挡住的那几点不画）。投壶的瞄准线、弧、落点那一圈都是它。
- **伊水的水纹**（`ripples.ts` 的 `Rings`）：方片的 (x, y) 摆到水面的 (x, z)，绕向就反了——从上往下看是背面；原先只画正面，一圈也没画出来过（橹、船尾、打水漂的水纹都看不见），现在两面都画。
- **省绘制**：不动的小器物（壶连同插在里面的十二支矢、灯笼的木盖与提绳）由 `setStatic(k, 'yard', …)` 并成一块（一次绘制）；投壶时矢才单独画（一张实例化的网）。灯笼的纸三盏并一块，各亮各的（纸的着色器在编的时候把「夜色 × 灯光」再乘上每个顶点自己的 `aLit`）。远了不画（风铃 45 米、船 160 米）。钓竿、浮子、鱼、纸鸢、水纹只在做的时候画。

## 出的声（名字给声音那一路；没做的那边自己不出）

## 给别的几路

- **村人那一路（说话、托事）**：`k.play.kiteInTree({ x, y, z }, yaw?)` 在那一点挂一只纸鸢（纸尾随风摆、一截断线垂着），返回 `{ obj, remove() }`——「孩子的纸鸢挂在树上了」的托事可以用它，取下来时 `remove()`。
- **村人那一路（孩子）**：秋千在小女孩（`npcs.swinger`）要来时让出来；她坐上去之前秋千会很快停稳。没有做踢毽子——行者还没有「抬脚」的动作；行者那一路若加一个 `av.kick?.(side)`，踢毽子就可以和孩子们一起做。
- **雪人挡路**：挂在 `k.life.blockers` 里（化了半径归零）；人物那一路若重建这个数组，要把它留着（或给一个加挡路圆的口子）。

## 检查

`KS_URL=http://localhost:3818/world.html node tests/play/games.mjs [id,…] [--shots]`：每一样从几步外走过去、开始、用界面会发的指令从头玩到尾（按下 / 松开、点画面、点签）、看成绩记对了没有、退出后人站得起来能走、身子回到场景里、镜头回到身后、没有这一路的报错；另看柴门开合。截图在 `shots/games/`。
摇橹另验转向：停着按 ← 往左掉头、按 D 往右，摇着按 A 转得比停着快，往左转时画面上船头也在左（左右不反）；在画上拖（触屏那样的指针事件）舵跟着偏、船头跟着转，松手回正；点一下水面，船头往那边转。投壶另验：头一支的提示里说了瞄准、按住、「正好」那段松手，壶上有签、地上有淡墨点，蓄力时空中有弧；第二局故意投大、投小、瞄偏，各说「力大了／远了」「力小了／近了」「偏左」，下一支的提示照着说怎么改。

## 还不够好的

- 秋千坐着蹬：小人没有「伸腿、收腿」，只靠上身前俯后仰；脚是悬着的。
- 摇橹的人侧身站在船尾、两手握着橹柄来回推拉，没有脚下踏步换重心。
- 摇橹在触屏上转向靠在画上拖（或点水面），界面上没有画出左右两枚键；单手拿着手机时，摇与拖不能同时（点水面定了去向再摇可以）。转得比真船快（摇着时一秒二十来度），为的是好操纵。
- 投壶按着时那道弧照着此刻的力道画，看弧也投得中；难处只在松手的那一刻（「正好」那段约一成宽，指针一秒走七成多，约一百五十毫秒）。
- 纸鸢在很高处时镜头仰得很陡，人只在画面下沿一小块；手机竖屏上更明显。
- 打水漂的石子小，远了只看得见水面一圈一圈的纹。
- 投壶的「横耳、横壶、龙首、龙尾、狼壶、带剑、倒中、倒耳」没有做。
- 柴门掩着时门洞里不挡路（走近它就开了）；开着时两扇门扇占的那一条是屋舍那边报的，一直挡着。
