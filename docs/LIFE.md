# 人物与生灵（src/world/life/）

安乐窝里的村人与鸡犬牛鸭、燕雀虫鱼。都在做事，不是摆设；动作从容，远看是画里的小人。

```ts
const life = createLife({ q, season, sfx });   // sfx(shot, { vel, x, z }) 可不给
scene.add(life.group);
life.update(dt, t, { hour, night, rain, snow, player, camera });   // 每帧
life.setSeason(s);
setDynamic(life.blockers);                      // 人与牛挡路（不在场的 r 为 0）
life.npcs.farmer.attend(行者的位置);            // 停下手里的活、转过来；attend(null) 接着干
```

`life.npcs[id]`：`{ id, name, root, avatar?, pos, present, attend }`。`present` 为假是回了家、走远了、或雨天不出门。
行者走到三米以内，不用谁叫，人会手里一顿、抬头看他、点一点头再接着干（坐着的只转头）。

## 走路

脚本只说去哪（`p.go(spot)`），路由 `route.ts` 认：路网是 PATHS 的折点，外加各家门前、甲家院墙的口子、牛棚、槐树两侧的绕行；
从人到路网、从路网到目的地用 walk.ts 的「挡不挡」现查，直着走得到就不绕。最后几步（进村塾、上桥面、绕到桌后入座）在脚本里写明。
同一帧只认一条新路，认过的记着；开场时先把常走的几条认一遍。
改了屋舍的摆法之后：`npx vite-node shots/life/routes.ts` 查路网每一段通不通，`node shots/life/sim.mjs --season=spring` 把一整天走一遍
（谁几点在哪、有没有走进屋舍与水里、脚本有没有出错、出了哪些声）。

## 省

人身都是低档的网（每人约三千二到四千三个三角，一次绘制；手里的东西另算一次）。十九人同时在场时人身共约六万一千三角。
四十五米外隔帧动，九十米外四帧一动，看不见的五帧一动，两百六十米外不画；没人看着时换事是直接到位的。
牲口鸟雀一种一张网（一次绘制），各有各的可见距离（六十到三百二十米）。

## 与别处对得上的数

- `spots.ts` 里凳、桌、船、桥、碓屋的位置是照着 build/ 的做法算的，各写明了出处；那边改了，改这里的一行。
- 梅上的雀：`PLUM_PERCH` 照着 env/flora/plum.ts 把那根横枝重走了一遍（同一粒种子、同样的取数次序）；那边改了枝的画法要跟着改。
- 伊水边的两处（樵夫坐处、白鹭）按画出来的地面（walk.ts 的 terrainY）现算——那张地面在河边比总图的地势低约 0.45 米。
- 秋千：`npcs.swinger` 坐在板心前 0.3 米，脚下垫到板下一个凳高；板若要荡，由外面每帧带着她的 `root` 一起动。
