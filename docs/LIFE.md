# 人物与生灵（src/world/life/）

安乐窝里的村人与鸡犬牛鸭、燕雀虫鱼。都在做事，不是摆设；动作从容，远看是画里的小人。

```ts
const life = createLife({ q, season, sfx });   // sfx(shot, { vel, x, z }) 可不给
scene.add(life.group);
life.update(dt, t, { hour, night, rain, snow, player, camera });   // 每帧
life.setSeason(s);
setDynamic(life.blockers);                      // 人与牛挡路（不在场的 r 为 0）
life.npcs.farmer.attend(行者的位置);            // 停下手里的活、转过来；attend(null) 接着干
```

行者走到三米以内，不用谁叫，人会手里一顿、抬头看他、点一点头再接着干（坐着的只转头）。

## 名册：`src/data/folk.ts`

全村三十四个人都登记在那里：`FOLK: FolkDef[]`，每人 `{ id, name, call, role, age, sex, home, family, temper, likes, plan }`——
名字（村里人怎么叫他）、怎么称呼先生、身份、年纪、住哪家（`SITE.houses` 的 id 或「村外」「渔船」）、家里有谁（别人的 id）、脾气一句话、
喜欢什么（`bag.ts` 的 `ITEMS` id 或几个字），一天的日程 `plan`（四季、晴雨分开写，夜里睡觉也写上）。

**名册就是村里人真的怎么过日子的出处**：people.ts / villagers.ts 里每个人的日程都是 `planNow(id, 钟点, 季, 雨雪)` 给的那一步的 `act`
（那件事的脚本名；没有 `act` 的一步是在家、或不在村里）。所以：

- 改一个人几点做什么、在哪做：只改 folk.ts。
- 添一件新的事：folk.ts 里写上 `act`，脚本那边（people.ts、villagers.ts、chores.ts）写上同名的那段——**两处一起改**。
  名册里有、脚本里没有的，开发时控制台报「名册里 某人 的「某事」没有脚本」，那一步当他在家。
- 不写进名册的只有几样临时的：货郎在茶亭招呼时孩子们跑去看（`gather`）、两位老人真坐下了石头才去看棋、饭还没送到农夫就多坐一会儿、
  大雨大雪天不开学；还有路上碰见了说两句、端茶、递板这些人与人之间的事。

`tests/folk.test.ts` 查名册的形状：每人每个钟点都有着落、家里人彼此对得上、住处是有的。

## 给别处用的接口（说话那一路、村人簿）

```ts
life.npcs[id]   // { id, name, root, avatar?, pos, present, attend, wave, act, doing, def }
planNow(id, hour, season, wet)   // → FolkPlanStep | null（从 life/index.ts 或 data/folk.ts 取）
FOLK, FOLK_BY_ID                 // data/folk.ts
```

- `name` 是名册里的名字（王伯、桂姐、虎子……）；`def` 是名册里这个人的整条。
- `act`：此刻做的那件事的名字（名册 `plan` 里的 `act`；在家、正往家走是 `null`）。
- `doing`：此刻在做什么，人话。名册里这一步的 `doing`；在路上是「正往某处去，……」，站在路上跟人说话是「站在路上和某人说话」，
  收工路上是「收了工，正往家里去」，被临时改了的事（货郎来了）另有一句。
- `present` 为假是回了家、走远了、或雨天不出门；`attend(行者的位置)` 停下手里的活、转过身（坐着的只转头）看着来人，`attend(null)` 接着干。
- `wave(那人的位置)`：远远地招一招手——手里的活停一停、转过身（坐着的只转头）、抬起右手摇两下（约两秒半），再转回去接着干；
  正被叫着、正站在路上和人说话时不招。说话那一路在情分到了「相得」、先生在六到十八米内时一天招一回。
- 名册里 `call` 是他怎么叫先生（多是「先生」，行脚僧是「施主」）；`likes` 用来送礼。

## 人与人之间

- **路上碰见**：走远路的人（去上工、回家、串门）两三步内碰见村里人，互相看一眼、点个头（出家人合十），出一声 `greet`；
  两个都在走远路、又都爱说话（各人的 `chatty`），就站下来说一会儿（五到十一秒）：面对面，一个说一个听，轮着来，有时笑一声。
  碰见的是在干活的人，那人手里一顿、抬头点一点。一家人一块儿出门不寒暄；快走到了（四米内）也不。同一对人两分钟内只招呼一回。
- **一家人同出同归不叠成一个人**：同一个钟点出门的，各人隔一两秒再出门；路上的折点各人略偏一点。
- **送饭**：阿秀把饭篮摆上埂，王伯（与二郎）端碗吃上四五十秒；饭还在路上时，王伯到了钟点也多坐一会儿等着。
- **端茶**：李二嫂扫地的空当端一碗茶到槐树下给公公：递过去，老人伸手来接；她站着比划着说几句，老人一下一下地点头，有时笑一声。
- **说书**：韩翁敲一通鼓，说二三十秒抖一个包袱（拍一下醒木 `wood`），听的人隔零点几秒一齐笑，孩子笑出声（`kidsLaugh`）；夏夜几个老人妇人摇着蒲扇。
- **递板**：小乙扛着板上了桥，赵大正跪在那里钉，他就站着等；赵大钉完一轮起身转过来，两手托住接过去、弯腰放在桥面上。
- **看活**：赵老坐在修桥处看儿子刨板，隔一阵抬手指一指；石头看爷爷下棋；杏儿看娘织布。
- **串门**：刘二姐来了，在路上碰见阿秀先说两句；到了门前把鸡蛋篮放在姐姐脚边，坐下说话，姐姐先做着针线等她。
- 货郎来了孩子们跑到茶亭围着看；客在院里石桌喝茶；樵夫与渔父隔着水说话（照旧）。

## 说话时送东西、接东西（说话那一路：`acts/talk.ts`、`acts/gift.ts`、`acts/favor.ts`）

东西是真的过手的，话与动作对得上：

- **先生送人**（签「带了样东西给你」→ 挑一样）：签上写的是这一回送多少（「鸡蛋 四个」「麦粒 一升」，不是一囊的数）。先生两手从袖里取出一件小器物
  （一篮鸡蛋、一碗茶、一把酒壶、一捆柴、一枝花、一张诗笺……`gift.ts` 现做），离得远就往前走一步（隔着石凳、桌子的，在他身边另找一处站得住的地方绕过去，
  走了一大段的镜头跟着重摆），捧着递过去、身子略俯（他坐着、是孩子就俯得多些，差一点够不着的两个人各自探身）。
  他放下手里的活伸手来接（一只手拿着帚、锄的，用空着的那只手；两只手都拿着东西的，先把右手的放下），**东西到了他手里的那一刻**，
  行囊里才少了、他才记下，面板上先生那句（「这四个鸡蛋，给你。」）与他接的那句一齐出来；递着的那一会儿面板上还是方才那句问话，签先收着。
  然后他点一点头（出家人合十），把东西放好：站着的蹲下放在脚边，坐凳的放在腿上（说完了挪到凳边地上），盘坐、跪着、蹲着的就近放，
  走着路的拎在手里，小东西揣进怀里，姑娘媳妇收了花插在鬓边，孩子收了糖吃了，茶先喝一口，懂诗的人（塾师、客）把诗笺拿起来看一看再收起。
  不肯收的（孩子不收酒、出家人不收荤、王伯不要花）：他抬起空着的手摆一摆、摇摇头，先生收回袖里，行囊里还在。
  够不着的（他在船上）：先生蹲下把东西放在跟前。放在身边的东西留在那里，他换事、回家时收走。
- **他给先生**（熟了回赠、见面塞的、托事讨来的、办成了的回礼）：东西先进了行囊（不浮字），他取出来递过来，先生两手接住、收进腰边的行囊、点头谢过；
  **「得……」在先生接住的那一刻浮出来**。回赠的那句（「先生拿着这个……」）在他递的时候接上。够不着的隔着一点扔过来。
- 托事里「交东西」的那一枚签（「茶来了，趁热」）同样是递到他手里才算交到。
- 说着说着别过、走开：一下子收到头——没递到手的作罢（行囊里还在），递到了的放好，「得……」照样浮出来。

送什么、一回送多少、递过去是什么样子：`src/data/itemUses.ts` 的 `GIFTS`（水、铜钱、没打的麦捆谷穗、带壳的谷子不送人；论升的一回一升）。
同一个文件的 `ITEM_USES` 是行囊里每样东西的「用处」（做什么用、在哪儿用、谁要），行囊页上每样东西下面一句，头一回得到时画面下方也说一句（只说一回，记在存档 `bagSeen`）。
**用处里说「某某爱这个」的，名册里他真的喜欢**；名册里有人喜欢的东西都送得出去（`tests/talk.test.ts` 对着查）。

村人这一边的手（`person.ts`，给说话那一路用；不经村人的脚本）：

```ts
Person.of(npc.root)            // 从 life.npcs[id] 找到他
p.cue = { L, R, look, bow, pose, hands }   // 被叫着说话时，每帧在「把手里的活放稳」（rest）之后照它摆；L / R 给 null 是那只手放回去、交还给活计
p.endCue()                     // 收住：手放回去，蹲下的站起来，合十的放下，放下的活计拿回手里
p.busyHand('R')                // 这只手此刻拿着活计里的东西
p.stowHand('R') / p.unstowHands()   // 两只手都占着时，先把一只手里的放下（藏起来），递完拿回去
```

## 走路

脚本只说去哪（`p.go(spot)`），路由 `route.ts` 认：路网是 PATHS 的折点，外加各家门前、甲家院墙的口子、牛棚、槐树两侧的绕行；
从人到路网、从路网到目的地用 walk.ts 的「挡不挡」现查，直着走得到就不绕。最后几步（进村塾、上桥面、绕到桌后入座）在脚本里写明。
同一帧只认一条新路，认过的记着；开场时先把常走的几条认一遍。
画里一个钟头一分钟（时辰流转的默认快慢）时，走一百米要画里一个半钟头——所以各人的活都安排在离家不远处，远路（下田、送饭）的那几步日程留够了时候；
有人看着才真的走，没人看着就直接在该在的地方。

检查：`KS_URL=http://localhost:<端口>/world.html node tests/play/day.mjs` 把一整天（四季、晴雨）按画里一个钟头一分钟快进着走一遍，
人人当作有人看着：脚本有没有出错、有没有人走着走着进了屋舍器物或深水、有没有人卡住、两个人有没有长时间叠在一起，各截几张图（`shots/day/`）。
改了屋舍的摆法之后还可以：`npx vite-node shots/life/routes.ts` 查路网每一段通不通。

  `follow(人)` 跟着一个有 `pos` 的东西（走着时跟在身后五六步一大群，站下了就在他周围散开吃）、`follow(null)` 就地吃、
  `lead(x, z)` 赶到某处、`graze(x, z, r)` 在一处散着吃；`present`、`center`、`leader`、`count`。
  他把羊赶回圈、交还（`manual = false`）之后，当天不再自己出圈。
- **驴**（农事、村人用）：`tether(x, z, rope)` 拴、`circle(cx, cz, r)` 拉磨（蒙上眼绕着转）、`follow(人)` 牵着走、`stop()`、
  `load('sack' | 'wood' | null)` 驮粮袋、柴；`manual = true` 时不再按时辰自己出入；`bray()` 叫一声；`present`、`pos`。拴着时挡路（一个半径 0.55 的圆）。
- **鸡**（说话那一路的托事「找回走散的母鸡」用）：`stray(x?, z?)` 让乙家那只芦花母鸡走散（不给就自己挑一处：桥头柳下、竹林边、桑园、茶亭、洗衣埠一带），
  返回 `{ x, z }`；`lost` 一直可读：`state` 是 `'none'`（没走散）/`'wander'`/`'held'`（行者抱着）/`'back'`（刚送回去，一直保持到下一次 `stray()`），
  `pos`（`THREE.Vector3`）、`home`（`{ x, z }`，乙家门前那一群）；`onHome` 送回时调一次。
  行者怎么抱：acts/beasts.ts 的「抱鸡」（`henCatch`）——走近了蹲下抱起来（她就地一蹲），抱着走（这件事开着，人照常走），到乙家门前点「放下」。
  `scatter(x, z, n)` 撒一把食，附近的鸡围过来抢（喂鸡那件事、村人喂鸡都用）。
- **狗、猫**（做事用）：`dog.pet('come' | 'lean' | 'belly' | null, 在哪)`，`cat.lure(草梢的位置 | null, 动着没有)`、`cat.pounced`。
- **鸭**：`ducks.herd(on)`（赶鸭时岸上、水里的都往栏口去，不再自己进栏）、`inPen`、`total`、`onBank`、`center()`。
- **鱼**：`fish.feed(x, z)`、`fish.feeding`。**牛**：`ox.eat`（0…1）。
- `fauna.hook`：总装那边接的几样（`ripple` 水面一圈、`splash` 溅水、`note` 浮一句），acts/beasts.ts 开场时接上；没接上就不做。

### 省

- 远近分级：每一种按离镜头的远近（三四十米内每帧、再远隔帧到隔五帧、看不见的偶尔一动、一两百米外不画、时辰被拨过去或远了直接到位）；
  `fauna.ms`（平滑过的毫秒）、`fauna.per`（各种各多少）可以现场看。
- `Parts.cull`：生灵的各块网格按摆着的那些块算包围球，整块不在画面里就不画（`rig.ts`；默认关，生灵这边都开了）。
- 地面高：天上飞的、满田飞的燕子用总图的 `ground()`，不去查行走那张一格一格现算的图。
- 量到的（桌面高档，1280×760，无头 Chrome）：生灵（含两头牛）每帧 0.13–0.80 毫秒（白天 0.6–0.8，夜里 0.13–0.25）；
  生灵自己占的绘制 0–14 次（村里 8、院中 13、观物亭 10、田 6、桃林 8、溪桥黄昏 14、夜里 0–7），三角 0–6.1 万。
  原来那一批生灵不剔除，看得见的十五到十九种每种都画，约 1.7 万三角。

### 还不够好的

- 鸡、狗、猫近看还是几块圆滚滚的小件拼的：没有羽毛、毛的笔触，腿是硬的两节；走路的脚在地上会滑一点。
- 鸭子游水只沿着溪的中线左右偏，碰到石头、桥墩不绕；赶鸭的鸭子不会被篱笆真的挡住（鸭栏的口子是按位置算的）。
- 黄鹂、喜鹊落的枝是按树的位置估的，不在真的枝上，近看会悬在叶丛里（远看是藏在叶间的一点）。
- 松鼠只在两株松的树干上下（树干当成直的），爬进树冠就不见了。
- 鹿只是远景，走不过去；鹤只顺着伊水飞，不落。
- 雪地脚印只给雀、鸡、狗；行者自己走过的脚印不归这里。

## 还不够好的

- 屋都不进去：夜里点灯纺线、读书只看得见塾里的先生与船头的渔灯；各家是窗纸亮着（屋舍那一路）。
