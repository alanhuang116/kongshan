# 安乐窝 · 声音

全部用 Web Audio 现场合成：没有录音，没有采样，不下载任何音频。代码在 `src/audio/`，对外只有一个单例 `audio`（`src/audio/index.ts`）。
每种声音可以在 **/audio-lab.html** 单独听、单独画频谱（开发用，不进正式构建）。

写这些声音的人听不到声音。每一种都是按那样东西怎么发声来搭、在无头浏览器里离线算出来、量过数值、看过频谱图才定的
（`tests/play/audio.mjs`，一百九十七项检查）。**像不像、好不好听，最后要靠人耳**——第十一节列了最该先试听的几样，按把握从小到大排。

这是个安静的地方：环境声的底很低（整个场景的均方根在 −43 到 −35 分贝之间，夜里在屋里只有 −52，雨天在外头 −31 上下），细节来得疏；
玩家自己弄出来的声音（脚步、纸笔、琴）比它高一截，但也都是轻的。

## 一、怎么用

```ts
import { audio } from '@/audio';

await audio.unlock();                                  // 必须在用户的一次点按里调用；之后才出声。可重复调用
audio.setScene(ks.soundscape());                       // 世界把此刻的「现场」交进来：每帧一次也行，一秒四次也行
audio.setListener(p.x, p.z, -Math.sin(yaw), -Math.cos(yaw));   // 听的人在哪、镜头朝哪

audio.play('page', { vel: 0.5 });                      // 一击的声音
audio.play('rooster', { at: [x, z] });                 // 世界里某处出的一声：按听的人的位置自己算左右、远近
audio.play('qin', { pitch: 7 });                       // 抚琴：比宫弦高七个半音（就近落到五声的音级上）
audio.step('grass');                                   // 一步（也认世界那边的叫法：wood、wet）
audio.setLoop('kettle', 1);                            // 一直响着的声音：煮水（0 即停）
audio.duck(0.5, 1.5);                                  // 做事时把环境声压低一半
audio.setGroup('insects', 0.5);                        // 用户音量：虫蛙这一组减半
```

| 方法 | 说明 |
| --- | --- |
| `unlock()` | 建 AudioContext、在手势里 resume；iOS 上把音频会话设成 `playback`（静音拨片拨下时也出声）。没解锁前别的调用只记状态，`play` 直接忽略 |
| `ready` | 已解锁且在运行 |
| `setScene(partial)` | 见第二节。只是记下来，每 0.1 秒合并应用一次；量化之后没变就什么都不做（六百次调用合计不到一毫秒） |
| `setListener(x, z, fx, fz)` | 听的人的位置（一般是行者）、朝向在地面上的方向（一般是镜头的；长度随意）。给了 `at` 的声音据此定左右与远近 |
| `play(shot, opts)` | 一击的声音。选项见第四节 |
| `step(surface?, opts?)` | 一步：`earth` `grass` `stone` `plank` `floor` `water`；也认 `wood`（即 plank）、`wet`（见第七节） |
| `qin(note?)` | 抚琴的一下：不给参数就顺着一条现编的旋律弹下一个音，返回弹的是什么（见第五节） |
| `setLoop(name, level, opts?)` | 一直响着的声音：`kettle` `inkstone` `saw` `plough`（见第六节） |
| `duck(amount, fade?)` | 环境声压低多少（0…1）。只压环境的各层（连同拉锯、犁地、远琴）；一击、煮水、研墨不受影响 |
| `setGroup(group, level, fade?)` / `getGroup` | 用户音量，六组：`wind` 风、`water` 水、`birds` 鸟、`insects` 虫蛙、`weather` 雨雪、`village` 村里。0…1.5，默认 1（＝按场景算出来的原样） |
| `setExtra(layer, level, fade?)` | 另开的层：`qin` 远远的几声琴（现编的，默认 0）；`chant` `bellfar` `eaves` 是旧的（见第十二节） |
| `setLayer(layer, level, fade?)` / `getLayer` / `getEffective` | 旧的九层名字：`wind` `birds` `stream` `rain` `insects` 现在是上面那几组的别名（stream→water、rain→weather），其余四个同 `setExtra` |
| `setAuto(false)` | 关掉场景自己带出来的环境声（只剩一击、loop 与另开的层） |
| `setMaster(v)` / `setMuted(b)` | 总音量（默认 0.8）、静音 |
| `keepAlive(on)` | 页面到后台也别停（默认隐藏就挂起、回来恢复） |
| `engine` | 调试、试听台用 |

导出的清单：`SHOT_NAMES`、`SHOT_GROUPS`、`BED_NAMES`、`GROUP_NAMES`、`LOOP_NAMES`、`GROUND_NAMES`、`NEAR_KEYS`、`LAYER_NAMES`（旧九层）、`EXTRA_NAMES`；
两个小算式 `nearOf(d, R)`、`bearingOf(dx, dz, fx, fz)`；`QinMelody`、`QIN_OPEN`；`renderOffline`（离线渲染）。

## 二、场景：`audio.setScene`

世界把此刻的「现场」整份交进来，二十三层环境声各自算出该有多少、按各自的快慢渐变过去。形状与 `Anlewo.soundscape()` 给的一致：

```ts
audio.setScene({
  place,                      // 人在哪一处：grove bridge yard hall pavilion fields village ferry
  hour,                       // 0–24
  night, dawn, dusk,          // 0…1：Atmos.night / dawn / dusk（不给就按 hour 与 season 自己算，算法与 Atmos 相同）
  season,                     // spring summer autumn winter
  rain, snow, mist,           // 0…1：Atmos.w.*（渐变着的）。不给就看旧的 weather
  wind,                       // Atmos.wind 的原值（平日 0.03–0.19，雨天到 0.34）
  indoor,                     // 0 室外 … 1 屋里（草堂 1，观物亭 0.2 上下）
  near: { stream, pond, river, waterfall, bamboo, pines, grove, fields, village, school, work, mill },   // 各 0…1
  bearing: { stream: -0.6 },  // 可选：各样东西在人的哪一边，−1 正左 … 1 正右
  focus,                      // 可选：正凝神听什么——'cicada' / 'rain' / null
  storm,                      // 可选：雷雨 0…1，大于 0 时雨层自己隔一阵排一声远雷
});
```

只给变了的几项也行（`near`、`bearing` 是一项一项并进去的）。旧的写法 `{ hour, weather, season, indoor, water, height }` 也还认。

### `near` 怎么算

`near.x` 是「离那样东西有多近」：**在它跟前（或里面）是 1，远到听不见是 0，中间按距离线性落下去**。
`nearOf(d, R) = clamp(1 − d / R)`，`d` 是到那样东西最近一点的米数（在里面给 0），`R` 是听得到的半径。混音时再各自乘方（见下表），所以世界这边给线性的就好。

| 键 | 到什么的距离 | 建议的 R | 驱动哪些层 |
| --- | --- | --- | --- |
| `stream` | 溪岸 | 25–45 米 | 溪；雨落在水上的声音；蛙 |
| `pond` | 池岸 | 16–30 米 | 池；蛙；雨落在水上 |
| `river` | 伊水的岸 | 120 米 | 河（远远的橹声）；蛙 |
| `waterfall` | 瀑布 | 两三百米，最大给到 0.6 就够（它是远景） | 瀑 |
| `bamboo` | 竹林的边 | 30–40 米 | 竹风；鸟、蝉、蟋蟀多一些；雨打叶 |
| `pines` | 最近的松 | 15–25 米 | 松风 |
| `grove` | 桃林（也算桑园、柳：阔叶的树） | 30–40 米 | 叶声；鸟、蝉；雨打叶；雨后叶上的滴水 |
| `fields` | 田 | 40–70 米 | 野风；蛙、蟋蟀；牛 |
| `village` | 邻家（屋、大槐树、井） | 60–70 米 | 鸡犬的远近（见「村里」）；燕；蝉 |
| `school` | 村塾 | 45–70 米 | 书声 |
| `work` | 修桥的地方 | 50–60 米 | 锤、锯、刨 |
| `mill` | 水碓 | 40–60 米 | 水轮的泼水与吱呀 |

没给 `near` 时，按 `place` 取一份大概的（`scene.ts` 的 `PLACE_NEAR`）——够用，但走动时是一格一格跳的，所以世界最好自己算。
给了 `near`，没列出的键当作 0。

### `bearing`、`focus`

- **`bearing`**：溪在左手边，溪声就偏左（最多偏六成，回声不偏）。`bearingOf(dx, dz, fx, fz)`：`(dx, dz)` 从人指向那样东西，`(fx, fz)` 是镜头朝向。
  不给就都在正中。没给过方位的层不会为它多建节点。
- **`focus`**：观物亭里「听蝉鸣」「听雨」时给 `'cicada'` / `'rain'`。那一层在三秒里提上来 **+7.6 分贝**（陪着它的——听雨时的檐滴——提 3 分贝），
  别的环境声退 7.5 分贝；回到 `null` 再三秒里还原。也认 `stream` `birds` `frogs` `crickets` `bamboo` `pines` `river` `waterfall` `recite` `snow`。
  那一层此刻并不在响（春天要听蝉）时，什么都不动。不认得的名字当作没有。

### 各层跟着什么走

每一层的量 ＝ 下表的算式 × 用户那一组的音量 × 这一层的校准（`TRIM`）。「渐变」是这一层换到新的量大约要多久。
表里的「风」＝ `Atmos.wind ÷ 0.25`，封顶 1（平日 0.1–0.75，雨天到顶）；没给 `wind` 时按晴雨自己估一个。算出来不到 0.035 的层当作没有，不建。

| 层 | 组 | 多少 | 渐变 |
| --- | --- | --- | --- |
| `air` 气 | wind | 一直有；0.45 + 0.55·风；冬天 ×1.3 | 4 秒 |
| `pines` 松风 | wind | near.pines^1.2 × (0.3 + 0.7·风) | 2.4 秒 |
| `bamboo` 竹风 | wind | near.bamboo^1.2 × (0.25 + 0.75·风) | 2.4 秒 |
| `leaves` 叶声 | wind | near.grove^1.2 × (0.2 + 0.8·风)；冬天 ×0.2（叶落了） | 2.4 秒 |
| `fieldwind` 野风 | wind | near.fields^1.1 × (0.25 + 0.75·风)；冬天 ×0.6 | 3 秒 |
| `brook` 溪 | water | near.stream^1.5；冬天 ×0.8，雨后水大 ×1.2 | 1.5 秒 |
| `pond` 池 | water | near.pond^1.3；冬天 ×0.35 | 2.5 秒 |
| `river` 河 | water | near.river^1.3 | 3 秒 |
| `waterfall` 瀑 | water | near.waterfall^1.2；夏天 ×1.1，冬天 ×0.6 | 4 秒 |
| `birds` 鸟 | birds | 有鸟就是 0.55–1（疏密另算，见下）；夜里、雨里是 0 | 6 秒 |
| `swallows` 燕 | birds | 春夏的白天；早晚最勤；雨里不飞；要有檐、村、田或水 | 6 秒 |
| `geese` 雁 | birds | 秋天（入冬还有零星）；晨昏与夜里；雨天不过 | 8 秒 |
| `cicadas` 蝉 | insects | 夏天的白天（上午渐起，午后最盛，傍晚收），初秋剩两成；雨一来就停；树多处响些 | 9 秒 |
| `frogs` 蛙 | insects | 暖的夜里：夏 1、春 0.4、秋 0.12、冬 0；黄昏先起；要离池、溪、田、河近 | 9 秒 |
| `crickets` 蟋蟀 | insects | 夜里：秋 1、夏 0.8、春 0.25、冬 0；秋天白天也有一点；雨夜少 | 9 秒 |
| `rain` 雨 | weather | ＝ rain | 3 秒 |
| `drips` 檐滴 | weather | max(0.75·rain, 湿) × (0.3 + 0.7·有檐或有树) | 4 秒 |
| `snow` 雪 | weather | ＝ snow | 6 秒 |
| `night` 夜 | wind | ＝ night；雨夜减半 | 10 秒 |
| `village` 鸡犬 | village | 一直「在」（雨雪天轻一些）；各样的远近在层里按 near.village 算 | 4 秒 |
| `school` 书声 | village | near.school^1.3 × 上学的钟点（只有上午：7:00–11:00，与世界里孩子们的作息一致；下午他们在外头玩）；雨里照念 | 2.5 秒 |
| `work` 修桥 | village | near.work^1.2 × 干活的钟点（7:30–11:40、13:00–17:25，与世界里木匠的作息一致）；下雨下雪就收工 | 2.5 秒 |
| `mill` 水碓 | village | near.mill^1.3；冬天 ×0.7。日夜不停 | 2.5 秒 |

- **鸟的疏密**（同时在场几只、叫得多勤）：黎明的合唱在**日出后一刻**到顶（春天 6:09），天没亮透就有头几声；往午间稀下去（7 点 0.57 → 正午 0.23）；
  傍晚归巢稍起；夜里没有。雨里不叫（按 (1 − rain)^1.5），雪天几乎没有，雾天少三成；春 1.15、夏 0.6、秋 0.4、冬 0.2；树多的地方多。
  最密时同时四只，一只鸟隔六七秒叫一回。布谷只在春夏、同时只有一只、十几只里才轮到它，一叫是连着几声然后歇很久。
- **鸡鸣属于清晨**（晨 0.12 以上才一阵一阵地叫），白天隔几分钟偶尔一声。离村远（桃林里、自家院里）也听得见，只是远——「清晨……听邻家鸡鸣」。
- **湿**：引擎自己记着。下着雨就涨（约 20 秒涨满），雨停后约两分钟慢慢干：檐滴越滴越慢，脚步里的「咕唧」也跟着它。
- **屋里**（indoor）：外头的各层过一道低通（18kHz → 2.2kHz）并降到一半；草堂开着门窗，不像大殿隔得那么死。雪天整个天地再闷一些。
- **一阵风**：引擎每 14–38 秒（风大则更勤）发一次「一阵风」，气、松、竹、叶、野风各自涨起来再落下去；竹林里跟着有一两声竹竿相碰。

### 世界自己放了同一种声音时

村里、书声、修桥这三层是「没人管的时候自己来」的。世界若自己 `audio.play('recite' | 'hammer' | 'saw' | 'plane' | 'rooster' | 'hen' | …)`
（村塾里的孩子、匠人、那只看得见的鸡跟着各自的动画出声），对应的层就让开一阵：书声 10 秒、锤锯 30 秒（匠人刨完要走到桥上去钉，中间十来秒没声）、鸡鸣 45 秒、别的禽畜 30 秒。
所以两种接法都行，也可以混着用：世界只管看得见的那几个，其余的由层补上；不会两头各念各的。

- **远得听不见的不算**：世界那一声传到耳朵里不到它在身边时的三成，层就不让——人在桃林里，村里那只鸡的动画照旧在叫，可是太远，这时候听见的是层里那只「远处的鸡」。
- 外头有一声听得见的鸡鸣（世界里那只、或玩家醒来时那一声），过三五秒，层里远处另一只有一半的时候应它。
- 现在的世界里（有「人物」那一块时）书声、锤刨、鸡鸭犬牛都是世界自己叫的，这三层实际只在它叫不到的地方、或那一块没装上时出声。

## 三、环境的各层

「节点」是这一层常驻的 Web Audio 节点数（一下一下的声音另算，响完即拆）。量出来的数见文末的表。

| 层 | 是什么、怎么做的 | 节点 |
| --- | --- | --- |
| `air` 气 | 到处都有的一点低低的风身——免得四下里是「数字的」死寂。一路粉噪声分三条：低处（80–380Hz）、中间一条游走的带（380–900Hz）、冬天才有的细细一线啸（风过枯枝茅檐，800–1500Hz 的窄带） | 9 |
| `pines` 松风 | 松涛：左右各一路粉噪声过带通，中心在 450–1100Hz 之间、响度在 0.35–1.1 之间各自游走；针叶极细的一层（3.4kHz）。风紧了整片涨起来，音高也扬上去（最多小半个八度） | 13 |
| `bamboo` 竹风 | 竹叶又干又硬：一段**有颗粒的噪声**（白噪声乘上每秒三十八个点的随机包络——许多叶子各自在碰）过 2.6–3.8kHz 的带通，左右各一路。没风时轻轻的，一阵风来涨到三四倍，竹竿相碰「笃」的一两声（空的：共鸣在 380–620Hz 及其 2.3、4.1 倍），风大时偶尔吱一声 | 15 |
| `leaves` 叶声 | 桃、桑、柳这些阔叶：比竹软、比竹低（1.8–3.2kHz），响度每秒变三四回——叶子是一阵一阵翻的 | 11 |
| `fieldwind` 野风 | 田上没有遮拦：左右各一路（1.9kHz 上下的「唰」），风浪推过去时一边先响、一两秒后另一边才响；底下一层旷野里的低风 | 14 |
| `brook` 溪 | 清浅的溪水过石头。白噪声过四条窄带（520、880、1420、2300Hz，Q5），中心一秒摆四五回、响度各自一隐一现——「汩汩」；褐噪声的一层身子；**一片水泡**（预先算好的 7.3 秒，每秒四十来个，每个是很快衰减、略往上滑的正弦）两路不同快慢地放；最高处一点亮。**近则明**：整层过一道低通，离得远（near 0.3）截在 1.7kHz、只剩低低的潺潺，走到水边开到 12kHz，泡声与亮才出来（频谱重心从 1.1kHz 到 2.0kHz）；水边偶尔一颗特别清楚的水珠 | 24 |
| `pond` 池 | 屋后小池几乎是静的：岸边极轻的一点水声（两条窄带各自慢慢起伏）；隔 5–16 秒鱼唼一下水面；隔 35–90 秒，暖的时候是蛙或龟滑下水（`plop` 的 frog / turtle），别的时候是鱼翻一下，后面跟一圈涟漪 | 5 |
| `river` 河 | 伊水宽而缓：低而宽的一片（95–480Hz，慢慢起伏）；岸边每 2–5 秒慢慢地一拍（起得慢、落得慢，左右不定）；白天隔 25–70 秒远远一声橹（`oar`） | 8 |
| `waterfall` 瀑 | 远处的瀑布：低而稳的一片轰（70–420Hz 为主，520Hz 上下另有一层，小喇叭才听得见），整片的响度隔十来秒一呼一吸；近一些才有水雾的「沙」 | 11 |
| `birds` 鸟 | 见下 | — |
| `swallows` 燕 | 一只燕子掠过：6–14 个又细又急的短音（3.2–5.6kHz），从一边到另一边；三成半的机会末尾带一串更密的「唧唧唧」。隔 4–13 秒一回（燕多则勤） | — |

**鸟**（`birds`）同时在场零到四只。每只是一种叫法、一个固定的音高与方位、远近，而且有它**自己的那一句**——生成一次，之后每回都唱这一句，只在快慢轻重上略有出入（真的鸟就是这样）；

| 山雀 `tit` | 一高一低地来回——「吱呗、吱呗」 |
| 斑鸠 `dove` | 「咕咕——咕」，低而圆（470–520Hz），远 |

## 四、一击的声音：`audio.play(name, opts)`

通用的选项：

| 选项 | 说明 |
| --- | --- |
| `vel` | 力度 0…1（默认 0.7）：轻重与明暗，0.25 时还有一半的量。**0.25 以下（又没给 `dist` / `at`）不再是「更轻的一下」，而是「更远」**——见下面「世界把远近折进力度里时」 |
| `pitch` | **半音**：0 是原样，12 高一个八度，可以有小数（`qin`、`pour` 另有讲法，见各条） |
| `pan` | 声像 −1…1 |
| `at` | 世界里的位置 `[x, z]`。给了就按 `setListener` 的位置与朝向自己算 `pan` 与 `dist`；各种声音传多远见 `RANGE`（笛 320 米、犬 240、鸡鸣 160、水碓 130、拨浪鼓 130、书声 110、捣衣 110、锤 100、母鸡 45……没列的 36 米），超出就不出声 |
| `dist`（又名 `far`） | 远近 0…1：0 就在身边，1 远到快听不见。越远越轻（到 1 时剩百分之七）、高处越少（低通从 16kHz 落到 900Hz）、回声略多 |
| `dur` | 秒：一笔、一帚、注水、研墨、拉锯、犁、雷、风……有长短的声音用 |
| `variant` | 同一种声音里的哪一样（见各条） |
| `space` | `open` 野外 / `room` 草堂里（小屋，余响 0.3 秒）/ `near` 贴近（几乎全干）/ `hall` 旧：大殿。不给就按场景的 `indoor` 定 |
| `delay` | 延后多少秒 |

**本来就是远远听的几样。** 什么都没说（没有 `dist`、`at`、`pan`，力度也不小）时：`dog` 按 0.7、`rooster` 按 0.6（邻家的鸡）、`cuckoo` 0.75、`flute` 0.6、`goose` 的 wild 0.8。
知道位置时照位置，但牧笛、布谷、天上的雁总隔着一段（最近也是 0.35 / 0.5 / 0.6），走到跟前也不贴着耳朵；犬与鸡没有这个下限——跟前那条狗没说 `variant` 就是轻轻一声「呜汪」。
`variant: 'far'` 对任何声音都是「远处的那一个」（至少 0.8）。明说了 `dist` 的一律照它的。

**世界把远近折进力度里时。** 现在的世界（`Anlewo.sfxAt`）不把位置传下来，而是把力度除以 `1 + (米数 ÷ 9)²`、左右另给在 `pan` 里。
照字面办，三十米外什么都听不见了——鸡鸣、牧笛、捣衣、书声本该传出去一两百米。所以引擎把 **0.25 以下的力度倒推回大概的距离**
（按原力度 0.6 算：0.25 ≈ 11 米，0.05 ≈ 30 米，0.01 ≈ 70 米，0.003 ≈ 125 米），再按这样声音能传多远（`RANGE`）去衰减、去高、加回声：
同是 0.01，鸡鸣还清清楚楚（峰值 0.06 上下），放盏的一声早就没有了。倒推的距离有两三成的出入（各样声音原本的力度在 0.3–0.9 之间），够用。
更准的办法是世界直接给 `at: [x, z]` 与没折过的力度——两种都认，见文末「给世界的话」。

| `rattle` 拨浪鼓 | `dur` | 货郎的拨浪鼓：柄一搓，两颗小槌一左一右打在两面鼓皮上——「卜楞、卜楞」，每一搓两下，搓四到六回（默认 0.6–1 秒）。两面鼓皮音高差一点 |
| `swing` 秋千 | `dur` | 荡一个来回（默认两秒半）：绳子与横枝吃住劲时「吱——」的一声，荡回来又是一声，低而慢 |
| `oar` 橹 | — | 摇一下橹：木头在橹桩上「咿——呀」两声（一扬一落），接着橹叶拨开水的一口气，几个泡 |
| `net` 撒网 | — | 网落在水面上湿湿的一「唰」，底下一拍，随后一片细碎的水珠 |
| `flap` 扑翅 | — | 鸡扑腾两下、鸭抖抖翅膀、鸟从枝上飞起：三到五下又软又快的「扑」（翅膀扇起来的一小口风，500–700Hz，没有音高），一下比一下轻 |
| `chirp` 啾 | — | 一只小鸟一到三声短的啾（3.3k→4.6kHz 一扬一落） |
| `tumble` 麻雀滚落 | — | 两只麻雀吵着吵着打着滚落下来：一阵很急的扑翅，上头是又密又急的啾，末了落在地上轻轻一「噗」 |
| `thresh` 打谷 | — | 连枷的一下：拍子打在铺开的谷穗上——干而闷的一「啪」（400Hz 上下），场地低低地一应，谷粒谷壳溅开又落下的一小阵沙。一下一下由世界去叫 |
| `laugh` 孩子笑 | — | 三到五声短的「哈」，一声比一声低、一声比一声轻，带着气声（嗓子与书声同一类做法） |
| `cluck`、`quack` | 同 hen、duck | 别名：就是 `hen`、`duck` |

**书声怎么做的**（`recite.ts`）。要像、要可爱、不要瘆人，靠的是这几样：

- **调子**：孩子念书是「唱读」——每字一拍（0.3–0.35 秒），在三四个音上高高低低：徵（D4）、角（B3）为主，上到羽（E4），句末落到角或商（A3）；一句的末一个字拖长到两拍多。
  上句悬着（落在徵、羽，微微上扬），下句落下来（落在角、商，往下滑）。G 宫五声，明亮，不用小调。
- **字**：按真的课文的读音走——《千字文》《论语·学而》《关雎》、孟浩然《春晓》、程颢《春日偶成》（邵雍的邻居）。字头按声母给一个凹陷（塞音收得紧、鼻音收得浅），
  咝音里加一小段噪声，韵母里的元音依次滑过去，鼻韵尾把口腔收小；每个字还带着它的**声调**——阳平往上挑、上声一沉、去声往下落（唱读里是收着的，只有说话时的六七成）。听不清字，听得出「在念书」。
- **不齐**：四五个孩子各有各的脾性——头一个总抢一点，第三个总慢半拍；各自偏高偏低二三十音分，音高上一直有一点不规则的晃（几个人合起来才不会拍出规则的「嗡嗡」）；收尾有早有晚。
- **嗓子**：每个孩子是一个锯齿波，起字时音高从下面一点滑上来；分两拨各过一组孩子的共振峰（比大人高两三成）。

### 天上

| 名 | 选项 | 是什么、怎么做的 |
| --- | --- | --- |
| `thunder` 远雷 | `dist`、`dur` | 只做远的——长长的一滚，没有近处那一声炸。`dur` 这一滚多长（默认 6–9 秒），`dist` 远近（默认 0.7；越远越低、越慢、越轻）。底是褐噪声过 200Hz 上下的低通，另有 300–400Hz 的一层「隆隆」（小喇叭放不出最低的），都乘同一条一浪低过一浪的包络 |
| `gust` 一阵风 | `dur`、`variant` | 一阵风穿过树（默认四秒上下），从一边吹到另一边：风身先到，叶声跟着涨起来再落下去。`leaf` 阔叶（默认）/ `bamboo` 竹 / `pine` 松 |

`tick`（最轻的一下：两片竹木相碰）、`open`（纸页往上的一声）、`close`（往下的一声）。

## 五、抚琴

每个音都是现算的一段波形（Karplus–Strong 拨弦，见 `qin.ts` 文件头）：指肉拨弦的激励、低弦暗高弦亮的环路、延迟线长度随时间变出来的绰注吟猱，泛音另算；出来以后过「琴身」。
定弦是正调，以 G 为宫：一弦 D2、二弦 E2、三弦 G2、四弦 A2、五弦 B2、六弦 D3、七弦 E3（徵 羽 宫 商 角 徵 羽）。同一根弦再弹，前一个音就止住。**一下就是一个音（或一个小句）。**

三种叫法：

1. **只给 `pitch`**（世界里的活动这样叫）：`audio.play('qin', { pitch: 7, vel })`——比**宫弦（三弦的散音 G2）**高几个半音（给了 `string` 就是比那根弦的散音高）。
   不管给的是几，都**就近落到五声的音级上**：落在七根弦的散音上就弹散音，再高就是按音（带一点绰、吟）。`variant: 'harmonic'` 则弹成泛音。
   0、2、4、7、9、12……（宫 商 角 徵 羽）正好都在调里；6 会落到徵上。
2. **不想管弹什么**：`audio.qin()`——顺着一条现编的旋律弹下一个音（一句三到六个音，句首多是低处的散音，中间按音居多，偶尔一个泛音，句末多落在宫音上）。
   返回 `{ tech, string, step, … }`，界面要画哪根弦在颤可以用它。
3. **说清指法**：`audio.qin({ tech, string, … })` 或 `audio.play('qin', { tech, string, … })`：

| `tech` | 是什么 | 别的选项 |
| --- | --- | --- |
| `open` | 散音 | `string` 第几弦（1–7） |
| `press` | 按音 | `string`、`step` 在这根弦上往上数几个五声音级；`slide` 起音从几音分之外滑入（负是从下方，绰）；`vib` 吟；`glide` 弹完滑到上 / 下一两个音级（走音） |
| `harmonic` | 泛音 | `string`；`step` 0 是二倍音（七徽），1 是三倍音，2 是四倍音 |
| `cuo` | 撮（与高八度同弹） | `string` |
| `gun` / `fu` | 滚（从 `string` 往低弦连拨四到六根）/ 拂（往高弦） | `string` |
| `phrase` | 一个现编的小句（三四个音） | `string` 从哪根弦附近起 |

远远的几声琴（不是玩家弹的）是另一层：`audio.setExtra('qin', 0.5)`。

## 六、一直响着的：`audio.setLoop(name, level, opts)`

`level` 0…1，0 即停；`opts`：`pan`、`dist` 或 `at`（世界里的位置）、`fade`（秒）。

| 名 | 是什么 |
| --- | --- |
| `kettle` 煮水 | 茶炉上的一壶水：坐上去二十几秒后滚开，之后一直滚着；关掉再开是重新烧。先是壶底极细的一点响（蟹眼）；嘶声渐渐起来、中心越来越低——「飕飕欲作松风鸣」；将开时细泡密了（鱼眼），壶身低低地鸣；滚开之后嘶声反而退一些，换成一串串「咕嘟」的大泡 |
| `inkstone` 研墨 | 一圈接一圈 |
| `saw` 拉锯 | 一推一拉 |
| `plough` 犁地 | 一段接一段 |

煮水、研墨是玩家手上那件事自己的声音：不过「屋里」那道低通，也不被 `duck` 压低。拉锯、犁地在外头，当环境声待。

## 七、脚步

`audio.step(surface, opts)`，或 `audio.play('foot', { ground, wet, vel })`。布鞋，慢慢走（每秒一步半上下）：没有鞋跟的「嗒」，只有脚跟一闷、脚掌一闷（相隔 65–100 毫秒），
外加脚下那样东西自己的声音。每一步都不一样（音高、轻重、两下之间隔多久都在小范围里随机）。一步本身 0.15–0.25 秒。

| `ground` | 样子 |
| --- | --- |
| `earth` 土路 | 两下闷的（200–280Hz、340–460Hz），脚掌落下时轻轻一「扑」，带一点土粒的沙 |
| `grass` 草 | 落脚更软，草叶被拨开又合上的一阵窸窣 |
| `stone` 石板（桥） | 比土硬一点，脚掌有清楚些的一「拍」 |
| `plank` 木板 | 板子自己有一个低的共鸣（105–140Hz、290–350Hz）；隔几步轻轻吱一声 |
| `floor` 屋里的夯土地 | 干、短、闷，几乎没有沙 |
| `water` 浅水 | 一溅，带一两个泡 |

- **地湿**：`wet` 0…1，不给就看场景（正下着雨、或雨后还没干）。湿了脚下多一点「咕唧」，沙少一些。
- `step()` 也认世界那边的叫法：`wood` 即 `plank`；`wet` 是「脚下是湿的」——真踩在水里（`opts.wading`）是 `water`，否则是湿了的土路。
  没说 `wading` 时：正下着雨或雨刚停就当是湿地，不然就是水。
- 脚落地的那一闷用的是带通，不是低通：低通过的粉噪声力气全在一百赫兹以下，笔记本的小喇叭放不出来，等于没有脚步声。
- 旧名 `step`（＝没说踩在什么上的一步）、`woodstep`（＝ plank）还在。

## 八、总线、远近、空间

```
一击 ─ [力度太小则淡出] ─ [远近：衰减 + 低通] ─ [声像] ─ 干 ─────────────┐
                                              ├ 送「草堂」（0.3 秒，暗）───┤
                                              └ 送「野外」（很薄的散尾）───┤
环境的各层 ─ [方位] ─ 屋里的低通 ─┐                                        ├→ 汇总 → 总音量 → 压限 → ×0.69 → 软限幅 → 输出
远琴 ─────────────────────────────┴ 压低（duck）─┬ 55Hz 高通 ─────────────┘
煮水、研墨（不压低）──────────────────────────────┘
```

- **野外**的混响（`openIR`）：田园里没有墙，声音几乎是干的——只有一层很薄、很散的尾（约 1.1 秒），外加北边山脚三道很轻、很闷的回声（0.2 秒之后才到）。
  默认只送一成半，远处的声音多送一点。（空山那一版是「山谷」：七道清楚的回声，放在平野上不对——柴门一响后面跟着一串「啪啪啪」。）
- **草堂**的混响（`roomIR`）：小屋，土墙茅顶都吸声，约 0.3 秒。`indoor` 越大，一击的声音送它越多、送野外越少。
- 压限器（阈值 −14dB、比 3）与末级软限幅（0.62 以下原样，最高约 0.89）：平时碰不到；最坏的组合（雷雨、各组开到最大、鸡鸣锤雷琴一起来）峰值 0.80，不削波。
- 调音以 G 为中心：琴、笛、孩子念书的调子都在 G 宫五声里，碰在一起不打架。

## 九、省不省

声音线程每秒要把图里的每个节点算三百七十五回，**节点数就是开销**（实测一个常驻节点约占桌面机一个核的万分之六到八）。所以：

- **各层是懒建的**：场景算出来该响了才建，量到 0 之后过一会儿就拆。回声那一路、偏左偏右的声像，谁真用到才建。
- **不为「慢慢变」建节点**：各条带的中心、响度的游走是排程时顺手排的渐变（`Base.roam`），不另建「调制源 + 增益」。
- **颗粒、开合算进波形里**：竹叶的颗粒、蝉的鼓膜、蟋蟀的一组一组、一片水泡、一片雨点、一滴水，都是算好的一小段循环着放。
- **滤波器与层里的增益按「每 128 个样本一个值」算**（k-rate）：这张图里没有哪个滤波器要逐样本地变，默认却是逐样本重算系数——单这一条省了一成多。
- **一击的声音响完就拆线**；同时在响的一击有上限：层里自己排的超过 22 个就先不出，玩家与世界触发的到 40 个才拦。
- 修桥的一阵锯是一下一下到点才建的，不一口气建几十个；层里的滴水（檐滴、溪里的水珠）放的是一小段算好的波形，三个节点。
- **场景给一层的量不到百分之三四就不建它**（比给满时低近三十分贝，听不见）。

实测（桌面 Chrome，`tests/play/audio-cpu.mjs`：真的 AudioContext，量渲染进程用掉的处理器时间，减去「什么都不响」时的底）：
一个场景约占一个核的 **百分之三到六**；村里书声加修桥最忙时到七到九；走路、抚琴、煮水同时来约百分之十。表在第十节末。
这一轮省下来四成上下（头一版同样的场景是百分之七到十）。手机没有实测过，按单核慢三四倍估——再要省，先砍的是同时在场的层数。

## 十一、请先用耳朵试听的

没有人听过这里的任何一个声音。结构、节奏、频谱、响度是量过的；音色像不像，按把握从小到大：

1. **书声**（`recite` / `school`）：字的节奏、声调、句读、不齐都在，频谱图上看着像说话。但锯齿波加共振峰的嗓子天生有点「瓮」、有点像声码器；
   会不会像孩子、会不会瘆人，只有耳朵知道。不对的话先试：把 `school` 那层的低通再压低（更远更糊，只剩节奏）、把 `recite.ts` 里的 `out.gain` 调小、孩子减到三个。
   `variant: 'lead'`（先生领读）是一个单独暴露的大人嗓子，把握更小，层里没有用它。
2. **禽畜的嗓子**（鸡、鸭、鹅、犬、牛、猫、雁）：音高的走法是照真的叫声定的（鸡鸣的四段与破音在频谱图上很清楚），但共振峰是固定的几个，听着可能像哨子、像卡通。
   猫和犬最没把握；鸡鸣、鸭把握大些。
3. **吱呀**（柴门、辘轳、橹、秋千、水碓的轮轴、犁、竹）：粘滑是一个很慢的锯齿波去激木头的共鸣。频率低了会像「噗噗」的放气声，高了像吹口哨——现在的数是估的。
4. **鸟**：单个振荡器走音高的鸟叫容易显得「电子」（已经加了音高上的细抖、麻雀加了调频、各鸟有自己的句子）。斑鸠用的三角波，高处的谐波可能偏多。
5. **笛**：结构简单，把握较大；气声与揉的分量是估的。
6. **蝉**：重心 4.7kHz，6kHz 以上占一成——是「不刺」的，但会不会听着只是一片嘶嘶的噪声、不像蝉，要听。蟋蟀（纯音的小包）把握大。
7. **竹风**（6kHz 以上占三成）与**雨**（两成）：是这里最亮的两样，长时间听会不会累要试；嫌亮就把 `Bamboo` 的带通再往下挪、`Rain` 的雨幕再压。
8. **雷**：小喇叭上只听得见 300Hz 上下那一层，会比耳机里单薄得多。瀑、河、夜的底、气也是低处的东西，小喇叭上本来就近乎没有。
9. **整体的响度关系**：环境声与一击之间差多少、各层之间的比例，是按数值定的（`scene.ts` 的 `TRIM`）。
10. **琴**：Karplus–Strong 天生偏吉他 / 筝；已经压暗、加了琴身与吟猱，但离真琴的「松沉」还有距离（这是原有的）。
11. **最后添的五样**（`flap` `chirp` `tumble` `thresh` `laugh`）：只量过响度与频谱重心，没有看过频谱图。孩子的笑最没把握——合成的笑声最容易显得怪，不对就先把它在世界里的力度调小。
12. **倒推出来的远近**（世界把远近折进力度里时）：各样声音在几十米、一百米外有多响是按数算的，没有人对着画面听过——嫌远处的鸡鸣、锤声、书声太显或太弱，改 `types.ts` 里的 `RANGE`（能传多远）最直接。

## 十四、给世界的话（声音这边不能改 `src/app`、`src/world`，接法上还可以更好的几处）

现在的接法已经能用（`src/app/sound.ts` 调的每一个函数都在，世界叫的每一个名字都有声音）。下面几处改了会更准：

1. **位置直接交过来。** `Anlewo.sfxAt` 现在把力度除以 `1 + (d/9)²`、另算 `pan`。改成原样往下传 `{ vel, x, z }`（不折力度、不给 `pan`），
   `sound.ts` 就会把它变成 `at: [x, z]`，由引擎按各样声音能传多远去算——不用再从力度倒推距离，左右也跟着镜头转。
2. **`near.mill`** 还没有：`soundscape()` 里补上（到水碓的距离，40–60 米内 1→0），水轮那一层才会响；碓头落下时叫 `millThump`。
3. **雷雨**：`soundscape()` 里给 `storm: 0…1`，雨层就自己隔一阵排一声远雷；或者世界自己在闪电后叫 `thunder`（`dist`、`dur`）。
