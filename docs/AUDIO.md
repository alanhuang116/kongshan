# 空山 · 声音

全部用 Web Audio 现场合成，不下载任何音频。代码在 `src/audio/`，对外只有一个单例 `audio`（`src/audio/index.ts`）。
每种声音可以在 **http://localhost:3800/audio-lab.html** 单独听、单独画频谱（开发用，不进正式构建）。

写这些声音的人听不到声音，所以每一种都是按器物怎么发声来搭、再用离线渲染量数值和看频谱图核对的。
**音色好不好听，最后要靠人耳**——文末列了最该先试听的几样。

## 一、怎么用

```ts
import { audio } from '@/audio';

await audio.unlock();                       // 必须在用户的一次点按里调用；之后才出声。可重复调用
audio.play('muyu', { vel: 0.7 });           // 一击的声音
audio.setLayer('chant', 0.6);               // 环境层的用户音量 0…1
audio.setScene({ hour: 6.5, weather: 'mist', season: 'autumn', indoor: 0, water: 0.3, height: 0 });
const off = audio.onSyllable((i) => { /* 诵经每字回调：i 从 0 递增 */ });
audio.setChant({ bpm: 72 });                // 每分钟字数；phrases 默认是《心经》五十二小句的字数
audio.keepAlive(true);                      // 静坐计时中：页面到后台也不停
audio.duck(0.7, 1);                         // 环境声压低七成（特写时）
```

| 方法 | 说明 |
| --- | --- |
| `unlock()` | 建 AudioContext、在手势里 resume、播一个无声 buffer；iOS 上把音频会话设成 `playback`（静音拨片拨下时也出声）。没解锁前别的调用只记状态，`play` 直接忽略 |
| `ready` | 已解锁且在运行 |
| `setMaster(v)` / `setMuted(b)` | 总音量（默认 0.8）、静音 |
| `play(shot, { vel, pan, pitch, dur, space, delay })` | `vel` 力度（默认 0.7，管响度也管明亮）；`space`：`open` 室外 / `hall` 殿内 / `near` 贴近（几乎全干）；不给就按 `Scene.indoor` 在室外与殿内之间取；`dur` 只对 brush、broom、pour 有用 |
| `setLayer(layer, level, fade?)` / `getLayer` | 用户音量 |
| `getEffective(layer)` | 这一层此刻实际的量（用户音量与场景合起来）。做混音界面时可用它提示「夜里没有鸟」 |
| `setScene(partial)` | 可以每秒调一两次；时刻差不到三分钟、位置差不到 1% 时内部直接跳过 |
| `setAuto(false)` | 关掉「天气 / 场景自己带出来的声音」，各层只听用户音量 |
| `onSyllable(cb)` / `setChant(opts)` | 诵经跟字。回调按声音真正出来的时刻触发（算上输出延迟） |
| `keepAlive(on)` | 默认页面隐藏就挂起、回来恢复；`true` 时不挂起，并把排程的前瞻从 0.25 秒放到 3 秒（后台定时器一秒才跑一次） |
| `duck(amount, fade?)` | 只压环境层，一击的声音不受影响 |

**与约定的接口相比，多了**：`getEffective`、`setAuto`、`engine`（调试用）、`setChant` 的 `bowl`（每一遍开头一声磬，默认开）；导出了 `renderOffline`（离线渲染，试听台与检查用）。没有少的。

### 两个容易想错的地方

1. **实际响度 = max(场景带出的基础量, 用户音量) × 场景修正 × 校准**。
   - 基础量：`rain` 在下雨时 0.6；`stream` 是 0.5 × `water`；`insects` 0.35（只在夜里起作用）。其余为 0。
   - 场景修正：`wind` 随高处加大（0.75 + 0.55·height），雪天 ×0.6、雾 ×0.8、雨 ×1.1；`birds` 夜里为 0（清晨 5–8 点最密，白天稀，傍晚稍密，雨雪天少）；`stream` 是 0.45 + 0.75·water；`insects` 19 点后渐起、清晨收，冬天没有，夏天白天换成极远的蝉；`eaves` 随高处加大。
   - 所以：用户把雨关到 0，下雨时仍有雨声（要彻底不要就 `setAuto(false)`）；用户把鸟开到 1，夜里也没有鸟。
2. **`windbell` 的 `pitch`**：给了就是 G6（1568Hz）的倍率；不给则在 G 宫五声（G6 A6 B6 D7 E7）里随机取一个。

### 用户自备的诵经录音

把有版权许可的录音放到 `public/audio/xinjing.mp3`。启动时会 HEAD 探测一次（要求返回 `audio/*`），有就让 `chant` 层循环播它，没有就用合成的。
播录音时没有逐字的时间信息，`onSyllable` 只按 `bpm` 打拍子，木鱼与磬也不再另加。

## 二、总线

```
一击 ─ 干 ───────────────────────────────────────────┐
     ├ 送「殿」  （脉冲响应现算：2.6 秒，越往后越暗）──┤
     └ 送「山谷」（1.2 秒：七道隔得开的回声 + 一层薄尾）┤
环境层（风鸟泉雨虫远钟风铎）─ 室内低通 ─┐              ├→ 汇总 → 总音量 → 压限 → ×0.69 → 软限幅 → 输出
环境层（诵经、琴）──────────────────────┴ 55Hz 高通 ──┘
```

- 压限器：阈值 −14dB、拐点 12dB、比 3、起 5ms、放 0.3 秒。浏览器的压限器自带一段补偿增益（这组参数实测 ×1.446），后面乘 0.69 抵掉，小信号正好原样通过。
- 末级软限幅（WaveShaper）：0.62 以下原样，往上渐渐压平，最高约 0.89——任何组合都不会削波。平时碰不到它。
- 室内（`indoor` 0→1）：室外各层过一道低通（18kHz → 1.1kHz）并降到 45%；一击的声音从送「山谷」换成送「殿」。雪天整体再闷一些（低通不高于 6.5kHz）。
- 环境声整体 ×1.6：默认设置下合起来约 −31dB（均方根），远低于一击的声音（木鱼峰值 0.3、钟 0.4），但手机外放也听得见。
- 调音以 G 为中心：钟的嗡音 G2、诵经 G2、大磬 B3、引磬 D6、风铎与琴都在 G 宫五声里，碰在一起不打架。

## 三、一击的声音

峰值是默认力度 0.7、室外、总音量 0.8 下离线渲染量的（输出端）。「余音」是降到最响处 −60dB 的时刻。

## 四、环境层

均方根是用户音量开到 1、离线渲染 10 秒量的（输出端）。

| 层 | 做法 | 均方根 |
| --- | --- | --- |
| `wind` 风 | 两路粉噪声。松涛：先切掉 240Hz 以下，再各过一条带通，中心在 330–880Hz 之间、响度在 0.35–1.1 之间各自慢慢游走（每 3–7 秒换一个去处，不是规则的摆），左右各一路；低处一层很轻的风身（90–230Hz）；高处才有 1.4–2.6kHz 的窄带啸。每 14–38 秒来一阵风（高处更密），整体涨到最多两倍再落回 | 0.05–0.075（看有没有赶上一阵风） |
| `birds` 鸟 | 七种叫法：短啾、颤音、布谷（只在春夏）、斑鸠、下滑的长哨、清晨的一句、一高一低的来回。同时在场零到六只，每只有固定的叫法、音高、方位、远近，叫 20–80 秒飞走换一只；远的更轻、高频少、回声多 | 0.011–0.015（清晨），峰值约 0.1 |
| `stream` 泉 | 白噪声过五条窄带（460–2600Hz，Q6），每条的中心 ±22% 不规则地摆、响度各自一隐一现；底下一层褐噪声（190–700Hz）；偶尔一个小水泡 | 0.033（不近水时） |
| `rain` 雨 | 雨幕：2.4kHz 以上的白噪声，5.2kHz 处鼓起一点，密度慢慢起伏；瓦上一层 150–520Hz（在殿里更明显）；雨点是预先算好的 5.3 秒（每秒约四十滴），左右两路快慢略不同地循环；檐滴每 0.5–2.2 秒一滴 | 0.068 |
| `insects` 虫 | 三只蟋蟀（4.35k、4.72k、5.05kHz），用循环的幅度图样开合：三四个 16ms 的小包一组，一组一组地来，周期各不相同；每只叫 8–25 秒歇 3–10 秒。夏天白天换成极远的蝉（6.2kHz 窄带噪声，56Hz 的颤） | 0.010（秋夜） |
| `chant` 诵 | 见下 | 0.059 |
| `qin` 琴 | 见下 | 0.025（稀疏） |
| `bellfar` 远钟 | 同一口钟，力度 0.4，过 620Hz 低通，几乎只送回声；建层后 6–20 秒第一声，之后每 40–90 秒一声 | 一声的峰值约 0.17 |
| `eaves` 风铎 | 三只，音高与方位固定（G6 偏西、B6 偏东、D7）；一阵风来响一到三声，没风时 22–60 秒一声 | 一声的峰值 0.04–0.2 |

### 诵经（合成）

- 声源：四个略失谐的锯齿波，都在 98Hz（诵经基本在一个音上），各带一点抖（±7 音分）与很慢的漂（±9 音分）。
- 声道：分成两拨，每拨是并联的三个共振峰带通加一路 260Hz 以下的胸声；两拨的共振峰一个 ×0.97、一个 ×1.06，起字差 30ms，一左一右。
- 字：按《心经》二百六十字的读音走（`xinjing.ts`，拼音解析成「声母类别 + 元音序列 + 有无鼻韵尾」）。字头按声母给凹陷（塞音收到 4%、咝音 12%、鼻音 40%、零声母 70%），咝音与送气音在凹陷里加一小段噪声；复韵母的元音依次滑过去；鼻韵尾把 F1 压到 270Hz。
- 句：每字一拍、一击木鱼（`fish`）；句末停一拍，音高落 70 音分，收一口气；每一遍开头一声磬、空两拍起腔（`bowl`）。
- 远近：汇总后过低通——院子里 1.7kHz，进殿 3.4kHz；院子里多送「山谷」，殿里多送「殿」。
- 默认 72 字 / 分，一遍约四分二十秒。

### 古琴（生成式）

- 每个音现算一段波形（Karplus–Strong）：激励是一个周期长的低通噪声，过「拨在弦长八分之一处」的梳状；环路里一阶低通加损耗——基音余音 3–9 秒，1kHz 以上的分音一两秒就没了，所以起音亮、余音圆。
- 吟猱靠变延迟：起音从下方 120–190 音分滑上来（绰，三成）、拨后 0.45–0.9 秒起每秒 3.2–4.6 次地颤（吟，五成半）、滑到邻近的音上去（走音）。泛音另算，几乎只有一个分音。偶尔一个撮（八度同弹）。
- 出来后过「琴身」：190Hz、410Hz 两处宽的共鸣，4.2kHz 以上收掉。
- 曲子现编：G 宫五声（D2 到 D4 共十一个音），一句二到五个音，音与音隔 1.2–4 秒，句与句空 6–14 秒；句首用低的散音，句末七成落在宫音。
- 为省工夫按一半的采样率算（琴音 5kHz 以上没有东西），弦长每 32 个样本算一次；桌面上一个音 1.5–3 毫秒、一个泛音不到 1 毫秒（在主线程上算，隔几秒才有一个）。

## 六、请先用耳朵试听的（把握不大的）

1. **诵经**：结构是对的，但「像不像人在念」「会不会像合成器的铺底、会不会诡异」只有耳朵知道。若不对，先试：把 `chant.ts` 里的 `far` 低通再压低（更远更糊）、锯齿波换成更暗的声源、或干脆放一份录音。
2. **古琴**：Karplus–Strong 天生偏吉他 / 筝；已经压暗、加了琴身与吟猱，但离真琴的「松沉」还有距离。
3. **鸟**：纯正弦的鸟叫容易显得「电子」；叫法的种类和疏密可以调（`nature.ts` 的 `CALLS`）。
4. **钟**：手机外放放不出 98Hz 的嗡音，听到的是 200–660Hz 那几个分音；耳机里才是完整的。两种都请听一下。
5. **整体的响度关系**：环境声与一击之间差多少、默认各层的比例，是按数值定的。

## 七、已知的事

- 第一次 `unlock()` 要现算两段混响的脉冲响应（桌面实测约 24 毫秒），各层第一次起来时再算几段噪声与控制曲线（合计约 21 毫秒）；手机上估计是这个的五到八倍——放在「入山」那一下点按里即可。只在真机上估过，没有实测。
- 没有在真手机、Safari、Firefox 上跑过：只在桌面 Chrome（无头）里验证。用到的接口（StereoPanner、ConstantSource、Convolver、DynamicsCompressor、WaveShaper、22050Hz 与半采样率的 AudioBuffer）Safari 14.1 以后都有。
- 页面在后台、又开着 `keepAlive` 时，浏览器把定时器压到一秒一次，所以前瞻放到 3 秒；若系统把页面彻底冻结（iOS 锁屏），声音仍会停。
- iOS 上「静音拨片拨下也出声」靠 `navigator.audioSession`（Safari 16.4 起）；更老的系统拨片拨下时没有声音。
- 钟连续猛敲时，每一击有十几个长余音的振荡器，二三十击叠在一起会到两三百个节点；正常的敲法（隔两三秒一下）没有问题。
- 开发服务器对不存在的路径返回 index.html（200），所以探测录音时除了看状态还看 `content-type` 是不是 `audio/*`。
