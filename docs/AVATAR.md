# 行者与村人的身子（小人）

由你操纵着走动的那个人——安乐窝的主人：素净的读书人，月白的交领长衫垂到脚踝，淡青的领缘与绦带，头顶挽髻、戴一顶软巾（巾后两条短带），一点髭须。脸几乎是空白的：一对阖着的眼线、极淡的眉。
村里的人（src/world/life/）用的是同一副身子，换一身衣着（`Look`）。

入口 `src/world/avatar/index.ts`，接口在 `types.ts`：

```ts
createAvatar(q: Quality, look?: Partial<Look>): Figure   // Figure 实现 Avatar；不给 look 就是行者
new Figure(q, look?)                                      // 同上
createStubAvatar(): Avatar                                // 几个墨色方块拼的替身（接口一样）
SCHOLAR: Look                                             // 行者的那一身
```

`Look`（都可只给一部分，其余取行者的）：`robe / robeDens / body`（衣色、浓淡、留白几成）、`skirt? / skirtDens?`（下裳另一色）、`trim`、`sash`、`hair`、`skin`、`shoes`（各带 `…Dens`）、
`hat: 'none' | 'li' | 'jin' | 'bun' | 'tufts'`（无、斗笠、软巾、发髻、两个抓髻）与 `hatWorn`（斗笠戴着还是背着）、`hatPig / hatDens`、
`scale`（身量，孩子约 0.7）、`head`（头的大小）、`sleeve`（袖的宽窄 0…1）、`hem`（下摆离地，大于 0.2 是短衣、露小腿）、`leg? / legDens?`、`beard`（0…1）、`cape`（蓑衣）、`accent?`、`folds`、`shade`。
现成的各色衣着在 `src/world/life/looks.ts`。

| 文件 | 管什么 |
| --- | --- |
| `figure.ts` | 身体怎么动：步态、姿态、俯身、手、头，以及每帧把长衫、袖子、袜筒摆好 |
| `parts.ts` | 不变形的部件与贴图：头、帽、手、鞋、背着的斗笠与蓑衣；衣着的贴图（交领、绦带、衣褶、发际、眉眼） |
| `loft.ts` | 会动的「筒」：若干圈点连成的曲面，每帧重摆、重算法线；刚性件也摆进同一张网 |
| `stub.ts` | 替身 |
| `src/lab/ink/life.ts` | 台子上的几个场景（见文末） |

## 做法

**整个人是一张网、一次绘制**：长衫、两袖、两只袜筒是每帧现摆的曲面；头、两手、两鞋、帽（背着的斗笠、蓑衣）是刚性件，每帧在 CPU 上摆进同一张网里。没有骨骼蒙皮。
材质是画法里的 `wash`（见 docs/INK.md）：各处的颜色（颜料的浓淡次方）画在每身衣着自己的一小张贴图里，交领、绦带、衣褶、发际、眼眉都在上面；网带 `color` 与正确的法线，勾线由画法的后处理来。

- 衣身自下摆到领口二十几圈，每圈是前后半径可不等的超椭圆。上身的圈串在一条会弯的脊上；下摆的圈站立时被两条（看不见的）腿顶出去，带一点滞后；跪、坐、蹲、坐凳各有一套圈的参数，姿态之间只是参数在过渡——所以关节没有缝，衣摆是「铺开」的而不是压扁的。
- 袖子是套在两段臂上的宽筒：臂越平，筒越往下垂成一只袋；臂垂下时长过手腕、只露指尖；手举起来袖子就褪下去露出手腕。袋的方向带惯性。窄袖（`sleeve` 小）就贴着臂。
- 袜筒顺着小腿的方向（站着朝膝、跪着贴地朝前），所以跪着时不会戳到地面以下。短衣（`hem` 大于 0.2）时它就是露着的小腿。
- 手臂是两段的解析反向运动学，肘朝外下；拢袖时肘在身前。

## 尺寸

## 坐标与挂点

- `root`：原点在两脚之间的地面，面朝自己的 **+z**，**+x 是他的左手边**（右手在 −x）。外面只设 `position` 与 `rotation.y`。
- `joints.hips / chest / head`：骨盆心、胸心、头心，都随身体转。
- `joints.handL / handR`（掌心的挂点）：**原点在掌心，+y 指向指尖，+z 是手心朝的方向**。自然下垂时 +y 朝下、+z 朝大腿（右手的 +z 是 +x，左手的是 −x），拇指朝前。`reach` 给了 `dir` 时 +y 就是 `dir`，给了 `palm` 时 +z 尽量朝 `palm`（先保 +y）。把东西 `add` 上去就是「拿着」：沿 +y 的一根棍握在手里是竖着顺着手指的。

## 姿态与 root 的高度

`setPose(p, dur)`，过渡用五次缓动，半途身子会先往前探。

| 姿态 | 样子 | root 在哪 |
| --- | --- | --- |
| `stand` | 站 | 脚下的地面 |
| `kneel` | 跪坐：双膝着地，臀坐脚跟，上身直 | **膝下的那个面**。膝在身前约 0.29，脚尖在身后约 0.28，骨盆在 −0.085 |
| `sit` | 盘腿坐 | **臀下的那个面**（坐蒲团就把 root 抬到蒲团顶面） |
| `crouch` | 蹲，上身前探约 30° | 脚下的地面 |
| `bench` | 坐在凳上：两腿垂着，大腿近乎平、小腿竖直、两脚踩地，两手搭在腿上 | **脚下的地面**（凳在身后） |

**凳**（`bench`）：root 放在两脚踩的那一点（地面上），面朝前；`setSeat({ h, cz })` 说凳面比脚下高多少（`h`，默认 0.44）、凳心在脚后多远（`cz`，负数，默认 −0.34）。
也就是：**人的 root 站在凳心正前方 0.34 米**（凳高 0.40–0.48 时大腿平、小腿直；别的 `cz` 也行，骨盆会跟着挪）。骨盆在凳面上方 0.10。矮凳（0.24–0.3）时膝会高过胯，是对的。

**垫子**（`kneel`、`sit`）：`setSeat({ h, r })`（圆的蒲团）或 `setSeat({ h, hx, hz, cx?, cz? })`（方的垫），`null` 取消。root 在垫子顶面上时，垫子以外的衣摆会垂到地面；坐着时两膝落下去；跪着时脚、按地的手落到地上。

`bow`（0…1 的目标值，内部是临界阻尼的弹簧，起落各约 1.1 秒）：

- 站：鞠躬约 60°，骨盆略往后送。
- 跪：叩拜。0.2–0.8 之间两手前伸按地，落在头的两侧。某只手被 `reach` 占着时那只手不按地。
- 坐、坐凳：略低头含胸。蹲：再前探一点。

## 手

`setHands(h, dur)`：`free` 自然下垂，走路时随对侧的腿小幅摆（跪着、坐凳时搭在腿上，盘坐搭在膝头）；`sleeve` 拢袖——两条小臂横在腹前，手各探进对面的袖筒，走路不摆；`pray` 胸前合十；`lap` 叠放腹前、掌心向上（右手在上）。

`reach(side, 世界点 | null, { dir, palm, rate })`：掌心到那一点。够不着就伸直朝它；`dir`、`palm` 都是世界方向；目标每帧可以变，按 `rate`（默认 10）追；给 `null` 平滑放回。不给 `dir` 时手指顺着「肩→目标」。

`lookAt(世界点 | null)`：左右 ±70°、上下 ±35°（相对上身），七成在头、三成在上身。

## 走

`update(dt, t, { speed, climb, turn })`。步幅 `0.40 + 0.19 × 速度`（米），相位按走过的路推进；**着地的脚每帧按地面速度往后退，所以不打滑**（不是靠缩放幅度）。

| 速度 | 步幅 | 每秒几步 | 着地占比 | 是什么 |
| --- | --- | --- | --- | --- |
| 1.45（走） | 0.68 | 2.15 | 0.62（有双脚同时着地的一段） | 从容的走 |
| 3.0（快） | 0.97 | 3.1 | 0.44（两脚有同时离地的一瞬） | 小跑，臂微屈 |

2.2–3.0 米/秒之间由走过渡到跑。起步是后面那只脚先迈半步；停步后两脚一先一后收拢。上坡步子小、前倾、膝把前襟顶起；下坡略后仰。转身向内侧倾（`turn` 为正是向左转）。每落一步回调 `onStep('L' | 'R')`。`contact.L / contact.R` 是此刻哪只脚撑着地；`gaitPhase` 是相位（0 左脚跟着地，0.5 右脚跟着地）。

**真实的地面** `setGround(fn)`：`fn(世界 x, 世界 z)` 返回那里地面的世界高度（界外 `null`）。

- 着地的脚：落地那一刻量一次脚心下的高度，撑地的这一程里就停在那个高度上；站定时一直量着。
- 摆动的脚：从抬脚处的高度迈到落脚处的高度，中间抬过两处里较高的那一处再加余量；上台阶时先抬后送。
- 坡上：脚顺着坡斜（`figure.ts` 里的 ramp、tilt），下摆最下面几圈不插进坡里。
- `fn` 为 `null` 或返回 `null` 时退回按 `climb` 的斜面摆。root 的高度仍由外面给，脚与 root 之间的出入由腿吃掉。

## 台子

`ink.html?m=…`（参数见 `src/lab/ink/life.ts` 文件头；`t=` 钟点、`w=mist` 雾、`season=`）：

- `avatar`：一个人，按参数摆。例：`&who=farmer`（换一身衣着）、`&pose=kneel&hands=pray&bow=1`、`&speed=1.45&phase=0.25`、`&from=stand&pose=bench&k=0.45`（看过渡的半途）、`&pose=bench&seat=stool&sh=0.42`、`&live=1`。
- `avatarWalk`：一个步态周期的八个定格（`&speed=3`）。
- `avatarPoses`：各个姿态排成一排。
- `looks`：村里各人的衣着站成一排（`&far=40` 再在四十米外摆一排，看远处读不读得出来）。

## 还不够好的

- 手是并指的「连指手」，没有分开的手指；近看（写字、沏茶的特写）会显得简。袖口里子是深色的，手缩在袖里时近看是一团墨。
- 走到 3.0 的小跑只在定格上看过，没有真人对照着调过节奏。
- 袖子与衣身、两袖之间只是相交，没有碰撞；合十、拢袖时两只袖口叠在一起，靠深色的里子遮。
- 坐在凳上（bench）时衣摆是按「膝上铺开、小腿前垂」摆的，凳很矮或很高时下摆的褶不大自然。
- 下摆的褶是固定的起伏加腿的顶推，不是布料模拟；急转身时不会甩。
