# 行者（小人）

寺里由你操纵着走动的那个人：进山的行者，不是僧人，不分男女。一袭月白的交领长衫垂到脚踝，藏青的领缘、绦带与下摆边，头顶挽髻束带，背后斜挂一顶竹斗笠，黑布鞋白袜。脸只有一对阖着的眼线与极淡的眉。

入口 `src/world/avatar/index.ts` 的 `createAvatar(mats, q)`，接口在 `types.ts`。

| 文件 | 管什么 |
| --- | --- |
| `figure.ts` | 身体怎么动：步态、姿态、俯身、手、头，以及每帧把长衫、袖子、袜筒摆好 |
| `parts.ts` | 不变形的部件与贴图：头、手、鞋、斗笠与系绳；长衫的贴图（交领、绦带、衣褶） |
| `loft.ts` | 会动的「筒」：若干圈点连成的曲面，每帧重摆、重算法线 |
| `src/lab/models/avatar.ts` | 台子上的五个场景（见文末） |

## 做法

混合：**长衫、两袖、两只袜筒是一张每帧现摆的网（一次绘制）**，头、两手、两鞋、斗笠是刚性件，共 **7 次绘制**。没有骨骼蒙皮，也没有着色器材质——都是 `MeshStandardMaterial` 经 `enhance` 接上寺里的雾。

- 衣身自下摆到领口二十几圈，每圈是前后半径可不等的超椭圆。上身的圈串在一条会弯的脊上；下摆的圈站立时被两条（看不见的）腿顶出去，带一点滞后；跪、坐、蹲各有一套圈的参数，姿态之间只是参数在过渡——所以关节没有缝，衣摆是「铺开」的而不是压扁的。
- 袖子是套在两段臂上的宽筒：臂越平，筒越往下垂成一只袋；臂垂下时长过手腕、只露指尖；手举起来袖子就褪下去露出手腕。袋的方向带惯性。
- 袜筒顺着小腿的方向（站着朝膝、跪着贴地朝前），所以跪着时不会戳到地面以下。
- 手臂是两段的解析反向运动学，肘朝外下；拢袖时肘在身前。

## 尺寸

身高 1.58 米，约六头身。眼高 1.45。骨盆心 0.86，腰（绦带）0.965，胸 1.16，肩 1.22（左右各 0.138），上臂 0.245、前臂 0.215，掌心在腕外 0.07。下摆离地 0.085。

## 坐标与挂点

- `root`：原点在两脚之间的地面，面朝自己的 **+z**，**+x 是他的左手边**（右手在 −x）。外面只设 `position` 与 `rotation.y`。
- `joints.hips / chest / head`：骨盆心、胸心、头心，都随身体转。
- `joints.handL / handR`（掌心的挂点）：**原点在掌心，+y 指向指尖，+z 是手心朝的方向**。自然下垂时 +y 朝下、+z 朝大腿（右手的 +z 是 +x，左手的是 −x），拇指朝前。`reach` 给了 `dir` 时 +y 就是 `dir`，给了 `palm` 时 +z 尽量朝 `palm`（先保 +y）。把东西 `add` 上去就是「拿着」：沿 +y 的一根棍握在手里是竖着顺着手指的。

## 姿态与 root 的高度

`setPose(p, dur)`，过渡用五次缓动，半途身子会先往前探。

| 姿态 | 样子 | root 在哪 |
| --- | --- | --- |
| `stand` | 站 | 脚下的地面 |
| `kneel` | 跪坐：双膝着地，臀坐脚跟，上身直 | **膝下的那个面**。膝在身前约 0.29，脚尖在身后约 0.28，骨盆在 −0.085 |
| `sit` | 盘腿坐 | **臀下的那个面**（坐蒲团就把 root 抬到蒲团顶面，即 `player.lift = SEAT`） |
| `crouch` | 蹲，上身前探约 30° | 脚下的地面 |

**垫子**：`setSeat({ h, r })`（圆的蒲团）或 `setSeat({ h, hx, hz, cx?, cz? })`（方的拜垫），`null` 取消。root 在垫子顶面上时，垫子以外的衣摆会垂到地面；坐着时两膝落下去；跪着时脚、按地的手落到地上，叩拜也伏得更深（额头去找垫子前面的地）。拜垫进深只有 0.52 米，跪上去膝在前沿、脚尖在后沿之外，这是对的；想让膝更靠里，把垫心放在人前 0.06–0.1（`cz`）。

`bow`（0…1 的目标值，内部是临界阻尼的弹簧，起落各约 1.1 秒）：

- 站：鞠躬约 60°，骨盆略往后送。
- 跪：叩拜。0.2–0.8 之间两手自合十（或别的摆法）前伸按地，落在头的两侧；到底时额头离地约 1 厘米。某只手被 `reach` 占着时那只手不按地。
- 坐：略低头含胸。蹲：再前探一点。

## 手

`setHands(h, dur)`：`free` 自然下垂，走路时随对侧的腿小幅摆（跪着搭在腿上，坐着搭在膝头）；`sleeve` 拢袖——两条小臂横在腹前，手各探进对面的袖筒，走路不摆；`pray` 胸前合十；`lap` 叠放腹前、掌心向上（右手在上）。

`reach(side, 世界点 | null, { dir, palm, rate })`：掌心到那一点。够不着就伸直朝它；`dir`、`palm` 都是世界方向；目标每帧可以变，按 `rate`（默认 10）追；给 `null` 平滑放回。不给 `dir` 时手指顺着「肩→目标」。

`lookAt(世界点 | null)`：左右 ±70°、上下 ±35°（相对上身），七成在头、三成在上身。

## 走

`update(dt, t, { speed, climb, turn })`。步幅 `0.40 + 0.19 × 速度`（米），相位按走过的路推进；**着地的脚每帧按地面速度往后退，所以不打滑**（不是靠缩放幅度）。

| 速度 | 步幅 | 每秒几步 | 着地占比 | 是什么 |
| --- | --- | --- | --- | --- |
| 1.45（走） | 0.68 | 2.15 | 0.62（有双脚同时着地的一段） | 从容的走 |
| 3.0（快） | 0.97 | 3.1 | 0.44（两脚有同时离地的一瞬） | 小跑，臂微屈 |

2.2–3.0 米/秒之间由走过渡到跑。起步是后面那只脚先迈半步；停步后两脚一先一后收拢。上坡步子小、前倾、膝把前襟顶起；下坡略后仰。转身向内侧倾（`turn` 为正是向左转）。每落一步回调 `onStep('L' | 'R')`。`contact.L / contact.R` 是此刻哪只脚撑着地（撑地的后半程脚跟已抬起，只有前掌着地）；`gaitPhase` 是相位（0 左脚跟着地，0.5 右脚跟着地）。

**真实的地面** `setGround(fn)`：`fn(世界 x, 世界 z)` 返回那里地面的世界高度（界外 `null`）。

- 着地的脚：落地那一刻量一次脚心下的高度，撑地的这一程里就停在那个高度上（脚在世界里本来不动）；站定时一直量着。
- 摆动的脚：从抬脚处的高度迈到落脚处的高度，中间抬过两处里较高的那一处再加余量；上台阶时先抬后送，免得脚尖踢在立面上。
- 落脚点若正压在台阶的棱上（脚跟、脚尖底下的高度差超过 3 厘米），依次试着往前、往后挪 6、12、18 厘米。
- 下摆最下面四圈：在台阶、坡上时沿下摆量 8 个点，不让它插进前面（或身后）那一级。
- 平地上平均每帧约 2–3 次调用，台阶上约 10 次（实测，`avatarStats` 会打出来）。`fn` 为 `null` 或返回 `null` 时退回按 `climb` 的斜面摆。
- root 的高度仍由外面给（取前后一段的平均即可），脚与 root 之间的出入由腿吃掉——腿是看不见的，只有鞋、袜筒和被顶起的衣摆看得见。

## 台子

`lab.html?m=…`（参数见 `src/lab/models/avatar.ts` 文件头）：

- `avatar`：一个人，按参数摆。例：`&pose=kneel&hands=pray&bow=1`、`&speed=1.45&phase=0.25`、`&from=stand&pose=kneel&k=0.45`（看过渡的半途）、`&reach=R&rp=-0.2,1.2,0.42&rd=0,1,0`、`&seat=kneeler`、`&live=1`。
- `avatarWalk`：一个步态周期的八个定格（`&speed=3`、`&row=x` 换成横排从背后看）。
- `avatarPoses`：十二个姿态；`&sel=4,5,6&face=-90` 只看其中几个。
- `avatarScale`：三米门框、蒲团、拜垫、香炉旁。
- `avatarStairs`：上下台阶（`&only=up`、`&ground=0` 对照没有真实地面时的样子）。
- `avatarStats`：三角、绘制、`update` 耗时、各姿态的最低点。

## 还不够好的

- 手是并指的「连指手」，没有分开的手指；近看（抄经、沏茶的特写）会显得简。
- 走到 3.0 的小跑只在定格上看过，没有真人对照着调过节奏；斗笠是刚性的，只左右轻晃。
- 袖子与衣身、两袖之间只是相交，没有碰撞；合十、拢袖时两只袖口叠在一起，靠深色的里子遮。
- 叩拜时斗笠跟着背竖起来，不会滑。
- 跪在垫子上的深叩拜，额头离垫子前的地面还有约 5 厘米（再低身子就折得不像了）。
- 下摆的褶是固定的起伏加腿的顶推，不是布料模拟；急转身时不会甩。
