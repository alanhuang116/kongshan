# 行者与村人的身子（小人）

由你操纵着走动的那个人——安乐窝的主人：素净的读书人，月白的交领长衫垂到脚踝，淡青的领缘与绦带，头顶挽髻、戴一顶软巾（巾后两条短带），一点髭须。脸几乎是空白的：一对阖着的眼线、极淡的眉。
村里的人（src/world/life/）用的是同一副身子，换一身衣着（`Look`）。

入口 `src/world/avatar/index.ts`，接口在 `types.ts`：

```ts
createAvatar(q: Quality, look?: Partial<Look>): Figure   // Figure 实现 Avatar；不给 look 就是行者
new Figure(q, look?)                                      // 同上
createStubAvatar(): Avatar                                // 几个墨色方块拼的替身（接口一样）
SCHOLAR: Look                                             // 行者的那一身
```

`Look`（都可只给一部分，其余取行者的）：`robe / robeDens / body`（衣色、浓淡、留白几成）、`skirt? / skirtDens?`（下裳另一色）、`trim`、`sash`、`hair`、`skin`、`shoes`（各带 `…Dens`）、
`hat: 'none' | 'li' | 'jin' | 'bun' | 'tufts'`（无、斗笠、软巾、发髻、两个抓髻）与 `hatWorn`（斗笠戴着还是背着）、`hatPig / hatDens`、

现成的各色衣着在 `src/world/life/looks.ts`。下雨下雪时在外头另戴的斗笠、蓑衣不是衣着的一部分，是谁都有的一副雨具（见下「雨具」）。

## 做法

**整个人是一张网、一次绘制**：长衫、两袖、两只袜筒是每帧现摆的曲面；头、两手、两腕、两鞋、帽（背着的斗笠、蓑衣）、雨天的斗笠与蓑衣是刚性件，每帧在 CPU 上摆进同一张网里（雨具不戴时收成一点、不再每帧去摆）。没有骨骼蒙皮。
几块的次序：头、左手、右手、左鞋、右鞋、（背上的东西）、左腕、右腕、（雨天的斗笠）、（蓑衣）——前五块的次序不变，`tests/play/clip.js` 按次序找手和脚。
材质是画法里的 `wash`（见 docs/INK.md）：各处的颜色（颜料的浓淡次方）画在每身衣着自己的一小张贴图里，交领、绦带、衣褶、发际、眼眉都在上面；网带 `color` 与正确的法线，勾线由画法的后处理来。

- 衣身自下摆到领口二十几圈，每圈是前后半径可不等的超椭圆。上身的圈串在一条会弯的脊上；下摆的圈站立时被两条（看不见的）腿顶出去，带一点滞后；跪、坐、蹲、坐凳各有一套圈的参数，姿态之间只是参数在过渡——所以关节没有缝，衣摆是「铺开」的而不是压扁的。
- 袖子是套在两段臂上的宽筒：臂越平，筒越往下垂成一只袋；臂垂下时长过手腕、只露指尖；手举起来袖子就褪下去露出手腕。袋的方向带惯性。窄袖（`sleeve` 小）就贴着臂。
- 袜筒顺着小腿的方向（站着朝膝、跪着贴地朝前），所以跪着时不会戳到地面以下。短衣（`hem` 大于 0.2）时它就是露着的小腿。
- 手臂是两段的解析反向运动学，肘朝外下；拢袖时肘在身前。
- 腕与一截小臂（袖子褪下去时露出来的那截）另是一块，顺着小臂（肘 → 腕）摆，不跟着手：手攥着东西腕折过去时，它不从袖子的另一边戳出来。

## 坐标与挂点

- `root`：原点在两脚之间的地面，面朝自己的 **+z**，**+x 是他的左手边**（右手在 −x）。外面只设 `position` 与 `rotation.y`。
- `joints.hips / chest / head`：骨盆心、胸心、头心，都随身体转。
- `joints.handL / handR`（掌心的挂点）：**原点在掌心，+y 指向指尖，+z 是手心朝的方向**。自然下垂时 +y 朝下、+z 朝大腿（右手的 +z 是 +x，左手的是 −x），拇指朝前。`reach` 给了 `dir` 时 +y 就是 `dir`，给了 `palm` 时 +z 尽量朝 `palm`（先保 +y）。把东西 `add` 上去就是「拿着」：沿 +y 的一根棍握在手里是竖着顺着手指的。

## 姿态与 root 的高度

`setPose(p, dur)`，过渡用五次缓动，半途身子会先往前探。

| 姿态 | 样子 | root 在哪 |
| --- | --- | --- |
| `stand` | 站 | 脚下的地面 |
| `kneel` | 跪坐：双膝着地，臀坐脚跟，上身直 | **膝下的那个面**。膝在身前约 0.29，脚尖在身后约 0.28，骨盆在 −0.085 |
| `sit` | 盘腿坐 | **臀下的那个面**（坐蒲团就把 root 抬到蒲团顶面） |
| `crouch` | 蹲，上身前探约 30° | 脚下的地面 |
| `bench` | 坐在凳上：两腿垂着，大腿近乎平、小腿竖直、两脚踩地，两手搭在腿上 | **脚下的地面**（凳在身后） |
| `lie` | 仰卧：脊放平，头枕在右手上略抬起、脸朝天，左手搭在腹上，两腿伸直、脚跟着席、脚尖朝天略外撇；长衫顺着腿铺开盖住腿、两边垂到席上 | **臀下的那个面**（席面），与 `sit` 一样。头心在 root 后约 0.58 米、头顶约 0.7 米；胯心高 0.134；脚跟在 root 前约 0.85 米 |

**仰卧**（`lie`，观星用）：
- 调用：`av.setPose('lie', 秒)`。已经盘腿坐着时（`sit`）就从坐着往后躺：身子往后靠、两手往身后撑一下，再放平、两腿伸出来（1.2–1.8 秒合适）；
  站着（或跪、蹲、坐凳）时直接给 `lie`，会**先坐下再躺**，`dur` 两段分着用（坐 0.55、躺 0.6 成）。躺着给 `sit` 是坐起来；躺着给 `stand`（或别的）会**先坐起再站**。
- root 不用挪：躺下、坐起都是以臀为轴，root 就在臀下的席面上（席高几厘米，就照 `sit` 的做法把 `player.lift` 设成席面比地面高多少）。
  席要铺得下：root 后 0.75 米（头）到 root 前 0.95 米（脚）。`setSeat` 给不给都行——躺着时整个人铺在席面上，垫子外不往下落。
- 躺着照样能 `lookAt(天上一点)`：在躺平的身子里转头（左右是绕身子长轴转、俯仰是往脚那边点头或往头顶那边仰），左右各约 60°。
- 躺着、正在躺下或起身时 `engaged` 为真，闲时的小动作一概不出；`ready`（能迈步了）要等站好了才为真，行者在这之前不听行走的输入（不会没站起来就滑着走）。

**凳**（`bench`）：root 放在两脚踩的那一点（地面上），面朝前；`setSeat({ h, cz })` 说凳面比脚下高多少（`h`，默认 0.44）、凳心在脚后多远（`cz`，负数，默认 −0.34）。
也就是：**人的 root 站在凳心正前方 0.34 米**（凳高 0.40–0.48 时大腿平、小腿直；别的 `cz` 也行，骨盆会跟着挪）。骨盆在凳面上方 0.10。矮凳（0.24–0.3）时膝会高过胯，是对的。

**垫子**（`kneel`、`sit`）：`setSeat({ h, r })`（圆的蒲团）或 `setSeat({ h, hx, hz, cx?, cz? })`（方的垫），`null` 取消。root 在垫子顶面上时，垫子以外的衣摆会垂到地面；坐着时两膝落下去；跪着时脚、按地的手落到地上。

`bow`（0…1 的目标值，内部是临界阻尼的弹簧，起落各约 1.1 秒）：

- 站：鞠躬约 60°，骨盆略往后送。
- 跪：叩拜。0.2–0.8 之间两手前伸按地，落在头的两侧。某只手被 `reach` 占着时那只手不按地。
- 坐、坐凳：略低头含胸。蹲：再前探一点。

## 手

`setHands(h, dur)`：`free` 自然下垂，走路时随对侧的腿小幅摆（跪着、坐凳时搭在腿上，盘坐搭在膝头）；`sleeve` 拢袖——两条小臂横在腹前，手各探进对面的袖筒，走路不摆；`pray` 胸前合十；`lap` 叠放腹前、掌心向上（右手在上）。

`reach(side, 世界点 | null, { dir, palm, rate })`：掌心到那一点。够不着就伸直朝它；`dir`、`palm` 都是世界方向；目标每帧可以变，按 `rate`（默认 10）追；给 `null` 平滑放回。不给 `dir` 时手指顺着「肩→目标」。

**攥着一根杆**：`reach(side, 杆上那一点, { grip: 杆的方向, palm?, rate })`。给了 `grip`，目标就是杆上被攥住的那一点，手自己摆：
手指是小臂的接续（取上一帧「肘 → 腕」垂直于杆的那一份，刚伸过去时取「肩 → 杆」），与杆垂直地绕过去、往掌心蜷一点；
掌心朝着杆、落在杆靠小臂那一侧 2.6 厘米处（杆横在掌心前，不穿过手）；`palm` 只用来挑掌心朝哪一边（不给是手背朝上，正握）。给了 `grip` 就不看 `dir`。
扫院的竹帚（两手）、煮茶时攥提梁、扇柄都这样用。（腕会折，但折的是手；腕那一截顺着小臂，不跟着歪。）

`twist`（弧度，正是往左转）：上身另外扭多少——胸、肩跟着转，胯不动；带一点缓冲。扫地这样由腰带着走的动作用，不用时给 0（`exitAct` 不管它，那件事自己在 `exit` 里放回 0）。

`lookAt(世界点 | null)`：左右 ±70°、上下 ±35°（相对上身），七成在头、三成在上身。

## 走与跑

`update(dt, t, { speed, climb, turn })`。**步态只看速度**：慢是走，快到 2.15–2.95 米/秒之间由走变跑，再快是真正的跑——外面不用另说「跑」。相位按走过的路推进；**着地的脚每帧按地面速度往后退，所以不打滑**（不是靠缩放幅度）。

| 速度（米/秒） | 步幅（米） | 每秒几步 | 着地占比 | 是什么 |
| --- | --- | --- | --- | --- |
| 1.4（行者平时） | 0.67 | 2.1 | 0.62（换脚时两脚都在地上） | 从容的走 |
| 3.0（摇杆推到头） | 0.93 | 3.2 | 0.44（两脚有同时离地的一瞬） | 一路小跑，屈肘前后摆 |
| 4.6（Shift、「疾」） | 1.31 | 3.5 | 0.32（腾空的时候比着地还长些，约占四成） | 跑：前倾、两臂屈肘大摆、摆脚顺着叉开的腿往上缩、往后扬 |

（上表是 `tests/play/motion.mjs` 在世界里量到的。跑的时候着地那一刻脚在胯前约 0.23 米；胯起伏约 4.6 厘米；脚跟踢起最高约 0.42 米。）

- 走：步幅 `0.40 + 0.19 × 速度`。跑：按步频定步幅（每秒 `2.85 + 0.13 × 速度` 步——穿长衫的人步子不放得太开、脚下勤）。
- 跑的样子：着地短、腾空长（两脚同时离地）；**落脚在胯前二三十厘米**（不是远远伸出去够地），撑地的这一程整个往后错一点——身子在两脚的前头；
  蹬地后脚跟先往后上方收（小腿折起来），再随大腿往前甩，甩过了头、落地前略往回收；脚尖蹬离时朝下，落地前翘回来。
  身子单脚撑地时最低、腾空时最高（起伏四五厘米），平均略低一点（膝不伸直）；前倾随速度加大，起跑时（加速）多探一点，急停时往后坐一点；骨盆与肩反着扭得更多。
  两臂屈肘、贴着身子前后摆，往前时手抬到胸前、靠里，往后时落到胯边；按步态的相位匀匀地摆（左臂在右脚落地时最前）。
- **布始终裹着腿**（腿、手都不从衣裳里穿出来；`tests/play/clip.js` 逐帧量，`motion.mjs` 第二节之二守着）：
  腿看不见，只用来顶布，摆成一串球——胯 → 膝 → 踝，球心隔 5 厘米，粗细自胯收到踝；抬起来的脚再加鞋跟、鞋心、鞋尖三个球。
  下摆每一圈管它上下各半个圈距的那一层，层里每个球的截面是一个圆；布在每个方向上至少撑到这些圆最远的那一点——**往外撑是立刻的，往回收才带滞后**（不然腿比布快，就穿出来）。
  摆脚被带起来（或在坡上斜下去）的点，到它此刻所在的那一层再量一次。各层的圆每帧先量好，被别的圆整个包住的不要，每条腿再算一个外接圆：这一点的方向上连它都够不着布，就不一个个比。
  （从前是「这一高度上腿在哪一点」的一个圆：腿一斜，横截面是长的；膝弯顶出的尖落在两圈中间；后面那条腿又有意只裹一半——三样都会从布里穿出来，2026-11-21 改掉。）
- **跑起来摆脚往上缩**（布裹不住叉开的两腿，就顺着腿往上缩，而不是撑到地上拖成一条尾巴）：整圈按速度缩一点（`RIDE`，跑到最快 8 厘米）；
  哪一边的腿叉得远、布撑出本来的半径加 `STRETCH`（12 厘米）还裹不住，那一边顺着腿往上缩到裹得住为止（最多 `RIDE_MAX` 32 厘米；量最下一层与它上面约 30 厘米处两层，中间按直线算），
  往上各圈按 1−u 递减（圈与圈不叠）；缩上去的地方按那个高度上钟的宽窄收（不平着抬起来成一圈帽檐）。往上缩是立刻的，放下来带滞后、与布往回收一样慢（不然腿一收回去摆脚先落、宽度还没收，就在身后拖一截）。
  走路时不量（步子小，布撑得住），由走变跑起才缩。
- 裤腿：站着时袜筒一直接到膝下（最上一圈过膝、顺着大腿往布里探一截），上沿落在布裹着的那条腿的轴上——摆脚扬到哪里，露出来的都是裤腿，不是一截空。
  衣裳两面都画：摆脚扬起来时看得见衣里（同一块布，背着光）；下摆里面是一条深色的贴边（不再收成一点封住底——那样后摆一扬，就成了两腿之间的一张膜），跑起来贴边提亮一些。
- 两臂：跑起来都屈肘前后摆（往后摆到胯外侧）。垂着、摆着的手按上一帧摆好的衣身量：掌心离布至少 4 厘米、指尖至少 2.2 厘米，在里头就水平地往外挪（不插进胯边的衣裳里）。
- 跑起来衣摆被风兜着往后飘：下摆的圈心往后错几厘米，后摆扬起一点，摆脚绕着身子抖（三个起伏绕着转）；被腿撑出去的地方摆脚也带起来一点。
- 转弯身子向内倾：走着只略倾；跑起来按离心力倾（世界里的速度 × 转得多快 / g，打八折），最多约 14°。`turn` 为正是向左转。
- 起步是后面那只脚先迈半步；停步后两脚一先一后收拢。急着收住（减速得猛）时步子碎而勤——步频不随速度一起落下去（着地的脚照样按真实速度后退，不滑）；
  停下时两脚若前后隔得远（跑着急停的弓步），先收远的那只，前一只快落定了后一只就跟上，不在弓步里干站着；那一下后摆也不撑成大钟。
  上坡步子小、前倾、膝把前襟顶起；下坡略后仰。台阶、坡上步幅收小（跑上台阶也是）。
- 每落一步回调 `onStep('L' | 'R')`。`contact.L / contact.R` 是此刻哪只脚撑着地；`gaitPhase` 是相位（0 左脚跟着地，0.5 右脚跟着地）。

**孩子与身量**：`speed` 给的是「他自己尺度里」的速度（世界速度 ÷ `Look.scale`，村里人那一路一直这样给）。步子的样子（走还是跑、步幅、腾空）按**同样的弗劳德数**
折算成成年人的速度来定：`折算速度 = speed × √scale`。于是身量 0.7 的孩子：世界里每秒 2.5 米上下就是跑（成年人要 3 米）；同样快时步子碎、步频是大人的 1/√0.7 ≈ 1.2 倍——
腿短的人本来如此。村里人那一路要孩子追跑，只要把速度给到位（比如世界速度 3 米/秒），身子自己就是跑的样子，不必另设什么。

行者这边的快慢（`player.ts`）：从容地走 1.4 米/秒（夜里再慢一成）；摇杆推到头快走 3 米/秒；按住或点一下锁住 Shift、点「疾」跑 4.6 米/秒（点地面自己走过去时锁住了跑也跑过去）。
快慢的变化有上限：加快每秒至多 4.2 米/秒（站着起步的头一步蹬得猛些，到 7）、放慢 7.5，停下来是匀着收到零（起跑一秒上下才快起来，头几步由小到大；急停一秒上下站定）；跑着拐弯方向的变化也有上限（越快拐得越缓），身子顺着真正去的方向（略往要拐的那边领一点），不会横着跑。
自己跑过去时，到拐点、终点之前按距离先放慢（终点前两米上下开始），不冲过头。坡与台阶上跑得慢一半。
`player.pace`（0…1，初值 1）乘在三档的目标速度上：挑担子、扛东西的事设它（农事挑担 0.72，散步就慢到每秒一米），放下设回 1；步态按速度自己跟上。

## 闲时

`gesture(name, side?)` 叠在姿态上的一层小动作（types.ts 的 `GestureName`）：

| 名字 | 样子 | 多久 |
| --- | --- | --- |
| `tidy` 理袖 | 主手小臂横到身前，另一只手拈住它的袖口扯两下，末了抖一抖；低头看着 | 3.4 秒 |
| `sky` 望天 | 两手背到身后，胸略挺，头慢慢仰起、左右看一看 | 5.6 秒 |
| `glance` 回头 | 头转过去七成、肩扭过去三成，停一停再转回来 | 2.8 秒 |
| `stretch` 伸懒腰 | 两手从身前举过头顶、十指相扣掌心朝上，胸往后仰、头仰起，从两边放下 | 4.4 秒 |
| `beard` 捻须 | 一手抬到颔下顺着须往下捋两回，另一只手负在身后，头略仰 | 4.8 秒 |
| `look` 旁看 | 走着往旁边看一眼（只这一样和 `shade` 走着也做） | 2.3 秒 |
| `shade` 扶笠 / 遮雨 | 头上有斗笠（雨天戴上的那顶，或本来就戴着的）：一只手抬起来扶一扶笠沿前侧，头略低，一会儿就放下。头上没有：一只小臂斜横在额前略高处，大袖垂下来挡着头脸，一直举着，给 `null` 才放下（这副身子臂短，举不到头顶上横着） | 有笠 2.6 秒；没有笠一直举着 |

`side` 是 1（偏左手）或 −1（偏右手），不给随便。整体的分量起落都有缓冲（0.35 秒进、0.4 秒出），所以从什么手的摆法进来都不跳。
**被占着就不做、做到一半被占了就收住**：`engaged` 为真时（不是站着、在俯身、手伸着、手里拿着东西、头看着某处、身下垫着东西、合十或叠手——做事时都是这样）；
站着做的那几样一走起来也收住。另有 `hands`（此刻的手的摆法）、`gesturing`（此刻在做哪一个）。

手的摆法多了一样 `back` 负手：两手背在身后腰下，左手在里、右手在外握着左腕；走起来也不摆。

**谁来安排**：`avatar/idle.ts` 的 `Idle`（行者的 `player.idle`；村里人也可以各用一个）：
- 站着——站定一会儿，隔十几二十秒换一换手的摆法（负手四成半、拢袖三成半、垂手两成），隔七到十几秒做个小动作（不连着做同一个，伸懒腰一分钟里至多一回；做完一件久坐的事站起来先伸一个；夜里望天的多些）；
- 散步——从容地走了八九到十四五秒，七成的时候就负手而行；走着偶尔往旁边看一眼；快到每秒 2 米以上（快走、跑）手就放开；
- 下雨下雪在外头——戴上斗笠、披上蓑衣（见下「雨具」）；站在雨里隔九到十八秒扶一扶笠沿（`shade`），别的小动作不做；跑起来、进了檐下就放下。不再抬袖遮雨（斗笠遮着）。
  雨具不算小动作：`idle.on = false`、做着事、身子被占着时，照样按天时与在不在檐下戴、卸。
- 只在身子没被占着时才动：做事时（`busy`：锁着，或 `player.busy()` 说着在做事）、或身子 `engaged` 时一概不出，手上的摆法也不去碰；被占过之后计时从头算。
  换处、被搬到别处（`teleport`）时从头算，手若是它换的放回垂手。`idle.on = false` 关掉（测步态时这么做）。
- `player.busy`：自己走动着做的那几件事（浇菊……）`locked` 为假，最好由总装接上 `() => !!k.act`；不接也行——拿着东西、手伸着、头看着某处时身子自己知道。

## 雨具（斗笠、蓑衣）

下雨下雪（雨或雪过四成，`gear.ts` 的 `WET`）、人在外头——头顶没有屋顶、屋檐——就戴上斗笠、披上蓑衣；进了屋、走到檐下就卸下。

**为什么是蓑笠，不是油纸伞**：跟拍的镜头在人身后高处，伞面会把人整个盖住；蓑笠从背后看是一个尖顶、一领草披，一眼就读得出来，
也正是水墨里「一蓑烟雨」「独钓寒江雪」的样子；两手空着，跑起来照样摆臂，雨里扫雪、做事都不用先收伞；村里的农夫、打更的本来也这么穿。

- `setGear(v, instant?)`：要戴几成（0…1）；`gearK` 是此刻几成。身子自己戴、卸：约 1.05 秒戴好、0.85 秒卸下。
  - 斗笠从背后翻上头：在背上那一处（笠面朝后贴着背，与背斗笠的人那一顶一样）与头上那一处（沿压到眉上一点、略往后仰，髻、巾顶都在笠里）之间，
    中途往上、往后让开头。本来不背斗笠的人，头一成里斗笠在背后由小长到原样；樵夫、放羊的（本来背着斗笠）就是把背上那顶翻上头，背上随之空了。
  - 蓑衣自肩上披下来：自领口往下一层层落下、张开。
  - 右手空着（没伸出去、没拿东西、不在做小动作、站着）时，戴、摘的那一下右手扶着笠沿跟过去。
  - `instant` 为真直接到位（没人看着、刚换了处、时辰被一下子拨过去）。
- 本来戴着斗笠的不另加斗笠（农夫、渔父、货郎、药农、行脚僧），本来披着蓑衣的不另加蓑衣（渔父）。
- 斗笠比平时戴、背的那种深一些（`RAIN_HAT`：沿的半径 0.272、高 0.17），篾纹用顶点色画（一圈深一圈浅、几道骨、深的笠沿），谁戴都是一样的篾色；
  蓑衣三层，一层压着一层，下沿参差；领口一圈围着颈，往下前襟敞开，盖到胯下一点（`CAPE`：胸心上 0.135 到下 0.4）；草丝也是顶点色。雪天朝上的面被画法留白——积着雪。
- 蓑衣是跟着胸走的刚性件，每帧按两臂量一回：袖子（肩 → 肘、肘 → 腕两段，按袖子的肥瘦当一根胶囊，越近袖口越肥）顶到哪里，那一片就撑出去盖在袖子上——
  走、快走、跑时臂、袖不从草里穿出来，往后摆的手从蓑衣下沿底下露出袖口。
- 什么时候戴：
  - 行者（`Idle`）：雨（`IdleState.rain`）或雪（`IdleState.snow`；不给就取 `gear.ts` 的 `SKY.snow`，村里那一路每帧报）过四成，不在屋里亭里（`indoor`），
    头顶 1.35 米那一点也不在屋顶底下（`shelterAt`：画法登记的十六处屋顶——草堂连檐口、亭、各家、村塾、碓房、棚——与「雨不湿、雪不积」同一份）。
    在不在雨里变了，出去 0.35 秒才戴、进了檐下 0.6 秒才卸（进出屋檐不来回换）；刚开场、换了处（`reset`）直接到位。走进草堂，在门里一两步卸下。
  - 村里人（`life/index.ts`，每四帧看一回）：走着路的按头顶有没有屋顶算；站下来干活的，离屋檐不到一步半（`nearRoof(x, z, 1.5)`）就算在檐下——
    雨天的活本来排在檐下，站处多半在檐口外一点点。不在画面里的直接换好。打更的老周雨夜「披着蓑衣打更」就是这么来的。

**真实的地面** `setGround(fn)`：`fn(世界 x, 世界 z)` 返回那里地面的世界高度（界外 `null`）。

- 着地的脚：落地那一刻量一次脚心下的高度，撑地的这一程里就停在那个高度上；站定时一直量着。
- 摆动的脚：从抬脚处的高度迈到落脚处的高度，中间抬过两处里较高的那一处再加余量；上台阶时先抬后送；下台阶时脚没迈过台沿不往下落（脚掌底下量两点，不擦着棱）。
- 坡上：脚顺着坡斜（`figure.ts` 里的 ramp、tilt），下摆最下面几圈不插进坡里。
- `fn` 为 `null` 或返回 `null` 时退回按 `climb` 的斜面摆。root 的高度仍由外面给，脚与 root 之间的出入由腿吃掉。

## 还不够好的

- 手是并指的「连指手」，没有分开的手指；近看（写字、沏茶的特写）会显得简。袖口里子是深色的，手缩在袖里时近看是一团墨。
- 跑是照着跑步的常识（着地短、腾空长、落脚在身下、脚跟踢向身后、屈肘摆臂）调的，在逐帧条上看过，没有真人录像对照着逐帧调过节奏。
- 跑起来露出来的是「裤腿」（袜筒接长到膝上），没有真的腿；摆脚往上缩、往后扬是按腿在哪儿算出来的，不是布料模拟——跑到最快时前后摆扬得像一口半翻的钟，近看有一点硬。
- 布裹着腿那一串球每帧都要量，行者走、跑时比改前每帧多花约 0.03–0.06 毫秒（见上面的表）。
- 腿是看不见的、只用来顶布：这副身子腿短（胯高 0.82），跑的步子按它收着，长衫底下的腿与真人比起来略「伸」。
- 袖子与衣身、两袖之间只是相交，没有碰撞；合十、拢袖时两只袖口叠在一起，靠深色的里子遮。
- 坐在凳上（bench）时衣摆是按「膝上铺开、小腿前垂」摆的，凳很矮或很高时下摆的褶不大自然。
- 下摆的褶是固定的起伏加腿的顶推、跑起来加上往后的飘与抖，不是布料模拟；急转身时不会甩。
- 遮雨那一下（头上没有笠时）：臂短，举不到头顶上横着，只能斜横在额前。
- 雨具：蓑衣是刚性的一领（只按两臂撑开），不是布料模拟——跑起来不飘、不甩，坐、跪时下沿不铺到地上；斗笠从背后翻上头，中途会擦过后脑一瞬；
  孩子、妇人戴的也是同一顶斗笠、同一领蓑衣（没有另做伞或帷帽）。
- 攥杆（`grip`）时腕会折过去，有时折得比真人多（扫院时上手约七八十度）；腕那一截顺着小臂，远看读得出是攥着，近看手与腕之间是一道折。
- 仰卧时下摆是「盖在两条伸直的腿上、两边垂到席上」的固定截面，不是布料落下来；躺下、坐起的半途是在盘坐与仰卧两种摆法之间逐点过渡的，近看衣摆有一刹那不大像布。
