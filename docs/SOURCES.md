## 〇、怎么查的

- **底本**：佛典与禅籍用 CBETA 电子佛典（大正藏 T、卍续藏 X、嘉兴藏 J 等）；诗文、老庄、四书、清言用中文维基文库所收底本（《全唐诗》四库本、各诗单页、王弼本《老子》等）。
- **做法**：取原文整卷 / 整页的原始文本，繁体转简体、只留汉字、把同一个字的不同写法（閒／閑→闲、祇／秖→只、缾→瓶、纔→才 之类）归一，再看数据文件里的整段文字是否**原样连续地**出现在原文里。心经、85 则短句、QUOTES 里的各条都通过了这一步；写进项目之后又把数据文件读回来与核对稿逐行比对了一遍。
- **取字**：一律简体。原文用通假字、异体字而今天有通行写法的，换成通行写法，并在 `from` 里注「原作某」；各本文字不同的，取一种，在 `from` 里注「一作某」。
- **局限**：核对的是电子录文，没有对照纸本或影印本。维基文库各页的校对程度不一。

## 给主代理的几条提示（先看这里）

1. **唐风的寺，钟楼对面是经楼，不是鼓楼。**「寺之制度，钟楼在东」是唐人原话；钟鼓二楼对设是宋元以后、明代才定型的格局。西边那座若做成经楼（正好作抄经处）最合唐制；要留鼓楼，就说是后世通例。（第四节 1）
2. **石灯在唐代是殿前正中一座**，不是夹道两列——成列的石灯笼更像日本神社。（第四节 9；后半句是我的判断，可靠程度中）
3. **人字栱是北朝到初盛唐的式样**；晚唐的佛光寺东大殿补间已不用它。朱柱白壁、直棂窗、月牙形鸱尾都有依据。（第四节 8）
4. **静坐「三声起、一声止」与丛林规约相合**：止静是三板一钟，开静是引磬一下。（第四节 3）
5. **念珠数到母珠掉头**有经文依据；**撞钟一百零八下**、「紧十八慢十八」都见于清规一系文献。（第四节 5、6）
6. **上香先中、再右、再左**只是通行做法，查不到清规条文；界面上不要说成「规矩」。五分钟、十分钟的「短香」也要说明是本应用的设定。（第四节 4、7）
7. `VERSES` 里 `gloss`、`ask` 是本应用的话，`lines / by / from / era` 是古人的，界面上要分开摆。`v23`（布袋和尚插秧偈）标了「传」，文字用的是能查到出处的那一版，与大家熟悉的「手把青秧插满田」不同。

## 一、心经

**所据**：玄奘译《般若波罗蜜多心经》流通本，正文二百六十字。

**与大正藏本的比对**（`C:T0251-1`，T08n0251）：把大正藏本自「观自在菩萨」至咒语末的正文转成简体，也是 260 字；逐字相比，前 242 字全同，只有咒语 18 字里的 7 个译音字不同：

| 位置 | 大正藏本 | 流通本（本数据） |
| --- | --- | --- |
| 咒语 | 揭帝揭帝　般罗揭帝　般罗僧揭帝　菩提莎婆诃 | 揭谛揭谛　波罗揭谛　波罗僧揭谛　菩提萨婆诃 |

- 流通本的咒语用字来历很早：唐靖迈《般若心经疏》（`C:X0522-1`）即作「揭諦揭諦 波羅揭諦 波羅僧揭諦 菩提薩婆訶」，明代宋濂、真可、德清诸家注本皆同；同是唐人，窥基《幽赞》作「菩提莎訶」、圆测《赞》作「菩提莎婆呵」，可见只是译音用字不同。数据取流通、课诵所用的一种。
- 「二百六十字」之数，明谢观光《般若心经释义》（`C:X0540-1`）已说「本文二百六十字」，清代注疏沿用。
- 「远离颠倒梦想」：大正藏本与本数据相同，前面没有「一切」。（通行说法：日本流通本多「一切」二字，计 262 字——这一点我没有逐本核对。）
- 大正藏本「是大神咒」四字俱在，本数据同。

**简体取舍**：

| 原字 | 用字 | 说明 |
| --- | --- | --- |
| 罣礙 | 挂碍 | 「罣」是「挂」的异体（《第一批异体字整理表》归入「挂」），规范简体写「挂碍」。佛教界的简体印本也常保留「罣碍」。全文两处；要换回「罣」只需替换这一个字。 |
| 呪 | 咒 | 大正藏用「呪」，流通本用「咒」。 |
| 揭諦 | 揭谛 | 照简化。 |
| 菩提薩埵、阿耨多羅三藐三菩提、般若波羅蜜多、涅槃、五蘊 | 菩提萨埵、阿耨多罗三藐三菩提、般若波罗蜜多、涅槃、五蕴 | 通行简体。 |

**分段与标点**：`HEART` 按意群分十段（25＋27＋20＋34＋28＋39＋22＋34＋13＋18＝260 字）；`HEART_PUNCT` 的标点是今人所加，从简，只用逗号、句号和一个冒号，不影响字数。

## 四、仪轨与常识的查证结论

每条给：结论、依据、可靠程度。

### 1. 东钟西鼓、晨钟暮鼓

- **结论**：钟楼在东，唐代已是定制。但唐代与钟楼相对的是**经楼（经藏）**，不是鼓楼；钟楼、鼓楼东西对设出现较晚，学界多认为定型于明代，于是有今天的「东钟西鼓」。
- **依据**：
  - 唐段成式《酉阳杂俎》续集卷五《寺塔记上》（长安平康坊菩提寺）：「寺之制度，钟楼在东，唯此寺缘李右座林甫宅在东，故建钟楼于西。」（`W:酉陽雜俎/續集/卷五`，已核对）
  - 唐末黄滔《泉州开元寺佛殿碑记》：「东北隅则揭钟楼……西北隅则揭经楼，双立岳峰。」（`W:黄御史集 (四庫全書本)/卷5`，已核对）
  - 正定开元寺：「晚唐时在正殿前东侧增建钟楼」，与西侧须弥塔相对（中文维基百科「开元寺 (正定)」）。
  - 钟鼓对设的年代：中国佛学院普陀山学院网站《浅析寺院钟鼓楼的雏形及演变历程》（2023）综述各家——萧默主宋代说，多数学者主明代，该文推定始于元末、确立于明代中期。
- **可靠程度**：「钟楼在东」高（唐人明文）；「对面是经楼」高；钟鼓对设的确切年代，中（学界有不同说法）。
- **晨钟暮鼓**：《敕修百丈清规》卷八说大钟「晓击则破长夜、警睡眠，暮击则觉昏衢、疏冥昧」，早晚都撞钟。通行的说法是早晨先钟后鼓、晚上先鼓后钟——这一句我没有查到清规明文，可靠程度中。

### 2. 大殿里大磬与木鱼的位置

- **结论**：通行做法是大磬在东、木鱼在西——面向佛像时，大磬在右手边（佛像的左侧），木鱼在左手边；维那司大磬，悦众司木鱼、引磬等。没有清规明文，个别寺院不同。
- **依据**：来果《高旻寺规约》卷三有「即站佛龛东磬边」（`C:B0098-3`），磬在佛龛之东；同书「维那押大磬」。今人介绍法器的文字多说「大磬置于佛桌右侧，法会、课诵时由维那击鸣」，也有说「佛像左侧」的——一从礼佛者看，一从佛像看，其实是同一侧（这两句来自网络检索的摘要，没有逐篇精读）。
- **可靠程度**：中。

### 3. 禅堂止静、开静敲几下

- **结论**：清代以来的丛林规约，止静是「三板一钟」（木板三下、钟一下；此前依次有一板一钟、二板一钟作预备）；开静是悦众鸣引磬一下（开小静）。各寺细节不同；今天的禅修道场多简化成「三声止静，一声（或两声）开静」。
- **依据**：清仪润《百丈清规证义记》卷八：「闻大鼓完，接三板一钟，止静。……悦众鸣引磬一下，开小静。」（`C:X1244-8`）来果《高旻寺规约》：「即招呼当值三板一钟止静」「当值三板一钟，打得响响亮亮的止静」（`C:B0098-1`、`-3`）。
- **可靠程度**：止静三板一钟，高；开静一下，中高；「各寺不同」是实情。

### 4. 上香三支的插法

- **结论**：查不到清规条文。通行的指引是先插中间、再插右边、再插左边，分别默念供养佛、供养法、供养僧；也有不少寺院提倡只上一支。左右以谁为准、口诀字句各处不一。「三支表戒定慧」「表佛法僧」同属通行说法。
- **依据**：网上流传的上香须知（如「上香时以一支为宜，若要上三支，第一支插中间（供养佛）、第二支插右边（供养法）、第三支插左边（供养僧）」）；在 CBETA 全藏里检索不到相应的规定，《敕修百丈清规》里只有住持烧香、拈香的仪节。
- **可靠程度**：低到中——是民间与寺院的通行做法，不是清规所载。

### 5. 念珠一百零八颗；母珠不越过

- **结论**：一百零八颗有经文依据；数到母珠不越过、掉转回头也有经文依据（出自唐代密教念诵法），汉地通行。
- **依据**：
  - 《佛说木槵子经》（`C:T0786-1`）：「当贯木槵子一百八，以常自随。若行、若坐、若卧，恒当至心，无分散意……乃过一木槵子」，又说满百万遍「当得断除百八结业」。
  - 《佛说校量数珠功德经》（唐宝思惟译，`C:T0788-1`）：「其数珠者，要当须满一百八颗。如其难得，或为五十四，或二十七，或十四，亦皆得用。」
  - 《金刚顶瑜伽念珠经》（唐不空译，`C:T0789-1`）：「母珠以表无量寿，慎莫蓦过越法罪。」
- **可靠程度**：高。

### 6. 撞钟一百零八下

- **结论**：一百零八下见于清规；「紧十八、慢十八」的敲法也有清规一系的来历，各地敲法不一。
- **依据**：
  - 《敕修百丈清规》卷八·法器章（`C:T2025-8`）：「引杵宜缓，扬声欲长。凡三通，各三十六下，总一百八下，起止三下稍紧。」
  - 《禅苑清规》（据无著道忠《禅林象器笺》卷十三、卷二十七所引，`C:B0103-13`）：「打大钟之法，先轻手拟钟三下，慢十八声，紧十八声，三紧三慢，共一百八声。」——我没有在 CBETA 的《禅苑清规》本文里直接检到这一句，只见于《象器笺》的引文。
  - 同书引《群谈采余》：一百八声是「一岁之义」——十二月、二十四气、七十二候合得此数；并录各地歌诀，如杭州「前发三十六，后发三十六，中发三十六声急，通共一百八」，越州「紧十八，缓十八，六遍凑成一百八」。
- **可靠程度**：一百八下、三通各三十六，高；紧慢的具体敲法，中（各地不同）。「一百零八表百八烦恼」是通行解释，上引文献给的是历法的解释。

### 7. 一炷香多久；坐香、行香

- **结论**：没有统一的时长。民间说一炷香约半个时辰；禅堂里「一支香」是一段行、坐的单位，长短随冬夏、时段由看香的人调度，从二三十分钟到一个多小时都有。坐为「坐香」，坐前在堂内绕行快走为「行香」，俗称「跑香」，行坐相间。
- **依据**：《高旻寺规约》卷三「四季定香式」：「看香一职，贵在调度……须按冬夏昼夜长短得宜，定之以香，准之以钟。」又说行香「按时不同……夏天日长，粥饭后用二板香经行……冬天日短，行香不宜长」（`C:B0098-3`）。今人的记述（网络检索摘要）：云居山禅堂仪规「大行香约二十五分钟」，少林寺禅七「一炷香约一个小时」。
- **可靠程度**：中。应用里五、十、十五、三十分钟的「短香」，宜明说是本应用的设定。

### 8. 唐风建筑的几点依据

- **佛光寺东大殿**：唐大中十一年（857）建；1937 年梁思成、林徽因等考察发现，据梁上题记与殿前经幢定年。「檐口曲线平缓，出檐深远。中部五间开木板门，两尽间和山面后间设直棂窗。」（中文维基百科「佛光寺 (五台)」）
- **南禅寺大殿**：平梁下墨书「大唐建中三年……重修殿」，即 782 年，比佛光寺东大殿早 75 年；面宽、进深各三间，单檐歇山顶。（中文维基百科「南禅寺 (五台)」）
- **朱白（朱柱白壁）**：佛光寺祖师塔「塔外墙原绘有土朱色的额枋、人字拱等构件图案」（同上「佛光寺」条），即在白壁上用土朱画出木构。唐代木构刷土朱、墙面刷白，是建筑史的通说（敦煌壁画、唐墓壁画所见多如此）；这句通说我没有逐条核对原始文献。
- **直棂窗**：见上佛光寺东大殿；长子法兴寺唐代燃灯塔的塔身也雕有棂窗。
- **鸱尾**：南北朝至隋唐是月牙形的鸱尾，唐代中后期逐渐突出吻部、张口吞脊，成为「鸱吻」，宋代定型。（中文维基百科「鸱尾」）
- **人字栱**：北朝到唐代常见的补间做法——云冈、天龙山石窟可见；西安大雁塔门楣线刻佛殿图「补间斗栱则是人字形上托短柱」；佛光寺祖师塔壁上也画着人字栱。（中文维基百科「斗栱」「佛光寺 (五台)」）但晚唐的佛光寺东大殿本身，补间已不用人字栱。
- **可靠程度**：年代与形制，高；「朱白」，中（通说，未核原始文献）。

### 9. 石灯（燃灯塔）在中国唐代的实物

- **结论**：中国早有石灯，唐代有实物存世，是中国本有的，不是日本独有。
- **依据**：中文维基百科「燈籠 (建築裝飾)」：中国的石灯笼「盛行于魏晋南北朝至唐代……五代之后逐渐少见。佛寺一般都在殿堂正前方设置石灯」；现存最早的是太原童子寺北齐石灯，唐代有山西长子法兴寺石灯、陕西乾县石牛寺石灯（今藏西安碑林）、河北曲阳北岳庙石灯，另有黑龙江宁安渤海国上京兴隆寺石灯。法兴寺燃灯塔：单层石塔，通高 2.6 米，青石，八角，基座壸门隔柱上有唐代题记，塔身四面雕门、四斜面雕破子棂窗。（「法兴寺 (长子)」条）
- **年份**：法兴寺燃灯塔通行说法是唐大历八年（773）建；京都大学人文科学研究所的旧照片档案只标「大历间」。我没有见到题记原文。
- **可靠程度**：有唐代实物，高；773 这个年份，中。

### 10. 小雁塔

- **结论**：唐景龙年间（707–709）建于荐福寺，密檐式方形砖塔；原十五层，明代地震损毁塔顶两层，现存十三层，高约 43.3 米。底边 11.38 米，由下而上逐层收分，轮廓圆和；塔壁不设柱额，每层砖砌叠涩出檐，檐下砌两层菱角牙子；底层南北开券门，二层以上南北开拱窗。
- **依据**：中文维基百科「小雁塔」。
- **可靠程度**：高。

### 11. 圆相（一圆相）

- **结论**：圆相是中国禅宗本有的，出自唐代南阳慧忠、经耽源应真传到仰山慧寂，成为沩仰宗的家风；不是日本独有。日本禅林的「円相」书画是承此而来的。
- **依据**：宋智昭《人天眼目》卷四（`C:T2006-4`）：「圆相之作，始于南阳忠国师，以授侍者耽源，源承谶记传于仰山，遂目为沩仰宗风。」宋善卿《祖庭事苑》卷二（`C:X1261-2`）、《从容庵录》卷五（`C:T2004-5`）所记相同。
- **可靠程度**：高。

## 五、没收的

**今人伪托或出处不实，不收：**

- 「一花一世界，一叶一如来」——不是《华严经》原文。CBETA 检索：宋代语录里有「一花一叶一如来」（死心悟新、瞎堂慧远），「一花一世界，一叶一如来」到清代语录才见（如《雨山和尚语录》卷七）；意思近于《梵网经》的「一华百亿国，一国一释迦」。因为总被冠以「佛说」「《华严经》云」，不收。
- 「不忘初心，方得始终」——CBETA 全藏检索无此句，不出《华严经》。
- 「前世五百次的回眸，才换来今生的擦肩而过」——无任何经典出处。
- 各种冠以「佛曰」「佛说」的白话语录，以及挂在仓央嘉措名下的「那一世，转山转水转佛塔」（当代歌词）。
- 「扫地扫地扫心地，心地不扫空扫地」——CBETA 检索无。只在 `QUOTES.sweepFolk` 里留作俗语，标「出处不详」，不进签筒。

**文字靠不住，换了或改了：**

- 「手把青秧插满田……心地清净方为道」——通行文字查不到早期出处，换成《定应大师布袋和尚传》的文字（v23），标「传」。
- 「灭却心头火自凉」——《全唐诗》作「灭得心中火自凉」，v64 从《全唐诗》。
- 「曲径通幽处……万籁此俱寂」——v47 从《全唐诗》正文「竹径」「都寂」，异文注在出处里。

**没能核对原文，暂不收：**

- 陈与义《焚香》（「即将无限意，寓此一炷烟」）——维基文库无此诗页面。
- 川禅师（冶父道川）「竹影扫阶尘不动，月穿潭底水无痕」——CBETA 里见于宋《密庵和尚语录》和明《金刚经补注》所引「川禅师颂」，没来得及核对道川《金刚经注》原书。
- 苏轼名下的《观潮》（「庐山烟雨浙江潮」）——没有查实是否见于苏轼本集。
- 所谓黄庭坚「香之十德」——没有查到见于黄庭坚本集的证据。
- 「偷得浮生半日闲」（李涉《题鹤林寺僧舍》）——不是伪托，只是没选；《全唐诗》正文作「又得」，「偷」是一作。

## 六、没能查实、需要留意的

1. 核对底本都是电子录文（CBETA、维基文库），没有对照纸本、影印本。
2. 以下各点只到「通行说法」的程度：大磬与木鱼的左右、上香三支的次序与含义、一炷香的时长、晨钟暮鼓的先后、「朱柱白壁」的文献依据、法兴寺燃灯塔的确切年份、日本流通本心经 262 字之说、「石灯成列是日本做法」这句判断。
3. 《禅苑清规》「慢十八声，紧十八声」一句，只见于《禅林象器笺》的引文，没有在《禅苑清规》本文里直接检到。
4. 《四十二章经》《八大人觉经》的译者年代是旧题，学界有疑；数据里的朝代照旧题写。
5. v23 首字「手」是据《明州岳林寺志》改的（续藏本作「牛」）；v26「踏遍」是通行文字（文库本《鹤林玉露》作「蹈遍」）；v83 末句据《茗笈》引文。
6. 中文维基百科的条目（建筑、石灯、小雁塔）是二手资料，其中个别表述没有注明来源。
