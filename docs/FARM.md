# 农事（`src/world/farm/`、`src/world/acts/farm*.ts`）

行者自己种的几畦地，与晒场上打场、扬场、推磨的那一套。《宋史·邵雍传》说他在洛阳「岁时耕稼，仅给衣食」——先生不是农夫，几分薄田、一畦菜，够吃就好；麦熟时也帮邻家割一截。

## 一畦地的账（`model.ts`，存在 `k.mem` 的 `'farm'`）

```jsonc
{
  "v": 1, "season": "summer", "day": 3,           // 照哪一季记的、记到第几日
  "beds": {
    "west": {
      "id": "west", "crop": "wheat", "stage": "ripe",   // 荒 wild · 翻过 tilled · 下了种 sown · 出苗 sprout · 长高 growing · 熟了 ripe · 收过留茬 stubble
      "grow": 0.3, "water": 0.6, "weed": 0.2, "care": 0.6,   // 这一步长了几成、土墒、草、照看得好不好（定收成）
      "sownIn": "autumn", "age": 3,                     // 哪一季下的种、下种后过了几季
      "op": "reap", "rows": [1, 0.4, 0, 0], "bound": [1, 0, 0, 0],   // 正一垄一垄做的那件事（till/sow/reap），每垄做到哪儿；割麦时每垄捆到哪儿
      "sheaves": 3,                                     // 捆好立在地里、还没挑走的麦捆
      "left": null                                      // 过了季没收的，邻家帮着收了放在地头：{ item, n }
    },
    "east": { … }, "vegE": { … }, "vegW": { … }
  },
  "village": [1, 0.35, 0, …],                          // 邻家那片麦每一垄割到哪儿（夏天；换季清零）
  "floor": { "crop": "wheat", "spread": 12, "beaten": 0.4, "heap": 0, "straw": 0 },   // 晒场：摊着几捆、打到几成、连糠带粒的几升、秸秆
  "gift": true, "pantry": { "wheat": false, "gu": false },   // 头一回的种给过没有；家里缸里去年的麦、谷子取过没有
  "work": 17, "helped": 2                             // 做过几件农活；帮邻家割完过几垄
}
```

**农时**（`src/data/farm.ts` 的 `CROPS`，合北宋洛阳一带的旱作）：

| | 下种 | 各季长到哪 | 收 |
| --- | --- | --- | --- |
| 冬麦 | 秋 | 秋、冬：出苗（冬天苗在雪底下）；春：长高；夏：黄熟 | 夏（割麦 → 捆 → 挑 → 打场 → 扬场 → 磨面） |
| 谷子（粟） | 春、夏（麦后晚谷） | 春夏：长高；秋：熟 | 秋（掐穗 → 打谷 → 水碓舂米） |
| 豆 | 夏（麦后） | 夏：长高；秋：熟 | 秋（拔豆） |
| 菜 | 春、夏、秋 | 当季就熟（春小白菜、夏苋菜、秋白菜萝卜） | 当季（摘菜） |

**时间怎么走**：

- 过一夜（`k.onDay`）：庄稼长 0.6 天（夜里长得快），土干一点、草长一点；下雨地就湿。
- 时辰流转着：每过半个时辰按钟点算一次（一天就是一天）。
- **时辰停着时**：每做完一件农活，正长着的庄稼长 0.22 天（`WORK_PUSH`）——三四件活出苗。
- 庄稼长到**这一季的上限**就停：秋天种下的麦，秋天里只到出苗，要等开春、到夏天。
- **换季**（界面上随时能换）一律当作「往后过了几季」，一季一季地过（夏→春是过了秋、冬）：庄稼长到那一季的上限；熟了没收的过了季，邻家帮着收了放在地头（`left`，回来「取回」或「挑麦」）；没熟就过了季的枯了；茬子、翻过没种的地长满了草；邻家那片麦重新算。
- 土墒低于 0.3、草多于 0.5，长得慢、照看分往下掉；浇水、锄草把它往上拉。照看分定收成：一垄收 `perRow × (0.6 + 0.6 × care)`。
- 夜里（`night > 0.62`）田里的活都不做；冬天地冻，不翻不种；下雨天场上不打不扬（会说为什么）。

**头一回来**（`freshState`，按此刻的季节）：春——西畦去秋种的麦正返青、东畦是谷茬（翻地种谷）、菜畦东头小白菜能摘；夏——西畦麦黄了（开镰）、东畦谷子长高了；秋——西畦留茬（翻地种麦）、东畦谷子熟了（掐穗）、菜畦白菜熟了；冬——麦苗在雪底下。头一回要下种而行囊里没有种时，「灶屋梁上挂着去年留的种」：麦种三升、谷种二升、豆种二升、菜籽三包（只给一回）。麦粒、谷子、豆本身也能当种。头一回推磨、舂米而行囊里没有粮时，「缸里还有去年的麦子」「囤里还有去年的谷子」，各舀四升（只一回）——冬天也有活做。

## 各件事（`acts/farm.ts`、`farmYard.ts`、`farmMore.ts`）

每一畦各有：翻地、下种、浇水、锄草、收（西畦东畦按庄稼分割麦 / 掐穗 / 拔豆，菜畦是摘菜）、挑麦（粮畦）、取回。哪件此刻能做，画里才浮出它的签（`on()`）。做到一半走开，下回从做到的地方接着做（`spot` 跟着挪）。

| id | 名 | 怎么做（手感） |
| --- | --- | --- |
| `farm:till:<畦>` | 翻地 | `hold`「锄」：按住举锄（`meter`「力道」），举到朱色那一段（0.62…0.94）松手落下翻得深；举过了头往回落。一锄一步，一垄翻完掉头翻下一垄。约半分钟一畦 |
| `farm:sow:<畦>` | 下种 | 先 `items` 挑种（这一季能下的那几样）；`hold`「撒」：按着就顺着垄走，一把一把撒（种子飞出去落在垄上） |
| `farm:water:<畦>` | 浇水 | 行囊里要有水。`hold`「浇」：一瓢一瓢地泼，`meter`「土墒」到 0.64…0.93 就够；浇过了头地里汪着水 |
| `farm:weed:<畦>` | 锄草 | 垄沟里的草各钉一枚 `tags`「草」；点签（或点草），人走过去蹲下拔掉 |
| `farm:reap:<畦>:wheat` | 割麦 | `hold`「割」：一镰一镰割过去，割下的铺成一溜；够一捆了键换成「捆」，按住捆好立在地里。割几把、捆一捆 |
| `farm:reap:<畦>:millet` / `bean` / `vegX:greens` | 掐穗 / 拔豆 / 摘菜 | `hold`：顺着垄一穗一穗掐、一棵一棵拔、一棵一棵摘，收进行囊 |
| `farm:load:<畦>` | 挑麦 | 立在地里的麦捆（连同邻家放在地头的）挑上肩，一回最多十六捆。之后行囊里有麦捆、水、谷穗时人右肩上挑着扁担（一头在前一头在后，随步子颤）：不跑（行者那边给了步子快慢的钩子就慢些）。面板上「挑到场上」：过石桥、顺村路一段一段地自己走到晒场，到了就打场（半路一动手就作罢） |
| `farm:take:<畦>` | 取回 | 地头邻家帮收下的谷穗、豆、菜 |
| `farm:help` | 帮割 | 夏天，邻家王伯的麦，割一截（十四镰），王伯塞一把新麦 |
| `farm:thresh` | 打场 | 挑来的麦捆（或谷穗）摊成一圈；连枷一起一落，`meter`「起落」到顶（0.74…1）时按下去打得实。麦打完是一堆连糠带粒的（每捆 1.6 升）；谷穗直接打成谷子（`gu`） |
| `farm:winnow` | 扬场 | `hold`「扬」：按住铲一锨，看 `meter`「风」（0.4…0.82 是好风）松手扬出去：好风得一升麦，风小糠扬不走，风大麦粒刮跑 |
| `farm:grind` | 推磨 | `hold`「推」：扶着磨棍绕着磨走，一圈一升麦成一升面 |
| `farm:pound` | 舂米 | 溪上水碓（屋舍那边的 `millHammer` 自己起落）。`meter`「碓头」抬起来（≥ 0.55）时按「翻」；落下来时伸手会挨一下（不算，振一振） |
| `farm:dip` / `farm:dip2` | 打水 | 溪边，`hold`「舀」：桶按进水里灌满自己提上来，一担两桶 |
| `farm:well` | 打水 | 井上，`hold`「摇」：摇辘轳桶一点点升上来，一松手往下滑；到井口提过来倒进自己桶里 |
| `farm:peach` | 摘桃 | 夏，石桥边那株桃（桃子挂在它夏天的叶底下）；`hold` 伸手够一个拧下来，一天长回几个 |
| `farm:jujube` / `farm:persimmon` | 打枣 / 摘柿 | 秋，竹竿：打枣枣子落一地再蹲下拾；柿子用竿梢的杈子一个一个夹 |
| `farm:mulberry` | 采桑 | 春夏，桑园西北角那一株，挎篮一把一把采 |

面板 state 用的都是界面那一路的约定（`src/app/acts/state.ts`）：`hold`、`meter`、`steps`/`step`（这样庄稼的农事链走到哪一步）、`items`、`tags`、`keys`、`progress`、`count`/`total`、`choices`（主操作带 `main`）、`done`。做完一件记一笔 `k.log({ kind: 'farm', text: '割了西畦的麦，捆了十二捆' })`；收成进 `k.bag`。

## 行囊

用的共用 id：`sheaf` 麦捆、`wheat` 麦粒、`flour` 面、`milletEar` 谷穗、`millet` 小米、`bean` 豆、`greens` 青菜、`peach`、`persimmon`、`jujube`、`mulberryLeaf`、`seedWheat`、`seedMillet`、`seedBean`、`seedGreens`、`water`。
新登记的：**`gu` 谷子**（升）——打下来带壳的谷粒，水碓舂过才是小米；也能当谷种。

## 给别人的（`import … from 'src/world/farm'`）

```ts
farmPlotState(i)   // i 是 0…3 或 'west' 'east' 'vegE' 'vegW'：{ id, name, crop, cropName, stage, stageName, ripe, water, weed, sheaves, rect }；农事还没建好是 null
farmPlots()        // 四畦都给（没建好时给位置、stage 'wild'）
farmReapSpot()     // 邻家那片麦该从哪儿接着割（夏天才有，割完了 null）：{ x, z, yaw, row, f }——人站在这里、面朝东（yaw π/2）
farmReapStep(m, who = 'farmer')   // 往前割 m 米（村里人一镰约 0.6 米）；返回这一下割完了一垄没有。画面跟着变
FARM_SITE          // { beds: [{id, name, x0, x1, z0, z1}…], village: {x0, x1, z0, z1, rows}, floor: {x, z, r}, mill: {x, z, r} }
farm()             // 整个农事（Farm）：.st 账、.bed(id)、.changed(id)、.worked(text)……
```

- **村人那一路**：夏天让农夫去割麦，就 `farmReapSpot()` 走过去、一镰一镰 `farmReapStep(0.6)`；`null` 了就收工（`life/harvest.ts` 已经这样接上：王伯割、二郎捆、拾麦穗的看 `farm().st.village` 找割过的垄）。秋天在晒场上打谷请避开 `FARM_SITE.floor`（圆心 61.6, 8.6，半径 2.95）与 `FARM_SITE.mill`（67.6, 9.1，半径 1.7）——晒场北半边（晒席、碌碡那边）都空着。`spots.ts` 的 `THRESH` 眼下在井田当中那一畦里，与这里不冲突。
- **说话那一路**：行囊里的 `flour`、`millet`、`wheat`、`peach`、`jujube`、`persimmon`、`greens` 都是能送人的收成；农夫也可以给种子（`k.bag.add('seedMillet', 1)`）。`farm().st.helped` 是帮邻家割完过几垄。
- **动物那一路**：喂鸡可以用 `millet`、`wheat`、`gu`。

## 画法

- **畦面**（`soil.ts`）：每畦一张贴地的网（0.2 米一格），外加一圈矮埂；翻过的起垄（垄脊、垄沟）、颜色深一层，浇过更深；翻到哪儿垄起到哪儿。两畦外头的走道铺一层土色，盖住底下麦地的底色。所有畦一次绘制。
- **庄稼与草**（`paint.ts`）：点叶那一套（`dabMat`），借草木那边的麦苗、熟麦、麦茬、谷穗、菜、豆、草的格（同一个样子），自己另画麦铺、麦捆、土块、种子、谷秆、萝卜、果子（`tiles.ts`）。每一笔的大小、偏移由坐标定的伪随机给，重画时不跳。一池笔开够大，变了就重写（一次绘制）。
- **飞起来的**：土块、种子、水点、糠、麦粒、草屑、叶、果，一池 160 笔，受风（糠顺风飘）。
- **石磨、麦堆、家什**（`props.ts`）：照真粗细建，颜色在顶点上，三种材质（木、石、粉）。锄、连枷借村里人那一套。

## 量过的

无头 Chrome（同一机位把农事整个藏起来再比）：

| 机位 | high | low |
| --- | --- | --- |
| 田畴（两畦与邻家麦）、石桥上望田、菜畦 | +10.4 千三角、+3 绘制 | +10.1 千三角、+3 绘制 |
| 晒场（场、石磨） | +2.2 千三角、+4 绘制 | +1.9 千三角、+4 绘制 |

畦面（连走道）约 8 千三角，田里的笔夏天约 860 笔（high）/ 710 笔（low），石磨约 2 千三角。不重画时每帧约 0.001 毫秒；整个重画一回约 2.6 毫秒（只在田里变了时才画，割麦时约一秒一回）。建造约 15 毫秒（`k.timings.farm`）。做事时另有手里的家什（一次绘制）、飞起来的笔（有时一次）；挑担子时扁担三次。
