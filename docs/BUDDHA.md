# 大殿的佛像

一尊唐风的释迦牟尼坐像（结跏趺坐、禅定印），连同仰覆莲台、八角须弥座、舟形火焰背光。
入口：`src/world/props/buddha.ts` 的 `createBuddha(mats, q)`。

## 尺寸与原点

- 原点在须弥座底面正中，面朝 +z，像的左手在 +x。
- 须弥座高 1.0（外接圆半径 1.9，八角）；莲台高 0.7（瓣尖处半径约 1.65）；坐处（莲台面）在 y = 1.7。
- 坐像自坐处到肉髻顶 3.19，膝距约 2.7，肩宽约 1.6；眼睛在 y ≈ 4.23（`userData.eyeY`）。
- 背光宽 3.72，底立在须弥座后沿（z ≈ −1.68），顶在 y = 5.62 并向前倾约 0.68。总高 5.62（`userData.height`）。
- 殿里放的时候：须弥座后面要留出背光的倾斜（背光最靠后在 z ≈ −1.68）；明间内柱之间净宽要大于 3.9。

## 形制的取舍与依据

查到的（只有这些，别的不要当成查证过）：

- 龙门奉先寺卢舍那大佛（初唐）：面容饱满、眉弯如新月、目长而下视、嘴角带淡淡的笑，保护调查里记「双唇微闭、嘴角深陷」；头发是水波状。见中新网 2022 年关于龙门卢舍那保护调查的报道（<https://www.chinanews.com.cn/cul/2022/06-02/9770399.shtml>、<https://www.chinanews.com.cn/cul/2022/08-24/9835115.shtml>）及澎湃、科技日报的同题报道。这些是检索摘要里读到的，我没有逐篇核对原文。
- 入唐以后「半偏袒式」（袈裟不同程度盖住右肩）成为佛衣的主流样式之一；唐代衣纹比北魏圆润。见澎湃 <https://www.thepaper.cn/newsDetail_forward_8536021>；偏袒右肩的本义见 JAANUS <https://projects.mcah.columbia.edu/jaanus/node/4114>。
- 佛光寺东大殿建于唐大中十一年（857）。它的主尊、须弥座、背光的具体形制**没有查到**可靠描述。

我定的（合乎常见的唐代造像，但没有逐项出处）：

- 面相丰圆（丰颐）、眉细长而弯并与鼻梁相接、双目垂视成一道长而平的弧、唇小而厚且两角微扬、白毫、长耳垂珠、颈有三道。头向前俯 7°，是给下面礼拜的人看的。
- 发用螺发（卢舍那是水波发，这里没有照它）：约 350 颗，自发际一圈圈排到顶，肉髻低平。发是绀青色，不贴金。
- 衣：袈裟覆双肩、胸前敞成 U 形，里面僧祇支自左肩斜向右胁；衣缘是一道圆润的边；衣纹只留两处——胸腹上自左肩斜垂下来的几重弧、腿上自膝至膝的几道弧——取「疏朗」，不做密纹。两臂有袖盖着，手自袖中出。
- 手：禅定印，右手叠在左手上，掌心向上，两拇指尖相触成一个圆缓的弧。足不露（被衣盖着）。
- 座：八角须弥座（上下各两层叠涩、束腰每面一个壶门，朱漆描金）；莲台是覆莲两重、束腰连珠、仰莲三重。
- 背光：舟形，边缘一簇簇焰尖；头后圆光（十六瓣莲花、连珠、弦纹），身后身光（连珠、弦纹），其外火焰纹。

## 做法

1. **塑**：`tools/buddha/figure.mjs` 用有符号距离场写出整尊像——椭球、圆台、圆角盒的平滑并 / 减。
   五官以「大形表面」为准定位（`frontZ`）；眉、睑缘、唇缝、颈纹是加在表面上的高斯状细线；衣是在身形上按「盖没盖到」加一层厚度，衣缘、衣纹都是这层厚度的起伏。
2. **出网格**：`tools/buddha/nets.mjs`（surface nets：粗格筛一遍、细格出点、沿梯度推到表面、法线取场的梯度）。
   分四块各用各的格子：身 `body`、头面 `head`、发 `hair`、手 `hands`。头身的分界是一个前低后高的斜面（下巴底整个归头），两边各多留 1.2 厘米互相压着，法线与顶点色取自同一个场，所以接缝看不出来。被发盖住的头皮、切口上的封盖面都丢掉。
3. **顶点色**：没有贴图。按「凹处的遮蔽」（沿法线取几个距离看场的值）把衣纹里、眼窝、唇缝、指缝压暗并偏赭，像积了年头的旧金；肉身最亮，袈裟略沉，僧祇支更沉；再加一点低频的深浅。
4. **两档**：细档约 13.9 万三角（身 4.8 万、头面 5.3 万、发 2.1 万、手 1.8 万），粗档约 3.9 万。粗档格子分不清细处，所以烘粗档时把衣纹收浅、眉眼唇颈的线放宽、衣缘的台阶放缓（`setDetail`）。
5. **写文件**：`public/models/buddha.bin`（细）、`buddha-low.bin`（粗）已经 gzip 过（约 743 KB / 237 KB），浏览器里用 `DecompressionStream` 解；`buddha-low-raw.bin`（688 KB，没压）给没有 `DecompressionStream` 的旧浏览器。格式见 `bake.mjs` 顶上的注释（分片、存差，为的是压得动）。
6. **运行时**：`buddha.ts` 取回来拼成 `BufferGeometry`（位置、法线、顶点色、索引）。取不到时退成一个车削的坐像剪影，殿不会崩。
   须弥座、莲台、背光在 `buddha/throne.ts` 里现搭：莲瓣是有厚度的曲面、实例化；背光的纹样逐像素算成高度图 → 法线贴图、明暗、透明（舟形与焰尖）、微光。

重烘（改了 `figure.mjs` 之后）：

```
node tools/buddha/bake.mjs              # 两档都烘，约 6 秒
node tools/buddha/bake.mjs --only=high  # 只烘细档
node tools/buddha/bake.mjs --scale=1.5  # 格子放大（调形时出得快；别把这样烘的文件提交）
```

改了头的大小 / 位置（`HS`、`OH`、`PIV`）后，记得把 `buddha.ts` 里的 `EYE`、`TOP` 两个高度改对（`TOP` 是烘出来的发那一块的最高点）。

## 接口

```ts
const bd = await createBuddha(mats, quality);   // THREE.Group，原点在座底中心，面朝 +z
scene.add(bd);
bd.userData.eyeY;    // 眼睛的高度（镜头对准这里）
bd.userData.height;  // 总高
bd.userData.glow;    // 背光的材质：emissiveIntensity 0…1（1 也只是微微泛光），随烛光调
bd.userData.gold;    // 金身（也用于莲台）；bd.userData.hair：发
```

- 档位：`quality.tier === 'low'` 或 `quality.mobile` 用粗档。
- 材质都是内置的 `MeshStandardMaterial`，没有 `ShaderMaterial`；金身、莲台、背光由 `mats.gold` 经 `variant()` 派生（已接雾），发是新建的普通材质，交给 `adopt()` 接雾。
- 殿内昏暗时，把 `gold / hair / glow` 的 `envMapIntensity` 压到 0.3–0.4（不然金身会映出殿外的天）。

## 灯怎么打才好看

- 脸不能只靠自下而上的烛光（下巴、鼻底亮，眉眼反而暗）。要有一点**自前上方来的柔光**——殿门进来的天光，或梁下的长明灯。台子里 `buddhaHall` 的摆法可以参考：供桌两支烛（低、近）、两侧各一盏、前上方一盏暖色点光、极弱的一道冷色天光。
- 金身粗糙度 0.4、金属度 0.92：点光给出的是一片片柔和的高光，别把烛光强度开太大（会被泛光吃成一团）。

## 还不够好的地方

- 眼是闭成一线的「垂目」，没有做半开的眼与眼珠；近看（2 米内）睑缘、眉线能看出是软的线而不是刻出来的棱。
- 手近看指节是圆润的整段，没有指甲、关节的细处；从上往下看手背的结构简单。
- 腿是被衣盖着的一整团，没有露足；侧面、背面只有大形，没有衣纹（背面本来就被背光挡着）。
- 背光是三层薄板叠出来的厚度，正侧面看仍然薄；焰尖是程序化的，略显规整。
- 佛光寺等唐代实例的座与背光形制没有查到出处，这里的组合是按常见样式定的。
