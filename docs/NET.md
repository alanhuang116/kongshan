# 同游：在园子里遇见别的游人

不同的人打开安乐窝（GitHub Pages 上那一份、服务器上那一份都一样），连到同一个中转，同一间屋子（24 个座位，座位按报过位置的人算）里的人互相看得见：
各人画成一位穿不同衣色的读书人，头上一枚小名签；走近了可以作揖（对方闲着会还礼）、说一句现成的话、同行。
连不上、断了，照样一个人玩，过一会儿自己再连。

## 连哪里

- **国内正式站（`https://anlewo.iwenxuai.com`，K8s）连同源的 `wss://anlewo.iwenxuai.com/ws`**：Ingress 把 `/ws` 反代到集群里的 `kongshan-relay`（`deploy/k8s/relay.yaml.tmpl`），不出国，延迟二三十毫秒。
- GitHub Pages 那一份与法国服务器上的那一份仍连法国的中转 `wss://kongshan.169-58-39-104.nip.io/ws`（`words.ts` 的 `DEFAULT_RELAY`），在法国那台机器的 Caddy 后面。
- 默认连哪个由 `words.ts` 的 `defaultRelay(host, secure)` 定：网址的 host 在 `SAME_ORIGIN_HOSTS`（目前只有 `anlewo.iwenxuai.com`）里就同源，否则连法国的。加一个新的域名时两边都要动：这里加进名单，中转的 `ORIGINS` 也要放行（`server/relay.mjs`）。
- 网址：`?ws=ws://localhost:3820/ws` 连本机的中转（试的时候）；`?ws=0` 不连；`?ws=1` 连默认的（在哪个站上就是哪个站的默认）。
- **开发服务器（vite dev）与自动测试（`navigator.webdriver`）默认不连**，要连就在网址上给 `?ws=`：几个人同时在一台机器上跑检查，连不上线上中转时浏览器会在控制台报一句，别人的检查是收报错的。不连的时候界面上同游的那一枚也不出。
- 题名页上不连：走进园子（界面到了走动的那一段，plugins 画出来）才连。`?ui=0` 或 `world.html` 又明说了 `?ws=` 的，画一淡开就连（截图用）。

## 线上传什么

没有一个自由写的字。名字是 `[第一张名单的序号, 第二张的序号]`（32 × 16 = 512 个雅号，如「伊川」+「散人」），衣色、话、处、事、姿态都是单子上的序号。

自己的样子一秒至多报八回、没变就不报：`[ct, x, y, z, 朝向, 速度, 处, 事, 姿态, 藏]`——
`ct` 是自己这边的钟（毫秒，连上那一刻起算，只增不减）；坐标落到厘米；事是 `k.act` 的 id 冒号前那一截在单子上的序号（不在单子上是 −1，别人那边就不说他在做什么）；
姿态是身子此刻的 `pose`（站、跪、盘坐、蹲、坐凳、仰卧）；**藏**是 1 时别人那边不画他：身子挂在秋千、船上（`root` 的父亲不是场景）、正在换处（`nav.busy`）、画还在雾里。

中转每 100 毫秒一拍，把这一拍里动过的人打成一条发给同屋各人；作揖、说话、同行随来随转。消息的样子见 `server/core.mjs` 与 `wire.ts`。

园中天时（2026-11-25 起）：屋里**排第一**（最早进来、还在的那一位）报 `{ t: 'sky', d: [时区（分钟，东八区 480）, 天气序号] }`——变了就报，一分钟再报一回。
中转只收排第一的那一位报的（别人报的不收、不算不对），记着这一份、转给同屋的人：`{ t: 'sky', fr, d }`；后进门的在 `wel` 里多一项 `sky: [报的那一位, 时区, 天气]`。
那一位走了，这一份就作废，等下一位排第一的报。天气的单子在 `proto.json` 的 `weathers`。版本号没动：旧的客户端不认 `sky`、照旧各画各的天时；新的客户端连着旧的中转，报的 `sky` 被当成不认得的种类（一分钟一回，不会被断开），各人退回按自己这里的此刻走。

## 别人的身子怎么画得顺

- **按他那边的钟插值**（`interp.ts`）：每一份样子带着他那边的钟。这边画的是「他那边的 lag + 280 毫秒以前」——lag 是近六秒里「到这边的时刻 − 他那边的钟」的最小值（两边钟差加上最快的那一程路），
  280 毫秒留给中转攒一拍（100）、他那边隔一拍才报（125）与路上的抖动。于是手里总有前后两份可以插：匀，不抖，不顿。lag 变了每秒最多挪 40 毫秒（差得太多才一步过去）。
- 他那边报的钟记的是**位置算出来的那一刻**：这份 tick 排在总装的 update 前头，读到的是上一帧走完时的位置，所以钟也记上一帧的（不然帧长一抖，钟与位置对不齐，速度就一跳一跳）。
- 进门时中转给的「各人最后报过的那一份」是旧账：收进来当起点，不拿它量 lag。
- 两份之间离得太远（换处、被搬过去，超过 6 米）不插，到了时候一步过去；身子也直接站过去，不走。
- 最后一份之后来不及了：走得快的顺着最后的速度往前推一点（至多 0.15 秒，再用两倍的时间退回来）；真停下了的不推。
- 步态只看此刻画出来的位移（插值出来的那条路），所以着地的脚不滑；坡度、转身的快慢也从这条路上量。

量到的（`together.mjs`，甲用真实按键走 2.6 秒，乙那边每帧记甲的位置）：走着的那一段每帧速度的离差约 3%，没有一帧原地不动、没有往回；甲停下后乙那边差 1–2 毫米。

## 别人什么样

与村里人同一副身子（`avatar/Figure`，粗一档的网），读书人那一身（长衫、软巾），换一种衣色：黛、赭、苍、缃、藕、青、墨、檀，都是淡彩，透在纸上，与村里人的靛灰、赭、素白放在一起不跳。
自己是月白，别人没有月白，一眼认得出哪个是自己。雅号的后半截定几样小处：钓叟、渔父戴斗笠，樵子背着斗笠，野老、老圃须发花白、老圃不戴巾，书生、游子没有须。

- 他坐、跪、蹲、仰卧（读书、抚琴、观星……），这边也是那个姿态、在那个高度上（报来的 y 已经含着蒲团那一点高）；手上的细动作（拨弦、执杯）不传。
- 他荡秋千、摇橹、正换处：这边不画他（名签淡出去，身子直接不见——画法里没有半透明，淡不了）。
- **远了就省**：每帧分两半——插值、量远近人人都做（很便宜）；重摆身子贵：离镜头八米内每帧，二十五米内隔帧，六十米内三帧一回，再远四到六帧，站着不动的更疏，不在画面里的不摆，一百六十米外不画。
  不摆的那几帧整个人（连同位置）都不动——与村里人一样，免得位置每帧挪、身子隔帧摆，着地的脚跟着滑。
  一帧里摆几个还有个顶（电脑五个、手机三个）：急的（刚跳过去、在作揖）、近的先摆，没轮上的下一帧先轮。新身子一帧至多做一个（一下子来十个人不卡）。
- 别人不挡路（走得过去）：总装每帧把村里人、牲口交给行走那一层当挡路的，同游的人不在其中——也省得有人故意堵着门。

开销（`together.mjs` 第九节，十个机器人围着甲走、都在画面里，电脑：RTX 4090、32 核，无头 Chrome）：

| 十人 | 约 1.0 毫秒（九成的帧 1.1 以内） | 3.0–3.2 毫秒 | 2.1–2.3 毫秒 | 149–151 次 | 87.5–89.7 万 |

## 遇见了做什么

- **作揖**：走到十二米以内，纸上那一行的「作揖」。自己站定、转向他、两手拢在身前躬身一下；他那边看见你躬身，下面浮一句「某某向你作揖」。
  他若闲着（没在做事、站着、没在走），过半秒自己还一礼——你这边看见他躬身、浮一句「某某还了一礼」。他忙着就只浮那一句，纸上那一行出朱墨的「还礼」（十五秒）。
- **说一句**：「幸会」「久仰」「同游如何」「正有此意」「请茶」「多谢」「好景致」「后会有期」，再加合这一季的一句（「桃花开了」「好凉风」「菊花黄了」「天寒，珍重」，夜里「月色正好」）。
  说的人头上浮着这句话五秒（近处的人都看得见，自己头上也有），被说到的那人下面另浮一句「某某：幸会」。一个人一秒多才能说一句（中转那边也限着）。
- **同行**：跟着他走——隔一会儿看他在哪，走到他身后一步半（自己会找路）；他跑远了就跑着跟（跟上了放开「疾」）；他在做事就站在旁边等。
  自己一动手（键盘、摇杆、点了别处、去做一件事）、他走了、他藏起来太久，就不跟了。被跟的人那边浮一句「某某与你同行」。
  远的人（三十米外）这一键叫「去寻」，做的是同一件事；远得很的（一百二十米外，比如他在渡口、你在桃林）先像村图上点一处那样换到他那一处（画面淡成雾），再走过去。
- 有人走近了（十五米内，头一回）浮一句「某某走近了」（同屋人多了不一个个说，十五秒才说下一个）；近处的人走了浮「某某别过」。头一回进来、园中另有人时说一句「园中另有三位游人」。

## 界面

- 右上（时辰那一条下面）一枚纸签：「同游 │ 三位」——园中**连你**一共几位（暂离的几分钟里也算；先前写的是「另有几位」，试玩的人当成总数，看着像少了一个人）；没连上时「同游」后面一点淡墨慢慢呼吸；独游时是「独游」。做事、翻册、换处、简册展开时收起来。
- 点开一张纸：「同游」、独游 / 同游、收；你是谁（雅号、衣色）与「换一个」；此刻怎样（连上没有、园中连你几位、近处几位、谁暂离）；园中各位由近及远——离多远（「就在身边」「十步外」「在草堂」）、在做什么；暂离的一行淡着、没有键；
  走得到跟前的那一位展开着现成的几句话，别的可以点开；末了一行小字：园中天时随谁（「此刻是你」或「随某某：那里比你这里快七个钟头」），名字与话都是现成的。
- **暂离**：别人的手机收起、切到别处半分钟，那边主动断开（`client.ts` 的 `onVis`），这边收到「走了」——先记作暂离（名字＋衣色记五分钟，`AWAY_MS`），浮一句「某某暂离」；五分钟内他连回来（名字衣色对得上），浮「某某回来了」，不算新来的。
- 画里：别人头上一枚小名签（墨字，身后一团纸色，像画里那些事的签），四十五米内由淡到实；走到十二米内签实一些、点得着（打开那张纸，翻到他）。说的话浮在名签上面。抬头看天时名签都不出。
- 同名的：后面添衣色「伊川散人（黛衫）」，衣色也一样再添一二三。
- 手机：纸占满宽、高的手机上停在摇杆上面（开着也能推着走）；横着的手机纸从上沿起、压住时辰那一条（开着用不着它）。键都不小于 44 像素。夜里是曜石黑上的月白字。
- 右上那块地方别的几路有时也放一张小纸（挑担子时的「往哪儿挑」）：压着了，那一枚与纸往下让到它底下（`--tg-shift`）。别的几路要它让的，给元素加 `data-tg-avoid`。
- 画里那些事的小签（Hud 的 Markers）要躲开这一枚与这张纸，得在 `Hud.tsx` 的 `KEEP_CLEAR` 里添上 `.tg-key, .tg-panel`（那个文件不归这一路改，已请总装加）。

## 园中天时：同游的人看同一个时辰

先前天时各人各是各的（你这里黄昏，他那里清早），试玩的人说没有交互感：大家看到的该是同一个场景、同一样东西。2026-11-25 改成（用户定的）：
- **同游开着，天时就随园中**：同屋排第一的那一位（最早进来、还在的）那里**真实的钟点与节气**——钟点按「此刻 + 他那里的时区」各人自己算（不传钟点，网慢了也不差），季与月按那一地的日子以节交月（`env/months.ts`：大雪起子月、立春起寅月……），**天气也随他**。
- 只有自己一个、或自己最早来：随自己这里的此刻；天气是自己的，可以拨，同屋后来的人跟着变。
- 随着的时候，自己拨的时辰、流转、季、月都不管用（天时那一页上锁着，上头写一句随谁；从别处拨的说一声「同游时，园中天时随最早来的那一位……」）；榻上睡一觉、亭中小睡都不拨时辰。
- 那一位走了：下一位排第一的接着报（多半是你），天时换成他那里的此刻，天气还回你自己的。
- 改成独游：天时还回自己拨的那一套（随上以前记下的时辰、流转、季、月、天气，`Anlewo.setShared` 的 stash）。随着的那些时候不往存档里记时辰，存档里自己拨的那一刻不动。
- 因为同游默认开着：一个人在园里时，园子也按你这里真实的钟点与节气走（晚上来就是夜里、十一月就是冬天）；要看别的时辰、季节，改成独游。
- 测试：`tests/play/together.mjs` 第十段，两页在不同的时区（上海、巴黎，差七个钟头）。老的几段网址上带 `share=0`（不随园中，定在网址给的时辰与季）。

## 同游时自己拨天时（2026-11-26）

天时页不再锁着：同游时拨了季、月、时辰、流转（或拨了别人定的天气），这一页上的那一下先 `Together.setOwnSky(true)`、`k.setShared(null)`（还回进园中天时以前自己的那一套）再照拨的走——画里是自己的天时，同屋的人看到的仍是园中此刻；
自己排第一时照旧替屋里报自己这里的时区与天气（拨天气大家跟着变）。「回到此刻」（`ks.backToNow`）：自己的那一套先回到此刻（此刻的月、随此刻），再 `setOwnSky(false)` 随园中。换独游、同游时这一回作罢。

## 样子、名片、玩法、路标（2026-11-25）

中转进门时的 `wel` 里 `x: 1` 说认得这几样（旧的一版没有 `x`，客户端就不发，园子照旧）：

- 样子 `lk`：至多十六个 0…255 的整数——`wearToWire`：[版本 1, 男 0 / 女 1, 衣, 冠, 簪 ×3, 佩 ×2]（`data/attire.ts` 的序号加一）。
  进门时一并报，换装（穿上了）再报；别人那边照着画成同一身（`wearFromWire` → `lookOfWear`）。没报过的画成读书人、按雅号配衣色。
- 名片 `cd`：至多十六个 0…999999 的整数——`play/board.ts` 的 [版本, 修为, 答题, 射箭, 投壶, 打水漂, 蹴鞠, 斗鸡, 骑, 打坐]，排榜用。
- 玩法 `g`：`{ k: games 的序号, to: 某一位或 0（同屋的人）, d: 至多十六个整数 }`。`Together.sendGame / onGame / onPeer`；
  一秒约八条（发给同屋的人算两条）。里头怎么排由各样玩法自己定（射箭、蹴鞠、斗鸡、抢座……）。
- 路标 `mk`：在某处留下自己取的一卦（位置、卦、月、时、天气），中转添上雅号与衣色，人人看得见（不分屋子）。中转只记在内存里，
  至多三百枚、各留三天，一个人同时至多三枚；`Together.placeMark / marks / unmark`。
- 别人在骑牛、斗鸡时身边的东西（牛、鸡）由那样玩法登记（`net/props.ts` 的 `registerRemoteProp`），这边就画得出来。

## 不存什么、不做什么

- 中转不存任何东西；名字、衣色、独游与否只存在各人的本机（`anlewo:net:v1`）。
- 没有聊天框、没有自己起名字：公开的站，不必管谁写了什么。
- 不做「屏蔽某人」（上面说的限速挡着最多是一直作揖）；以后要加，在客户端记一张「不理会」的单子就是。

## 还不够好的

- 身子的细动作不传：别人抚琴时这边只是盘坐着，手不拨弦；拿着的东西（钓竿、灯笼、扫帚）不画。
- 藏起来（秋千、船上）是直接不见，不是淡出去；回来时直接出现。
- 别人站在蒲团上时，下摆不按蒲团铺开（不知道垫子多大）。
- 没在真手机、真网络（几百毫秒的延迟、丢包）上试过；本机的检查里网络几乎没有延迟。280 毫秒的余量对一般的手机网络应当够，抖得厉害时会停一停再接上。
- 一间屋子 24 个座位：座位只算报了位置的人，连上了却一份位置不报的（页面冻住、锁屏、坏客户端）不占座，进了屋一分钟还不报的会被断开。同时来的人多了会分到几间屋子，两间屋子里的人彼此看不见（界面上只说「园中另有几位」，不说有几间）。
