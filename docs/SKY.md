# 天（星空、日月、观星、星图）

夜里的天是真的天：洛阳（北纬 34.6°、东经 112.4°）此地此刻看得见的星，按画里的日子与时辰摆好；银河、五星、月相、流星都在。画法守 `docs/INK.md`：星是纸上留出的一点白，连线是月白的淡描，名字是小楷配一点朱砂。

## 一、有什么

| | 在哪个文件 | 说明 |
| --- | --- | --- |
| 星 | `src/data/stars.ts`（数据）、`env/stars/catalog.ts`（解开）、`env/stars/layers.ts` 的 `StarLayer` | 依巴谷星表亮于 6.0 等的 5044 颗，加上星官连线、距星用到的暗星，共 5131 颗。一等星以上是清楚的一点白、带一圈很柔的晕（不要十字芒），二三等清楚可辨，暗星成一层细尘；大小按 CSS 像素给（乘渲染器的像素比），手机、电脑上看着一样大。色指数只给极淡的一点冷暖；轻轻地闪（低处闪得厉害，五星不闪）。大气消光按气团算（约 0.12 等/气团，最多算到六个气团：地平以上十度暗半等）；被天边近的两重远山、树、屋挡住的不画，最远那一重淡山后面的只暗三成。月光洗星是克制的：看得见的最暗星等无月 6.2 等、满月 5.6 等（比真的满月夜宽厚一些——画上要看得见星河），月旁二十来度里再少一些；暗星的浓淡有个底（三成多），一层细尘看得出来。|
| 银河 | `env/stars/milkyway.ts`、`env/sky.ts` 的天 | 按银道坐标现画的一张图（开场后空闲时分几段画，不拖慢开门）：人马座方向最亮，天鹅座到人马座一道暗隙，团块与颗粒。不偏蓝紫的素白（淡墨留白的意思），晴夜里总是一道看得清的光带：无月时最亮，月大时整条略淡、月旁三十来度那一段淡得多（按月的方向在着色器里减）；贴着地平五度以下才淡下去（漫游镜头只看得到地平以上十到四十度，这一截里也看得见）。另有一层极淡的「微尘」（看不清一颗颗的暗星，银道上密得多——天汉看上去是一片数不清的细星，不只是一团白气），按三维格子撒在天球上，点是圆的。晴夜的天往高处一层层沉下去（天顶最深），星与天汉才托得出来。不用外来的轮廓数据（许可不明）。 |

| 月 | `astro.ts` 的 `moon` | 盈亏由界面按今天的农历给（`atmos.moonPhase`）。位置跟着盈亏走：月在日之东「盈亏 × 360°」（黄经），黄纬按白道（倾 5.145°、交点每天退 0.053°）。亮的一边朝着日头，暗的一边隐约有灰光；白天离日远时也淡淡看得见。 |
| 五星 | `astro.ts` 的 `planets` | 岁星、荧惑、镇星、太白、辰星：JPL 近似轨道根数（表一）算今年这一天的位置与亮度，与星点画在同一次绘制里（五星不闪）。 |
| 星官 | `src/data/xingguan.ts`、`catalog.ts`、`LineLayer`、`LabelLayer` | 三垣二十八宿 289 个星官（明末补的近南极二十三官不收）：连线、属哪一区（以《步天歌》为准）、星名（织女一、角宿增一）、二十八宿的距星。平时不显，观星时才描出来。 |
| 流星 | `LineLayer.meteor`、`Sky.meteor` | 晴夜里偶尔一颗（观星时多些）；六场每年都来的流星雨，那几夜多半从辐射点那边射出来（不报西洋名，只说「像是从某某一带射出来的」）。 |

## 二、坐标与钟

- **J2000 赤道**：星表、星官、五星都用它（x 指春分点、z 指北天极）。
- **当日赤道**：J2000 加岁差（IAU 1976）。画里用今年（`SKY_YEAR`，取本机的年份）——这是你今晚出门能看到的天。想看邵雍那时（熙宁年间）的天，把 `SKY_YEAR` 改成 1070 即可：北天极会挪到北极星旁五度多、纽星（北极五）附近，二十八宿的界线也跟着变。
- **世界**：+x 东、+y 上、+z 南。`horizon(lst)` 把当日赤道转到世界；`Sky.now.M` 是「J2000 → 世界」的矩阵（星斗用，含候星移多拨的钟头），`now.M0` 不含多拨（日、月用）。
- **钟点**：画里的钟点按当地真太阳时（日头正南是十二点），所以当地恒星时 = 太阳赤经 + 太阳时角（钟点 − 12）× 15°。

## 三、两条定下来的规矩

1. **日出日落对着 `SUN` 表**。别的模块都按 `atmos.ts` 的 `SUN` 表定昼夜（纸色、灯火、村里人几点出门）。真实的日出日落与表差不过半个钟头，这里把钟点「拉一拉」（`warpHour`）：表上日出那一刻，算出来的太阳正好在地平线上（−0.833°，含蒙气差），白天、夜里各自匀着拉。测试里核对过四季日出日落都落在表上、正午在正南、拉过的钟点一路往前走不打结。
2. **日子跟着第几日往后推，但不跑出这一季**（`skyDay`）。季节由人在「天时」里定，日子从那一季的 `DAY` 起，过一夜加一天，推到季末（立夏、立秋、立冬、立春）再回到季初。这样冬天的雪夜不会出夏天的星。要改成「一直往后推」，只改 `skyDay` 一处。

## 四、别处怎么用（都在 `k.atmos.sky` 上）

```ts
const sky = k.atmos.sky;
sky.star(i)                 // 北斗七星（0 天枢 … 6 摇光）与北极星（7，勾陈一）此刻在世界里的方向（单位向量）——认北斗、观物用
sky.dir(i)                  // 星表第 i 颗星此刻的方向；sky.toWorld(j2000) / sky.toEq(世界方向)
sky.data                    // 星表、星官（name/region/stars/segs/center）、starName(i)、ju（距星）、dipper、find(名)
sky.pick(方向, 容差)         // 点着了什么：{kind:'star', star, asterism} | {kind:'line', asterism} | {kind:'planet', planet}
sky.lines.set(星官序号, 0…1, 快慢, 描粗)   // 描一个星官；setAll(…) 全部；guide(0|1, a, b) 一道走动的虚线（指路）
sky.labels.show(key, 字, j2000方向, { sub, side, big })   // 天上题一个名；hide(key)、hideAll(前缀)
sky.stars.highlight(Map<星序号, 0…1>)    // 点亮几颗星
sky.meteor()                // 划一颗流星；sky.meteorRate 平时的多少；sky.shower() 今夜有没有流星雨
sky.chart()                 // 此刻天的样子（给星图）
k.atmos.starShift = 6       // 星斗另外往后拨几个钟头（候星移；月跟着转，照亮万物的「光」不动）
```

`mansionOf(j2000方向)`（`catalog.ts`）：落在二十八宿的哪一宿（按距星赤经划分；觜参颠倒处让参宿从觜宿距星往东一点起）。

## 四之二、平时夜里抬头、点天（不必去观星）

- **抬头**：晴夜在屋外，镜头往上拖过平时的最低处，就慢慢低下来、凑到身后，往天上仰到五十来度（人的头肩留在画面下沿）；一迈步就慢慢低回来，进屋一下子回来（`nav.ts` 的 `UP_MIN / UP_DIST / UP_EL`）。
- **点天**（`Anlewo.skyTap`；话由 `acts/skyinfo.ts` 拼，观星那件事也用它）：先看月，再看五星、星、星官的连线，都没点着再看是不是点在天汉上（`milky()` 那一处亮过 0.16）。点着了天上那一处点亮（连线描出来、旁边写名字），界面出一张**星笺**（`src/app/SkyCard.tsx`）：题是名字（毛笔字），一行属哪一垣哪一宿、此刻在哪个方向多高，古书里的一两句与出处，本应用写的白话。
  - 天汉那一张说这一段在哪个星官、哪一宿一带；银心那一头、天津的暗隙、对着银河外边最淡的那一段各多一句；两岸的牵牛（河鼓二）、织女（织女一）在天上的话淡淡点亮、写上名字。
  - 收起：点「收」；走开两三步、进屋、做起事来、天亮、开了四十秒，世界自己收。电脑上笺在下面当中；手机上也在下面，这时摇杆、「疾」、印先收起来（点地面照样走过去）。画面下方浮的话挪到笺上面。
- **头一个晴夜**在屋外，浮一句「夜里的星斗都是真的：往上拖，抬头看；点一颗星，看它是哪一官」（存档 `stars.hinted`，只提一回）。
- 观星那件事里点天也认天汉了（从前点在银河上是空的）。

## 五、观星（`acts/stars.ts`，事的 id：`stars`）

- **哪里**：柴门外东南、村路与溪之间的草坡（`STAR_SPOT`，x 8、z 25.6）。离路、离溪岸各两三米，不在田里，正南望过溪、田畴、伊水，天最空；东南一株柳、西边远处的石峰与桔槔留在画面下沿当衬。
- **什么时候有**：夜深（`night > 0.6`）、没有雨雪雾。
- **流程**：人走到席边 → 席卷着铺开（一秒）→ 盘腿坐下 → 镜头先在身后朝南看着他坐下，再慢慢转过去、抬起来（三秒），停在此刻天上最好认的那一片（偏南的优先）。之后：
  - 拖动看四方（一直看到天顶）；点一颗星 / 一段连线 / 一颗行星 / 月：那一官的连线描粗、星点亮一些，天上题名（小楷、一点朱砂；星自己的名小一号写在左边），面板里是古书的话、出处与我们写的白话；点空处收起。
  - 四象：挑一象，七宿一宿一宿点亮（在地下的说在地下），镜头跟着转；七宿完了出《天官书》《尧典》各一句。
  - 候星移：朝北看，六个时辰在十二秒里转过去（北斗描出来），停一停说一句邵雍的诗，「回到此刻」再转回来。
  - 流星：观星时大约十几秒一颗，流星雨那几夜多。
- **观星录**（`k.mem` 的 `stars`）：`{ seen: 认得的星官名[], planets: 认得的行星[], xiang: 看过的四象[], nights: 看了几夜, meteors: 见了几颗流星 }`。头一回认得一个星官时浮一句「认得了一个星官：织女（第三个）」。星图上把认得的星官都写出名字。

**认北斗**（`acts/dipper.ts`，id `dipper`）改用同一套：点出的星题名，七颗齐了勺子描出来、斗口引一道走动的虚线到北极星。斗柄所指按「天极到摇光」判（与测试一致）。**观物·候星移**（`acts/pavilion.ts` 的 star 那一模式）：北斗淡淡描出、北极星题名。

## 六、星图（`src/app/sheets/StarSheet.tsx`、`src/app/styles/stars.css`）

盖天式圆图：北极在中，内规（洛阳终夜不落的那一圈，赤纬 55.4°）、赤道、外规（看得见的最南，−55.4°）三道圆，朱色虚线是黄道，二十八宿按距星分作二十八条界线，银河一抹淡墨，此刻地平以下罩一层（昼是纸色、夜是夜色）。面朝南仰看：中天在下、东在左。拖动转、点星看名与出处、「回到此刻」。画到 4.9 等星；二十八宿名用朱，另写北斗、织女、河鼓、天狼、老人等十几个与三垣的名，再加上观星时认得的。手机 393×714、375×548 都看过（图按册页宽度缩放，下面的字在册页里滚）。

## 八、画法与分量

- 星点、连线、名字都画在第三步（`FX_LAYER`），自己比深度：只落在「天」上（深度图里没画东西的地方）；天边那三重远山是天的着色器里画的，星点在顶点着色器里用同一段 `RIDGE_GLSL` 判断自己在不在山后。银河、月在天的着色器里（第一步），所以被远山、树、屋挡住是自然的。
- 绘制：平时夜里 +1（星点与五星一次）；有流星、或观星时连线 +1；天上题名 +1。最多 +3。三角：连线约两千（观星时），星点不算三角。
- 量到的（开发机，无头 Chrome，GPU 计时）：桌面 1280×760、像素比 2、高档——天（含银河、月、远山）0.23–0.29 毫秒（关掉银河差别在误差里），星点、连线、名字各不到 0.01 毫秒；手机尺寸、低档——天 0.04 毫秒。不锁帧时整帧 2.2–2.8 毫秒，开关星空差 0.1–0.5 毫秒（在误差里）。真手机没量过。
- 档位：低档只画亮于 5.0 等的（1627 颗）、天汉图 512×112；中档 5.6 等、768×160；高档全部、1024×224。

## 八之二、雷电、密云、池上的霞（2026-11-25，为观象添的）

- **闪电**：夏天雨下大了（雨过六成），`atmos.ts` 隔十一到三十三秒在天边随便一处打一个；`atmos.strike(方位)` 也可以指定（观象「噬嗑」站定后三秒在南边远山上打一个，之后五六秒一个）。一下是：纸面一白（一闪、一暗、再一闪、又一闪，`atmos.flash`，夜里减半），一道折折的电自云底（仰角正切 0.31）落到远山后头（0.022），主干九折、半腰分出一枝，前半秒一直亮着、跟着闪一跳一跳，过后一秒多淡尽。电画在天的着色器里（`uBolt`、`uBolt2`），远山挡着的那一截看不见；不另添绘制。雷声仍由声音那一路按 `storm` 自己排，与闪不对时。
- **密云**：西山上一带带墨的云烟（`Sky.rack`，几十片远景那种 puffs 并成一次绘制）：西北厚的一大团压得高（遮了半边天），往西南拖成低低一条薄的。雾过三成、要下雨了（雨一两成起）聚起来，雨下透了留一半，夜里看不见；平时不画。比深度，近处的树、坡挡得住它。观象「小畜」「夬」。
- **池上的霞**：天的霞（`SKY_GLOW`、`SKY_GLOW_PIG`）与门前塘的水共用一份：晨昏朝着日头那边望过去，池面远一点的地方映一层霞色（溪不映）。映的是往亮里调的一层暖粉，不只往暗里乘——只乘的话透出池底的泥色，是褐的不是红的。伊水晨昏的霞色挪到镜头前两三米就有，正对着日头的那一道更浓（一条金红的光路，`far/veil.ts`）。观象「睽」「未济」。
- **雁阵**（`life/fauna/sky.ts` 的 `geeseAcross`）：观象「渐」站定时叫一行雁从眼前的天上过——前头一百五十米、略偏左、四十来米高（画的上三分之一，手机竖着也在画里），往南略偏西走远；天上已经有一行（多半在别处）就叫它改走这一条。

## 九、没做的、要留意的

- **躺下看**：小人还没有仰卧的姿态，观星时是盘腿坐在席上仰头看（镜头贴到眼前时不画人）。代码里已备好 `lying` 一档：头位（`head()`）、开场镜头的高度与俯仰（`P0()`）都按它取。行者那一路加了 `lie` 以后，只要把「铺席、坐下」那一句 `sitDown(...)` 换成仰卧的调用并置 `lying = true`（见总装的交接）。
- 星的位置用依巴谷的历元 1991.25，没有按自行推到今年（最快的几颗差一两角分，看不出）。没有做蒙气差、视差。月亮的位置只按盈亏与白道算，不是完整的月历表（差几度）；五星用近似根数（差角分级）。
- 银河是写意的（位置、走向对，细节是噪声）。
- 「月在某宿」「此刻某宿中天」按今天的距星赤经划分；宋代的宿度与今天不同（岁差、觜参颠倒），只是个大概。
- 声音名 `starTap`、`starLight`、`matUnroll`、`matRoll`、`meteor`（声音那一路已做）。观星时 `k.focus = 'stars'`（夜更静），起身、Esc 中途作罢都还原成 null。流星：`sky.onMeteor` 由观星那件事接上——观星时一定出 `meteor` 一声，平时只在晴夜屋外。
