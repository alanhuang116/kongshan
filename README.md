# 空山

> 空山无人，水流花开。——苏轼《十八大阿罗汉颂》

**在线：<https://alanhuang116.github.io/kongshan/>**（电脑用键盘鼠标，手机用左下的摇杆；宜耳机）

一座可以独自走进去的唐风山寺。你操纵一位行者（月白长衫、背一顶斗笠）在寺里走：走近了香炉、拜垫、木鱼、钟、鼓、书案……他会自己走到位，把那件事做出来。网页应用，电脑与手机同一套；可装到主屏幕，来过一次之后断网也能进山。

没有账号、没有服务器、没有一张图片素材、没有一段录音：**每一根柱、每一垄瓦、每一棵树、佛像、法器都是程序搭出来的，每一声钟、磬、木鱼、风、鸟、雨都是现场合成的。**

## 跑起来

```
npm install
npm run dev        # http://localhost:3800 （手机在同一个局域网里可以直接用电脑的地址访问）
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 看打包后的样子（离线缓存只在这里才装）
npm test           # 经文与短句的指纹；哪里能走、怎么找路（改了总图或殿的尺寸要跑）
npm run fonts      # 字体包升级后重新生成 src/app/styles/fonts.css
npm run test:motion   # 浏览器里量人的动态（先另起 3801 的开发服务器，见 tests/play/README.md）
npm run test:acts     # 浏览器里把十二件事各做一遍，量人与器物对不对得上
```

Node 20.18 可用（Vite 6）。打包结果是纯静态文件、全部用相对路径，放在域名根下或子目录（如 GitHub Pages 的 `/kongshan/`）下都能跑。

## 放到 GitHub Pages

```
npm run build
node tools/deploy-pages.mjs https://github.com/<你>/<仓库>.git gh-pages
```

把 `dist/` 作为只有一次提交的分支强推上去（分支上只留最新这一版）；仓库的 Pages 设成从那个分支的根目录发布。公开的仓库里不想露邮箱，就先设 `PAGES_NAME`、`PAGES_EMAIL`（GitHub 的 noreply 地址）。改了不带指纹的文件（`public/models/*.bin`、图标）要把 `public/sw.js` 里的版本号加一，老访客才会换新的。

调试用的网址参数：`?auto=1`（跳过开场）`&s=court`（从哪一处开始：foot gate court pond censer tree bell drum steps hall study tea terrace）`&t=dawn|day|dusk|night|10.5`、`&w=clear|mist|rain|snow`、`&season=spring|summer|autumn|winter`、`&q=low|mid|high`、`&act=incense`（直接进某项活动）`&ui=0`（不要界面）。

开发时的两个台子（不进正式构建）：`/lab.html?m=hall`（单看一个模型，`m` 取 `src/lab/models/*.ts` 里登记的名字；小人是 `avatar`、`avatarWalk`、`avatarPoses`、`avatarStairs`）、`/audio-lab.html`（逐个试听、看频谱）。

## 怎么走

| | 电脑 | 手机 |
| --- | --- | --- |
| 走 | `W A S D`（相对镜头的前后左右）；`↑ ↓` 也是前后 | 左下的环，按住往哪边推就往哪边走 |
| 小跑 | 按住 `Shift` | 把环推到头 |
| 转镜头 | 拖动画面；`Q` / `E`、`← →` | 拖动画面；双指捏合拉近推远 |
| 走到某处 | 点地面（会绕开挡着的东西，过桥、上踏跺） | 同左 |
| 做一件事 | 走近了，下面浮出它的名字：点它，或按 `E` / `F` / 回车；也可以直接点画面里的标记 | 同左 |
| 做事时 | 空格 = 点一下 / 按住（拜、撞钟、注汤） | 点、按住、拖 |

平时走 1.45 米/秒（一米五八的人每秒两步上下），小跑 3.0；台阶和坡上自动慢四成。钟楼、鼓楼从楼下朝院子的那扇门「上楼」。路远的话点右上的「图」，点一处，画面暗一下就到。

## 寺里有什么

| 处 | 能做的事 |
| --- | --- |
| 山道 → 山门 | 开场：点「入山」。头一回来，人站在山脚，自己沿石阶走上去；以后直接到山门前 |
| 石桥 | 一池、一桥、一殿的正面 |
| 莲池 | **放灯**：下到池南的石埠，在水边跪下捧灯；灯上写一句（只存在本机），俯身放到水面，轻轻一推，合掌看它漂远 |
| 香炉 | **上香**：取香 → 侧身就烛火点着 → 举香三拜 → 探身一支支插进炉里 |
| 银杏 | **扫叶**：拿起扫帚照常走动，走到哪扫到哪；扫净了，风一来又落 |
| 钟楼 / 鼓楼 | **撞钟**（两手扶木，按住往后引，松手；每声配闻钟偈一句，惊起一群鸟）/ **击鼓**（执双槌，点鼓面哪里槌落哪里） |
| 殿前 → 大殿 | **礼佛**（跪到拜垫上，按住俯身叩首）/ **木鱼**（跪坐持槌，一击一字，《心经》二百六十字）/ **拈一则**（捧签筒摇出一则古人的话） |
| 经房 | **抄经**：在案前坐下取笔；宣纸、朱丝栏、描红，你落笔时案前的人也跟着在纸上动；写过的字按你的笔迹留成一卷，可存成图 |
| 茶寮 | **吃茶**：绕过茶几入座；候汤，左手提壶注汤，右手端盏，吃茶去 |
| 云台 | 亭里两个蒲团：北边**静坐**（面朝云海，一炷香烧尽计时，三声引磬起、一声止）/ 南边**念珠**（一百零八颗，到母珠掉头） |

右上四枚小键：**图**（寺图，朱点是你；点一处，画面暗一下就到）、**时**（此刻 / 晨昼暮夜；晴雾雨雪；四季）、**声**（总音量与九层环境声）、**簿**（功课簿，只记数，不记功德；里面有「缘起」）。

天时默认跟着本机的钟点与日历走：晨昏、月的盈亏（按农历）、四季的草木（秋天银杏黄、冬天梅开、夏天荷花）。

## 几个决定

- **你是一位行者，自己走。**（第一版是「点一处、镜头走过去」，没有人；后来改了。）平时镜头跟在他身后；做事时镜头退到一旁看着他做——所以每件事都得让他「真的做得到」：手臂只有半米多长，够不到的就挪近、探身、改摆法，而不是让东西自己飞过去。
- **垫子不踩。** 拜垫、蒲团在地图里是挡路的东西：人走到垫子后面站定、转过身，再往前跪（坐）上去；做完退回垫子后面站起来。
- **台阶按坡走，脚踩在踏面上。** 身子的高度取前后一步之内地面的平均（不然上一级顿一下）；脚落在哪一级由小人自己量。
- **水够不到，就修一级石埠。** 池岸比水面高半米，跪在岸上手碰不到水，所以池南加了两级下到水边的石阶。钟也因此挂低了三十多厘米（撞座到胸口），撞木缩短到楼上放得下。
- **唐风，而不是明清的红墙黄瓦。** 朱柱白壁、直棂窗、鸱尾、硕大的斗栱与人字栱、出檐深远而起翘平缓。依据与「不严格处」（如钟鼓对设是后世通例）写在「缘起」和 `docs/SOURCES.md`。
- **不计功德。** 没有「功德 +1」、签到、等级。功课簿只记数。签筒不问吉凶。
- **雾是沉在低处的。** 不用引擎自带的雾：按高度衰减，朝日 / 月的方向染色；最远的山只是画在天上的几重剪影（远山无皴）。
- **屋里是暗的。** 给大殿、经房等登记了「屋子的盒子」，盒内的面不受天光，只受从门斜进来的日光与灯烛。
- **器物声按发声原理合成**，不用录音；诵经声也是合成的（只取「远处有人在诵」的意思）。想用录音：放一个有版权许可的 `public/audio/xinjing.mp3`（放了以后重起开发服务器 / 重新打包），「诵」那一层会自动改播它。
- **一切只存在本机**（localStorage）：偏好、功课簿、抄经的笔迹、灯上的字。

## 画质与性能

| 档 | 用在 | 像素比上限 | 日影 | 后期 | 池水倒影 |
| --- | --- | --- | --- | --- | --- |
| high | 台式机（8 核以上） | 2 | 4096 | 泛光 + 4× 抗锯齿 | 有 |
| mid | 一般电脑 / 较好的手机 | 1.5 | 2048 | 泛光 | 电脑有 |
| low | 一般手机 | 1.25 | 1024 | 无 | 无 |

画面慢了会自动降清晰度，宽裕了再升回来；静坐时帧率降到 30。`?q=` 可强制档位。

在开发机（i9-13900KF + RTX 4090，无头 Chrome）上量到的：石桥看大殿那一幕 high 约 279 万三角 / 639 次绘制（含倒影那一遍），low 约 75 万 / 312 次；都是 60 帧。从打开到能点「入山」：high 约 5–6 秒，low 约 3 秒（其中程序化贴图 1.7 / 0.45 秒）。

## 验证过的，和没验证过的

**验证过**（脚本在 `tests/play/`，怎么跑见那里的 README；都是无头 Chrome 里用真实的按键、点按、拖动跑的）：
- **人的动态**（58 项）：按键方向对；走 1.45 米/秒、每秒 2.14 步、步幅 0.68 米（身高的 0.43），单脚着地占六成、换脚时两脚都在地上；小跑 3.0 米/秒、每秒 3.1 步、有腾空；着地的脚不打滑（滑动约为走速的 1%）；胯起伏 3 厘米、头稳；两臂一前一后地摆；起步 0.35 秒走匀、停步不拖、站定后两脚并拢不再动；掉头是转过去的（最快 7.5 弧度/秒）；上下殿前踏跺、山道石阶、石桥、石埠时身子一帧最多升降 2 厘米、脚陷进踏面不超过 2.5 厘米；顶着墙停住且不原地踏步，斜着蹭墙顺着滑；跪、坐、蹲不穿地；镜头在 48 个机位上都不进墙、不钻地。
- **人与器物**（每项都从几步之外走过去开始；电脑、手机各 81 项）：走到位、站定、面朝对；香头凑到烛火才点着、手到了灰面上方才松手、三支都在炉里；叩首时头到垫前；槌头落在鱼背上（差 2 厘米内）；两手扶着签筒、撞木、帚竿、茶壶提梁、茶盏、莲灯（手离要够的地方 5 厘米内）；鼓槌落在点到的地方；笔尖落在纸上该落处（差 3.5 厘米内）；灯是两手送到水面的；绕过茶几入座；做完都站得起来、东西都放回原处。
- **连续动作**逐帧截成连环画看过：走、小跑、起停、掉头、上下台阶、走到垫子后面跪 / 坐上去再起身、合十到叩首。
- 带界面的画面（电脑 1440×810、手机 390×844）逐张看过：面板不挡人（宽屏面板与人各占一侧，竖屏面板在下人在上），没有出界的元素。
- 找路（单元测试）：池南到池北走桥、绕过茶几入座、上踏跺进殿到拜垫后面、紧挨香炉的地方走到旁边、钟楼上绕开钟。
- 正式构建放在子目录下（模拟 GitHub Pages）：从开场点「入山」、用键盘走上石阶、找路走到香炉前按 E 上香、寺图换处，无报错；来过一次之后断网重开成功。
- 雨、雪、雾、四季、晨昼暮夜的画面各看过。
- 声音：每种声音离线渲染后的峰值、衰减、频谱结构（见 `docs/AUDIO.md`）；最坏组合不削波。
- 经文与短句：逐字比对 CBETA / 维基文库的录文（见 `docs/SOURCES.md`）。

**没验证过**：
- **没有在真手机上跑过**，也没试过 Safari / Firefox。手机上的帧率、发热、启动时间都只是估计（低档 75 万三角对中低端手机偏重）。摇杆与双指缩放只在模拟的触摸事件上试过，手感要真机上再调。
- 人的动态「自然不自然」是按数值与逐帧截图判断的，**没有人看着连续的画面评过**：小跑的节奏、坐下起身的快慢最可能要再调。
- 小人的手是并指的，抄经、端盏的近景显得简；长衫的褶不是布料模拟，急转身不会甩。
- **声音没有人听过**——我只能看数值和频谱。最没把握的是诵经声与古琴；钟在手机外放上听不到 98Hz 的嗡音。
- 触感（振动）、屏幕常亮、摇手机摇签，只写了、没在真机上试。
