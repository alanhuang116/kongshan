# 安乐窝

邵雍的桃花源：一幅可以走进去的山水。

北宋的邵雍把自己住的地方叫「安乐窝」。这里照着他诗文里的意思，把它想成洛阳城南、伊水北岸的一处田园（不是哪一处遗址的复原）：你操纵一位先生慢慢地走——缘溪穿过桃林，过小石桥、进柴门，到院里、草堂、屋后的池与观物亭；溪南是一畦畦田，东头是邻家与村塾，再往南是伊水边的渡口。走近了什么，可以停下来做一会儿：读书、写两句诗、抚琴、煮茶、浇菊、看云、认北斗、与村里人说几句话。网页应用，电脑与手机同一套；可装到主屏幕，来过一次之后断网也进得来。

- **画法**：一幅会动的浅绛山水——近处淡彩，远景水墨，底是带一点暖的旧纸，天与水留白；全画最艳的只有桃花和那一点淡朱的日头（见 `docs/INK.md`）。
- **易**：邵雍一生治《易》。这里不起卦、不问吉凶，《易》只当「象」看：这片地方的八方合着先天八卦（南乾北坤、东离西坎）；一日十二时辰、一年十二个月各配一个消息卦（右上角那枚小卦就是此刻的时辰）；走到一处、赶上那个时候，站定看一会儿，就观得一象——井台上是「木上有水，井」，炉上的水是「水在火上，既济」——收进「观象册」（先天方图，八八六十四卦）。
- **界面**：纸、墨、一点朱砂。画的四角各有一样小件：左上是处名，右上是时辰与一卷简册（村图、天时、观象册、声音、起居注、关于）；画里夜了，界面跟着换成深墨上的月白。

没有账号、没有服务器、没有一张图片素材、没有一段录音：**每一座山、每一株桃、每一间屋、每一个人都是程序现画出来的，每一声溪水、鸟鸣、鸡犬与读书声都是现场合成的。** 古人的原话都注了出处，本应用自己写的话另外说明（「关于」页）。

调试用的网址参数：`?auto=1`（跳过题名页）`&s=grove|bridge|yard|hall|pavilion|fields|village|ferry`（从哪一处开始）`&t=now|dawn|day|dusk|night|10.5`、`&w=clear|mist|rain|snow`、`&season=spring|summer|autumn|winter`、`&q=low|mid|high`、`&act=<事的 id>`（直接做某件事，如 `xiang:革`、`dipper`、`book`）`&ui=0`（不要界面）。

## 跑起来

```
npm install
npm run dev        # http://localhost:3800 （手机在同一个局域网里可以直接用电脑的地址访问）
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 看打包后的样子（离线缓存只在这里才装）
npm test           # 文字的出处与形状、总图（加一倍法的数目、水往低处流）、哪里能走与找路、六十四卦齐全
npm run fonts      # 字体包升级后重新生成 src/app/styles/fonts.css
npm run test:motion   # 浏览器里量人的动态（先另起 3801 的开发服务器，见 tests/play/README.md）
npm run test:acts     # 浏览器里把每一件事从几步外走过去做一遍
```

Node 20.18 可用（Vite 6）。打包结果是纯静态文件、全部用相对路径，放在域名根下或子目录（如 GitHub Pages 的 `/kongshan/`）下都能跑。在 Windows 上要在盘符大写的路径里打包（`D:\…`），小写的 `d:\…` 会让 Vite 报 `html-inline-proxy`。

开发时的三个台子（不进正式构建）：`/world.html?s=yard`（整景，不带界面：`1 2 3 4` 换晨昼昏夜、`5 6 7 8` 换四季、`9 0 - =` 换晴雾雨雪，`?over=1` 是题名页背后的俯瞰）、`/ink.html?m=hall`（在正式的画法与天时底下单看一个模型，`m` 取 `src/lab/ink/*.ts` 里登记的名字）、`/audio-lab.html`（逐个试听）。

## 放到 GitHub Pages

```
npm run build
node tools/deploy-pages.mjs https://github.com/<你>/<仓库>.git gh-pages
```

把 `dist/` 作为只有一次提交的分支强推上去（分支上只留最新这一版）；仓库的 Pages 设成从那个分支的根目录发布。公开的仓库里不想露邮箱，就先设 `PAGES_NAME`、`PAGES_EMAIL`（GitHub 的 noreply 地址）。改了不带指纹的文件（图标、清单）要把 `public/sw.js` 里的版本号加一，老访客才会换新的。

## 怎么走

| | 电脑 | 手机 |
| --- | --- | --- |
| 走 | `W A S D`（相对镜头的前后左右）；`↑ ↓` 也是前后 | 左下的环，按住往哪边推就往哪边走 |
| 快走几步 | 按住 `Shift` | 把环推到头 |
| 转镜头、看四周 | 拖动画面；`Q` / `E`、`← →` | 拖动画面；双指捏合拉近推远 |
| 走到某处 | 点地面（会自己找路：绕开篱笆树石，过桥、走汀步、上台基） | 同左 |
| 做一件事 | 走近了，画里浮出它的名字：按 `E` / `F` / 回车，或点那个名字 | 点那个名字，或右下的主按钮 |
| 做事时 | 点画面（弹琴的一声、扇火、舀酒、点星），面板上选 | 同左 |

平时走 1.4 米/秒（散步的快慢），快走 3 米/秒；坡和台阶上自动慢一些。路远的话打开右上的简册点「村图」，点一处，画面淡成一片雾就到了。

## 这里有什么

| 处 | 能做的事 |
| --- | --- |
| 桃林（入口） | 沿溪六十四株桃；春天落花顺水漂下去 |
| 石桥、柴门 | **读联**：柴门上一副「闭门即是深山，读书随处净土」（明人陈继儒的句子，「关于」里如实写着） |
| 院中 | **浇菊**（拿葫芦瓢绕着菊圃一丛一丛地浇，十六丛）、圭表（日影长短，看得出节气）、石桌四凳、一株老梅两株松 |
| 草堂 | **书案**（翻《周易》《皇极经世》，或写两句诗——界面上照着写）、**抚琴**（席上盘腿坐，一声一声地弹）、**煮茶**（扇火候汤，注茶）、**自斟**（一杯两杯，微醉即止）、**榻**（夜里一觉到天亮，白天小憩）、北墙上的**先天图** |
| 观物亭 | **观物**（看云起、听蝉鸣、察草虫、候星移）、**小睡**（午后打个盹，醒来写两句）、亭心的**先天八卦盘**（按先天之序转身看八方） |
| 溪桥（夜里） | **认北斗**：点出勺子的七颗星，由斗口两星找到北极，看此刻斗柄指向哪一方 |
| 邻家、田畴、渡口 | 与村里人说话（问桑麻、听渔樵问对、与客对坐……），看人耕田、采桑、修桥、读书、下棋、浣衣、牧牛 |
| 随处 | **观象**：六十四卦各对着这片地方的一景、一个时候；站定看一会儿，那一卦就显出来，收进「观象册」 |

右上一枚小卦是此刻的时辰（十二消息卦），一卷简册里是：村图、天时（十二时辰、四季、晴雾雨雪）、观象册（先天方图，八八六十四卦）、声音、起居注、关于。天时默认是春日上午，也可以跟着本机的钟点走。

## 几个决定

- **画出来，不是照出来。** 没有光照、影子、色调映射；每样东西是「纸 × 颜料^浓度」，背光的一面浓一些，轮廓与转折处由画法统一落墨线，远处褪成墨色，山从山脊往下由浓到淡（`docs/INK.md`）。
- **《易》只当象看，不占卜。** 八方合先天八卦，时辰配消息卦，景物对卦象（大象传）；园里暗藏加一倍法的数：一梅、二松、四凳、八亭柱、十六丛菊、三十二丛竹、六十四株桃；四时各一花：桃、莲、菊、梅。
- **人情味。** 田要耕、桑要采、桥要修、孩童读书、老人有人照看：村里的人各有各的活与时辰，夜里回家，雨天不出门；走近了他们会抬头看你一眼。
- **你是一位先生，慢慢地走。** 每件事都让他「真的做得到」：坐凳、盘坐、蹲在炉前，手伸到琴弦、书页、酒瓮口上；做完站起来。
- **坡上顺着坡走，台阶一级一级地上。** 脚踩在画出来的那一层地上（行走用的地面高度与地面网格一模一样）。
- **文字有出处。** 古人的话逐字对过几种版本（`docs/SOURCES.md`）；本应用自己写的话（题下「心能安处即桃源」、「春种秋收，便是大吉」、村里人的家常话）在「关于」里分开说明；门联是明人的句子，不冒充宋人。
- **一切只存在本机**（localStorage）：偏好、起居注、观过的象。

## 画质与性能

| 档 | 用在 | 像素比上限 | 草木数量 |
| --- | --- | --- | --- |
| high | 台式机（8 核以上） | 2 | 全部 |
| mid | 一般电脑 / 较好的手机 | 1.5 | 七成五 |
| low | 一般手机 | 1.25 | 一半 |

都开四倍多重采样（点叶点花的软边靠它）。画面慢了会自动降清晰度，宽裕了再升回来；做静的事（小睡、观物）时帧率降到 30。`?q=` 可强制档位。

开发机上（无头 Chrome）各处量到的：high 约 50–84 万三角、52–140 次绘制；low 约 32–59 万三角。从打开到能点「入」约 3 秒。

## 验证过的，和没验证过的

**验证过**（脚本在 `tests/play/`，怎么跑见那里的 README；都是无头 Chrome 里用真实的按键、点按跑的）：
- **人的动态**（66 项）：按键方向；走 1.4 米/秒、步幅与步频合身量、着地的脚不滑、单双支撑交替；快走有腾空；起停、掉头；**上下坡（院前到溪边的缓坡）、草堂的踏步石与台基、石桥、观物亭的踏步、汀步**时身子升降连贯、脚不陷；顶着篱笆停住、斜着顺着滑；跪、盘坐、坐凳、蹲不穿地；镜头在 48 个机位上不进墙、不钻地。
- **每一件事**（51 项）：都从几步之外走过去、站定开始、按流程做完、站起来能走；观象记进册子。
- 总图、行走（单元测试）：一梅二松三十二竹六十四桃、溪水一路往低处流、井田九畦当中在耕、从入口到各处都走得通、水里墙里菊圃里站不住。
- 文字：五百多处引文逐字对过两到四种版本（见 `docs/SOURCES.md`）。
- 晨昼昏夜、晴雾雨雪、四季的画面各看过。

**没验证过**：
- **没有在真手机上跑过**，也没试过 Safari / Firefox。手机上的帧率、发热只是估计。摇杆与双指缩放只在模拟的触摸事件上试过。
- 人的动态「自然不自然」是按数值与截图判断的，没有人看着连续的画面评过。
- **声音没有人听过**——只能看离线渲染的数值与频谱（`docs/AUDIO.md`）。
- 草木、屋舍、人物各自的不足见 `docs/FLORA.md`、`docs/PROPS.md`、`docs/LIFE.md`。
