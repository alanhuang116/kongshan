# 安乐窝

邵雍的桃花源：一幅可以走进去的山水。

在线：<https://alanhuang116.github.io/kongshan/>（电脑、手机打开即用；可装到主屏幕）

北宋的邵雍把自己住的地方叫「安乐窝」。这里照着他诗文里的意思，把它想成洛阳城南、伊水北岸的一处田园（不是哪一处遗址的复原）：你操纵一位先生慢慢地走——缘溪穿过桃林，过小石桥、进柴门，到院里、草堂、屋后的池与观物亭；溪南是一畦畦田，东头是邻家与村塾，再往南是伊水边的渡口。走近了什么，可以停下来做一会儿：读书、写两句诗、抚琴、煮茶、浇菊、看云、认北斗；翻地下种、割麦打场、推磨舂米；晴夜抬头就是洛阳此刻的真星空，点一颗星、一段银河，旁边一张星笺说它是哪一官、在哪一宿；也可以铺一领席躺下观星；荡秋千、摇橹、垂钓、放纸鸢、投壶、打水漂、堆雪人。村里三十四口人各有名姓、各有一天的日程，可以停下来说话、送东西、替人办事。时辰会走（默认画里一个钟头是这里一分钟），过了子夜就是新的一天，庄稼一天天长。网页应用，电脑与手机同一套；可装到主屏幕，来过一次之后断网也进得来。

- **画法**：一幅会动的浅绛山水——近处淡彩，远景水墨，底是带一点暖的旧纸，天与水留白；全画最艳的只有桃花和那一点淡朱的日头（见 `docs/INK.md`）。
- **易**：邵雍一生治《易》。这里不起卦、不问吉凶，《易》只当「象」看：这片地方的八方合着先天八卦（南乾北坤、东离西坎）；一日十二时辰、一年十二个月各配一个消息卦（右上角那枚小卦就是此刻的时辰）；走到一处、赶上那个时候，站定看一会儿，就观得一象——井台上是「木上有水，井」，炉上的水是「水在火上，既济」——收进「观象册」（先天方图，八八六十四卦）。
- **界面**：纸、墨、一点朱砂（料在 `src/app/styles/ink.css`）——板与册页是托在画上的宣纸（有纤维、墨晕开的淡影、上下两道极淡的裱边），可点的是纸签，主操作是一笔带飞白的浓墨，圆键（入、册、毕、收、疾、摇杆）是一圈笔画不匀的墨环，该按的那一方是朱印；画里的小签是写在画上的墨字，走近了的那一件在那一点上有一圈墨环慢慢呼吸、旁边一方小印写着怎么做；按下去的地方晕开一滴墨（`src/app/ink.ts`）。画的四角各有一样小件：左上是处名，右上是第几日、时辰与一卷简册（村图、天时、观象册、星图、村人簿、行囊、声音、起居注、关于）；画里夜了，界面跟着换成石墨黑上的月白与香槟金。电脑、平板、手机竖屏横屏（到 iPhone SE 那样的矮屏）各有各的排法。

没有账号、没有一张图片素材、没有一段录音：**每一座山、每一株桃、每一间屋、每一个人都是程序现画出来的，每一声溪水、鸟鸣、鸡犬与读书声都是现场合成的。** 古人的原话都注了出处，本应用自己写的话另外说明（「关于」页）。存档只在本机；唯一联网的是「同游」——同在园里的人互相看得见、能作揖问候，经一台只转发、不存东西的小中转（`server/`，见 `docs/NET.md` 与 `server/README.md`；中转不在时照常一个人玩）。

调试用的网址参数：`?auto=1`（跳过题名页）`&s=grove|bridge|yard|hall|pavilion|fields|village|ferry`（从哪一处开始）`&t=now|dawn|day|dusk|night|10.5`、`&w=clear|mist|rain|snow`、`&season=spring|summer|autumn|winter`、`&q=low|mid|high`、`&act=<事的 id>`（直接做某件事，如 `xiang:革`、`dipper`、`book`、`stars`、`farm:thresh`、`swing`）`&ui=0`（不要界面）`&flow=0`（时辰停着，截图、自动检查用；也可给每秒几个钟头，默认 1/60）。

## 跑起来

```
npm install
npm run dev        # http://localhost:3800 （手机在同一个局域网里可以直接用电脑的地址访问）
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 看打包后的样子（离线缓存只在这里才装）
npm test           # 文字的出处与形状、总图（加一倍法的数目、水往低处流）、哪里能走与找路、六十四卦齐全
npm run fonts      # 字体包升级后重新生成 src/app/styles/fonts.css
npm run test:motion   # 浏览器里量人的动态（先另起 3801 的开发服务器，见 tests/play/README.md）
npm run test:acts     # 浏览器里把每一件事从几步外走过去做一遍
```

Node 20.18 可用（Vite 6）。打包结果是纯静态文件、全部用相对路径，放在域名根下或子目录（如 GitHub Pages 的 `/kongshan/`）下都能跑。在 Windows 上要在盘符大写的路径里打包（`D:\…`），小写的 `d:\…` 会让 Vite 报 `html-inline-proxy`。

开发时的三个台子（不进正式构建）：`/world.html?s=yard`（整景，不带界面：`1 2 3 4` 换晨昼昏夜、`5 6 7 8` 换四季、`9 0 - =` 换晴雾雨雪，`?over=1` 是题名页背后的俯瞰，`&flow=0.0167` 让时辰走、`&run=1` 一直跑；不给 `flow` 时辰停着）、`/ink.html?m=hall`（在正式的画法与天时底下单看一个模型，`m` 取 `src/lab/ink/*.ts` 里登记的名字）、`/audio-lab.html`（逐个试听）。

## 放到 GitHub Pages

```
npm run build
node tools/deploy-pages.mjs https://github.com/<你>/<仓库>.git gh-pages
```

把 `dist/` 作为只有一次提交的分支强推上去（分支上只留最新这一版）；仓库的 Pages 设成从那个分支的根目录发布。公开的仓库里不想露邮箱，就先设 `PAGES_NAME`、`PAGES_EMAIL`（GitHub 的 noreply 地址）。改了不带指纹的文件（图标、清单）要把 `public/sw.js` 里的版本号加一，老访客才会换新的。

## 怎么走

| | 电脑 | 手机 |
| --- | --- | --- |
| 走 | `W A S D`（相对镜头的前后左右）；`↑ ↓` 也是前后 | 左下的环，按住往哪边推就往哪边走 |
| 快走 | — | 把环推到头 |
| 跑 | 按住 `Shift`；点一下 `Shift` 锁住一直跑，再点一下放开 | 摇杆旁的「疾」（竖着的手机在摇杆正上方，不占画面当中） |
| 转镜头、看四周 | 拖动画面；`Q` / `E`、`← →` | 拖动画面；双指捏合拉近推远 |
| 走到某处 | 点地面（会自己找路：绕开篱笆树石，过桥、走汀步、上台基；隔着溪的，先绕到石桥或汀步再过去；被牛、村里人挡住了让一步再走；实在过不去，画面下方说一声） | 同左 |
| 做一件事 | 走近了，画里浮出它的名字：按 `E` / `F` / 回车，或点那个名字 | 点那个名字，或右下的主按钮 |
| 做事时 | 点画面（弹琴的一声、扇火、舀酒、点星），面板上选；要按住的（割麦、摇橹、蹬秋千）按住画面右下的大键或 `空格` | 同左（大键在右下） |

平时走 1.4 米/秒（散步的快慢，夜里再慢一成），摇杆推到头快走 3 米/秒，跑 4.6 米/秒（两臂屈肘大摆，长衫被腿顶起、摆脚顺着叉开的腿往上缩、往后扬——腿、手都不会从衣裳里穿出来）；坡和台阶上自动慢一些，挑着担子走得慢、不跑。站久了、散步一阵，人会负手、理袖、望天、伸个懒腰。路远的话打开右上的简册点「村图」，点一处，画面淡成一片雾就到了；村人簿里点「去找他」也行。

打开时画还在铺，画面正中一圈墨环照着进度一笔画满，环里写着百分之几、环下是正在做的那一步（铺纸、远山、种桃……），两步之间环也慢慢往前挪；等了八秒还没好，下面多一句「头一回打开要多等一会儿」。
头一回进来，画从雾里显出来以后浮出五页「初到」（这是哪里、怎么走、怎么做事、时辰会走、声音在哪里调），一页一页翻或「不看了」，看过就不再自己出（「关于」「今日」里可以再看）。再来时题名页上写着上回停在哪、第几日（还有观了几象、认得几个星官、手上几件托事），「入」就从上回停下的地方接着走；也可以点「从桃林走进来」。人走着时每隔几秒记一次落脚处（换处、在雾里时不记）。手机上被门柱、篱笆、树干挡住时，人透出一层淡墨的影子（夜里是月白），看得见自己在哪。

## 这里有什么

| 处 | 能做的事 |
| --- | --- |
| 桃林（入口） | 沿溪六十四株桃；春天落花顺水漂下去 |
| 石桥、柴门 | **读联**：柴门上一副「闭门即是深山，读书随处净土」（明人陈继儒的句子，「关于」里如实写着）；柴门有人走近自己吱呀开；石桥西的溪岸上**垂钓**（蓄劲抛竿，浮子猛沉才提，遛鱼时劲要不松不紧） |
| 柴门外草坡（晴夜） | **观星**：铺一领席躺下仰看。天是洛阳此地此刻的真天（依巴谷星表五千多颗星、五星、银河、流星雨），点一颗星认出它的星官（三垣二十八宿），「四象」一宿一宿点亮，「候星移」看北斗绕极；简册里另有一幅盖天式**星图** |
| 院中 | **浇菊**（十六丛，一瓢浇四丛，回去舀水）、**投壶**（照司马光《投壶新格》计筭：有初、连中、贯耳、骁箭……）、**点灯笼**（黄昏后堂前两盏、柴门一盏）、**扫院**（秋扫落叶、冬扫出一条路）、**堆雪人**（冬天有雪时，推雪球越滚越大）、圭表、石桌四凳、一株老梅两株松；陈设随四季换（胆瓶里春桃夏荷秋菊冬梅、晒架上春笋夏书秋柿冬菜） |
| 草堂 | **书案**（翻《周易》《皇极经世》，或写两句诗——写成的诗笺收进行囊）、**抚琴**、**煮茶**（煮好盛一碗带着）、**自斟**、**榻**（夜里一觉到天亮，白天小憩）、北墙上的**先天图**；冬天榻前一盆炭火 |
| 观物亭 | **观物**（看云起、听蝉鸣、察草虫、候星移）、**小睡**、亭心的**先天八卦盘**、亭角**风铃** |
| 溪桥（夜里） | **认北斗**：点出勺子的七颗星，由斗口两星找到北极，看此刻斗柄指向哪一方 |
| 田畴 | **农事**：先生自己的两畦与两小畦菜——翻地、下种、浇水、锄草，冬麦秋种夏收、粟与豆夏种秋收、菜当季就熟；**割麦**捆麦、挑到晒场**打场**、**扬场**、**推磨**；掐谷穗、打谷、水碓**舂米**；帮邻家王伯割麦；摘桃、打枣、摘柿、采桑；溪边舀水、井上摇辘轳打水。挑上担子（水、麦捆、谷穗）就说挑到哪儿、往哪边走：右上一张小纸里一枚跟着镜头转的箭头与「往东北，踩汀步过溪，约六十步」，画里那一处立一笔带朱点的墨，村图上画出路；走到跟前站住就做起来；用不着可以「放下」，回头再「挑起」 |
| 邻家 | 三十四口人，各有一天的日程（喂鸡、推豆腐磨、织布、编筐、拉坯烧窑、修桥、读书、放羊、打更……，雨天各有各的活）；夏夜槐树下有说书。走近了**说话**：问忙、问农事手艺、闲话家常、送东西（先生拿出那样东西双手递过去，对方伸手接住了才算送到，接了点头、收好——蹲下放在脚边、揣进怀里、插在鬓边；小孩递酒是摆手不要）；行囊里每样东西都写着「用处」，头一回得到时说一句；熟了叫法会变、会回赠；有人托你办事（讨柴、要鱼、念信、找回走散的母鸡……）。新添篾匠、陶家（馒头窑）两户与药圃；村塾前**荡秋千** |
| 渡口、河滩 | **摇橹**（解开小划子，沿北岸摇到竹篙再摇回来；← → / A D 转向，触屏上按住左边的「左」「右」，或点一下要去的水面）、**打水漂**、春天**放纸鸢** |
| 随处 | **观象**：六十四卦各对着这片地方的一景、一个时候（地点、时辰、季节、晴雨照《观象册·意象整理》）；站定看一会儿，那一卦就显出来：卦辞、大象、白话，与「所见」（此地此刻看到的那一景）；收进「观象册」，册里另有「说明」 |
| 同游 | 同在园里的别的游人：一位位穿着不同颜色的衣衫、头上一枚名签（随手起的雅号）；走到跟前可以**作揖**（对方闲着会回礼）、说一句现成的话、**同行**；右上「同游」一枚里看园中各位在哪、在做什么，也可以换作「独游」。手机上点了作揖、说话、同行，那张纸自己收起，好看见自己那一揖、头上那句话 |

右上是「第几日」——点它翻开「今日」：此刻宜做的几件事（按时辰、季节、晴雨挑，此刻做不了的不列）、田里此刻能做的活、手上还没办完的托事、观象与认星记到几成，每件一句话说它是什么、在哪、远近，点「去」就走过去做起来——旁边是此刻的时辰与一枚小卦（十二消息卦）。时辰底下一道细线是一整天：白天那段实、夜里点线，一点朱砂是此刻（夜里换作一圈金）。时辰走过天亮、日中、日头偏西、太阳快落山、天黑、夜深时，画面下方说一句；过了一夜说「又是新的一天」。一卷简册里是：今日、村图、天时（十二时辰、四季、晴雾雨雪；时辰流转停、缓、常、疾四档）、观象册（先天方图，八八六十四卦）、星图、村人簿（按家或按此刻在哪看每个人、他今天的日程、情分与托事）、行囊（割的麦、打的粮、钓的鱼、煮的茶……，每样写着用处）、声音（山居、纯自然、冥想、人间、静五种，再细调风、水、禽、虫、雨、村、人……；初来时总音量先放得轻一些，自己调过就照自己的；合成的人声——书声、村人说话、孩子笑——默认不出，选「人间」或调「人」才有）、起居注、关于。天时默认是春日上午、时辰慢慢走（「缓」：画里一个钟头是这里两分钟；自己没挑过快慢的，都按这一档），也可以跟着本机的钟点走。

## 结构

```
src/
  world/            三维的那片山水（不依赖界面框架）
    ink/            画法：ink（颜料、浓淡、共用的量、点叶点花）、painter（设色 → 积墨勾线 → 罩染 → 装裱）、brush（现画的笔触图集）、text（毛笔字的贴图）
    core/           World（渲染、主循环、画质档、指针）、geo（几何工具）、rng
    env/            atmos（时辰、四季、晴雾雨雪 → 纸色雾色）、sky（天、日月）、stars/（真星空：恒星时、岁差、星表分档、银河、五星、流星；docs/SKY.md）、far（远景：八方的山水，按先天八卦）、land（地与溪池）、water、flora（草木）
    build/          屋舍与器物：草堂与屋里的陈设（随四季换）、柴门门联、院、桥、亭、邻家与村塾、篾匠陶家药圃、井、碓房、渡口……（挂点、可拿的器物、占地、敞棚的檐口都报给行走与屋顶遮罩）
    life/           村里的人（名册在 data/folk.ts，各人一天的日程照它过）与生灵（fauna/）
    fx/             雾、炊烟、窑烟、落花落叶、雨、雪、灯晕
    avatar/         行者（小人）：长衫是每帧现摆的筒，不是蒙皮；走、快走、跑的步态，坐卧（含仰卧）、俯身、闲时的小动作、两臂的反向运动学（docs/AVATAR.md）
    farm/           农事的账（每畦七个样子、墒情、草、照看）、畦面与庄稼的画法、扁担（docs/FARM.md）
    play/           秋千、船与橹、钓竿、纸鸢、壶与矢、灯笼、水纹（docs/PLAY.md）
    acts/           可做的事：home（书案、琴、茶、酒、榻、先天图、门联）、pavilion（观物、小睡、八卦盘）、yard（浇菊、小车、讨茶）、xiang（观象）、talk 与 favor（说话、情分、托事）、dipper（认北斗）、stars（观星）、farm*（农事四十余件）、swing boat fishing kite pitchpot skip snowman lantern broom chime gate（器物与玩）
    site.ts         总图：哪里是什么（唯一的出处；坐标 +x 东、+z 南，原点草堂正中）
    walk.ts         哪里能走：地面高度 + 水深 + 挡路的东西 + 找路（0.2 米一格的 A*，拐弯拉直）
```

## 几个决定

- **画出来，不是照出来。** 没有光照、影子、色调映射；每样东西是「纸 × 颜料^浓度」，背光的一面浓一些，轮廓与转折处由画法统一落墨线，远处褪成墨色，山从山脊往下由浓到淡（`docs/INK.md`）。
- **《易》只当象看，不占卜。** 八方合先天八卦，时辰配消息卦，景物对卦象（大象传）；园里暗藏加一倍法的数：一梅、二松、四凳、八亭柱、十六丛菊、三十二丛竹、六十四株桃；四时各一花：桃、莲、菊、梅。
- **人情味。** 田要耕、桑要采、桥要修、孩童读书、老人有人照看：村里三十四口人各有名姓、家人、脾气、所好与一天的日程，夜里回家，雨天在檐下做雨天的活；路上碰见了点头，爱说话的站下来说几句。走近了能说话，情分慢慢深（初识、相熟、相得、知交，不做数值条），熟了远远地会朝你招手。
- **时辰会走，日子一天天过。** 默认画里一个钟头是这里一分钟；过了子夜、或在榻上睡到天亮，就是新的一天：庄稼长一截，雪人化一点，扫过的院子又落满叶。换季当作往后过了几季（秋种的麦，换到夏天就黄熟了）。
- **屋顶底下是屋里。** 雪不积在屋里、雨不打湿屋里，雨雪落花不飘进檐下（画法里一层屋顶遮罩，屋舍报上来的檐口多高就遮到多高）。进了草堂，屋顶与南墙隐去，镜头从南面高处往里看，只在南面敞着的那一扇里转（俯仰、远近也有个范围），不会转到山墙后头、钻进院里的树；人走近东西山墙时镜头往南让一让；进出都是从原处缓缓滑过去，在屋里做完事回到这个镜头。摸狗时镜头从侧面看人蹲下挠它（先找右侧、再左侧、再前面，挑一处看得通的），不绕到人背后，免得人和狗被身子挡住。
- **换季一起换。** 地色、雪、草木、远树、天光、纸色在同一段（一秒多）里一起从此刻的样子换到新的一季，接连点几季也接得上；冬天下着雪换到别的季节，雪停、天放晴，地上的雪跟着化尽（要在别的季节看雪，再点「雪」）。换季才露面的东西开场时先画一遍，换的那一下不卡。
- **天是真的。** 晴夜的星按洛阳的纬度、此刻的恒星时与今年的岁差摆；斗柄春东夏南秋西冬北，参商不同天；月相是今天的月相。日出日落落在节气的时刻上，所以圭表的日影也是真的。
- **你是一位先生，慢慢地走。** 每件事都让他「真的做得到」：坐凳、盘坐、蹲在炉前，手伸到琴弦、书页、酒瓮口上；做完站起来。
- **坡上顺着坡走，台阶一级一级地上。** 脚踩在画出来的那一层地上（行走用的地面高度与地面网格一模一样）。
- **文字有出处。** 古人的话逐字对过几种版本（`docs/SOURCES.md`）；本应用自己写的话（题下「心能安处即桃源」、「春种秋收，便是大吉」、村里人的家常话）在「关于」里分开说明；门联是明人的句子，不冒充宋人。
- **一切只存在本机**（localStorage）：偏好、起居注、观过的象、行囊、田里种了什么、和谁熟、托的事办没办、第几日。

## 画质与性能

| 档 | 用在 | 像素比上限 | 草木数量 |
| --- | --- | --- | --- |
| high | 台式机（8 核以上） | 2 | 全部 |
| mid | 一般电脑 / 较好的手机 | 1.5 | 七成五 |
| low | 一般手机 | 1.25 | 一半 |

都开四倍多重采样（点叶点花的软边靠它）。画面慢了会自动降清晰度，宽裕了再升回来；做静的事（小睡、观物）时帧率降到 30。`?q=` 可强制档位。

开发机上（无头 Chrome，RTX 4090、32 核）各处量到的：high 约 49–95 万三角、53–158 次绘制；low（手机尺寸）约 30–67 万三角、50–155 次绘制；不锁帧时整帧 0.8–2.0 毫秒（九成的帧在 2.4 毫秒以内）。最重的是桃林入口望全谷那一眼，其次是上午的村里（三十来个人在外头）。从打开到能点「入」约 3 秒。

## 验证过的，和没验证过的

**验证过**（脚本在 `tests/play/`，怎么跑见那里的 README；都是无头 Chrome 里用真实的按键、点按跑的）：
一次全跑（`node tests/play/all.mjs`，约 75 分钟）的结果，2026-11-21：
- **共用的底子**（12 项）：时辰流转过子夜是新的一天，榻上睡到天亮也算一夜；键盘散步 1.35 米/秒、Shift 跑 4.4 米/秒、松手停；屋顶遮罩登记 16 处，书案地面遮着、院里屋脊露天，进草堂时屋顶剖开。
- **人的动态**（127 项）：按键方向；走、快走、跑的步幅步频、着地的脚不滑、单双支撑与腾空；起跑、急停、跑着转弯内倾；**上下坡、草堂的踏步石与台基、石桥、观物亭的踏步、汀步**时身子升降连贯、脚不陷；顶着篱笆停住；跪、盘坐、坐凳、蹲、仰卧不穿地；闲时小动作；挑担放慢；镜头不进墙、不钻地。
- **每一件事**（电脑、手机各 57 项）：都从几步之外走过去、站定开始、按流程做完、站起来能走；观象记进册子。
- **说话**（262 项）：三个时辰把在外头的二三十个人一个个走过去说话、送东西、做成三件托事；面板在三种尺寸下放得下。
- **观星**（21 项）、**农事**（56 项：春夏秋三季整条链，行囊里的数目对）、**生灵**（51 项：九件事、四季各一整天、跑过鸡群会惊散、狗会迎人）、**玩**（86 项：十样从头玩到尾、记分对、退出站得起来；柴门开合）、**村里的一天**（48 项：四季晴雨八种一天，没人穿墙、进深水、卡住、叠在一起）。
- **全流程**（电脑、手机）与**界面**（六种尺寸各三十来屏：出界、截断、安全区、键太小、两键相叠、字与底的对比，都是 0 条）；正式构建上再跑全流程与断网重开。
- **声音**（386 项）：每一种都离线渲染出来量时长、峰值、频谱，比对相像的两种分得开；混音的规矩；实时跑一遍。
- 单元测试（162 项）：总图（一梅二松三十二竹六十四桃、溪水一路往低处流、井田九畦）、行走（从入口到各处都走得通、水里墙里菊圃里站不住）、存档与行囊、名册（每人每个钟头都有着落）、话（说到的家里人真是他家里人）、农时、星空（斗柄四季的指向、参商不同天、北极星高度等于纬度）。
- 文字：五百多处引文逐字对过两到四种版本（见 `docs/SOURCES.md`）。

## 还没做的 / 已知不足

- 远处的石峰、近处的大树近看仍有程序搭的痕迹；夜里屋里的家什偏暗。
- 鸡、狗、猫、羊近看还是几块圆块拼的，腿是硬的两节，走起来脚会滑一点；鸭子游水不绕石头和桥墩；黄鹂、喜鹊落的枝是估的，近看会悬在叶丛里。
- 屋里看不见村里人（人进了屋就不画）；织布、推磨时手与梭、磨把对得不严；站在檐下的人雨大时可能被淋到。
- 仰卧时衣摆是固定的截面，躺下那一刹近看不大像布。雨雪天的蓑衣是刚性的一领（只按两臂撑开），跑起来不飘。
- 踢毽子没做（行者还没有抬脚踢的动作）；陶家的窑春夏秋一直烧着，没有歇几天烧几天的节奏。
- 合成的一声「嗯」（村人打招呼）听着可能假，先静掉了（`src/app/sound.ts` 的 `HUSH`）；远处几个人说话的嗡嗡（`murmur`）留着但压得很轻。
- 只有简体；没有英文。
- 一个人的园子：没有「与他人同在」。
